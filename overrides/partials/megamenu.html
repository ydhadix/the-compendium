{#- Global hover mega-menu: L1 top nav items, rendered horizontally (depth = 1) L2+ every section that has children (beyond its own index page) shows them, recursively, until the depth cap is reached. Depth cap: config.extra.megamenu_max_depth (default: unlimited) is the deepest level rendered as an expandable flyout, counting the horizontal top row as 1. A section at the cap renders as a plain link to its own index page instead of opening another flyout, so its contents stay reachable via that index.   • {% if item.index_page %} {{ item.title }} {% else %} {{ item.title }} {% endif %} {{ megamenu(children, depth + 1) }}
    • {% else %} {#- a section with no children to show: a plain link to its index -#}
  • {% if item.index_page %} {{ item.title }} {% else %} {{ item.title }} {% endif %}
