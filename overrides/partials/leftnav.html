Active path = mkdocs `item.active` for pages in the nav; for pages kept out of the nav (leaf pages) it is `localnav_chain` / `localnav_host` from navtools.py. Those siblings appear only while we are on one of them — the hub's own index page shows nothing below it, so the same depth rule used for sections holds for leaf collections too.
