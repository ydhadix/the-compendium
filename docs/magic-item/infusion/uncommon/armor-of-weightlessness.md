### Armor of Weightlessness
Uncommon Armor (Any), Attunement
{ .subtitle }

**5** Charges (regain **1d4 + 1** per Day)
{ .subtitle }

You have Immunity to Falling Damage.

###### Cast
You can cast the following spells:

| Spell | Action | Charges |
|---|---|---|
| _Jump_ | Bonus Action | **1** Charge |
| _Levitate_ | Bonus Action | **2** Charges |
