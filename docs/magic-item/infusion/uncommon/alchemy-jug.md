### Alchemy Jug
Uncommon Wondrous Item
{ .subtitle }

**1** Charge (regain **1** per Day)
{ .subtitle }

###### Name Liquid
Magic Action, 1 Charge
{ .subtitle }

You choose one of the following liquids, and the jug immediately begins producing it.

| Liquid | Maximum |
|---|---|
| Acid | 8 ounces |
| Basic Poison | 4 ounces |
| Beer | 4 gallons |
| Honey | 1 gallon |
| Mayonnaise | 2 gallons |
| Oil | 1 quart |
| Vinegar | 2 gallons |
| Fresh Water | 8 gallons |
| Salt Water | 12 gallons |
| Wine | 1 gallon |

###### Pour
Utilize Action
{ .subtitle }

You can pour out up to **2** gallons per minute of the named liquid, up to its Maximum.
