### Rope of Climbing
Uncommon Wondrous Item
{ .subtitle }

This rope is **60** feet long and can hold up to **3,000** pounds. It has an Armor Class of **20**, **20** Hit Points, and Poison and Psychic Immunity. It regains **1** Hit Point every **5** minutes, but is destroyed if it drops to **0** Hit Points.

###### Command
Magic Action
{ .subtitle }

While holding one end of the rope, you can speak one of the following Command Words. Speak its opposite to end the effect.

| Command Word | Effect |
|---|---|
| Move / Stop | Choose a location within **60** feet. The other end moves **10** feet toward it before each of your Turns ends. |
| Fasten / Unfasten | The other end securely fastens to an object. |
| Knot / Unknot | Large knots appear at **1**-foot intervals, shortening the rope to **50** feet and granting Advantage on Checks to Climb it. |
| Coil / Uncoil | All other effects end and the rope coils itself. |
