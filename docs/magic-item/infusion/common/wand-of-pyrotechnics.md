### Wand of Pyrotechnics
Common Spellcasting Focus (Arcane Focus)
{ .subtitle }

**7** Charges (regain **1d6 + 1** per Day)
{ .subtitle }

###### Spark
Magic Action, 1 Charge
{ .subtitle }

You can create a harmless burst of multicolored light at a point up to **120** feet away. The light is as bright as a torch flame but lasts only **1** second. The light is accompanied by a crackling noise audible out to **300** feet.
