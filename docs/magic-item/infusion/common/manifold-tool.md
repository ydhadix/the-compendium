### Manifold Tool
Common Wondrous Item, Attunement (Artificer)
{ .subtitle }

**1** Charge (regain **1** per Day)
{ .subtitle }

###### Transform Tool
Magic Action
{ .subtitle }

This tool transforms into any Artisan's Tool you have Proficiency with.

###### Gain Proficiency
Magic Action, 1 Charge
{ .subtitle }

You can gain Proficiency with one Artisan's Tool until you finish a Long Rest.
