# Charges

Some Magic Items hold Charges that power their effects.
{ .subtitle }

An item with Charges lists its maximum number of Charges alongside how many it regains. Using certain effects expends a number of Charges, and an effect can't be used while the item lacks the Charges to pay for it.

## Regaining Charges

An item regains Charges each Day, either a fixed number or a rolled amount noted in parentheses, such as **1d6 + 4** per Day. An item never exceeds its maximum number of Charges.
