# Infusions

Infusions are magical properties added to Weapons, Armor, Adventuring Gear, and other items, turning them into Magic Items.
{ .subtitle }

## Using Magic Items

Magic Items usually require wearing or wielding them properly. Magic Items that don't fit the standard [Item Types](../../item/equip.md#item-types) are called Wondrous Items, and their usage varies.

### Infusion Properties

Many Infusions share common properties.

| Property | Effect |
|---|---|
| [Attunement](attunement.md) | You must Attune to this item to use its effects. |
| [Charges](charge.md) | You expend this item's Charges to use some of its effects. |
| Command Word | You must audibly speak a Command Word to use some of this item's effects. |
| [Consumable](../../item/equip.md#consumables) | You can use this item a limited number of times before it loses its magic. |
| Cursed | This item has a hidden, detrimental effect. Most methods of identifying items don't reveal curses, and you can't voluntarily end your Attunement to it. |

### Identification

Some Magic Items are indistinguishable from their nonmagical counterparts, while others are obviously magical.

The _Identify_ Spell is the fastest way to reveal an item's properties.

Wearing or attempting to use an item can also offer hints about its properties. For Potions, a little taste is enough to tell you what a Potion does.

Alternatively, you can spend a Short Rest focused on only that item while in physical contact with it. This can't be the same Short Rest used to Attune to the item. After you finish the Short Rest, you learn the item's properties and how to use them.

## Infusions by Rarity

| Rarity | Description |
|---|---|
| [Common](common/index.md) | Minor Infusions with modest, often utilitarian effects. |
| [Uncommon](uncommon/index.md) | Broadly useful Infusions for exploration and combat. |
| [Rare](rare/index.md) | Potent Infusions with significant magical effects. |
| [Very Rare](very-rare/index.md) | Powerful Infusions rivaling high-level magic. |
| [Legendary](legendary/index.md) | The most powerful Infusions, rarely crafted. |
| [Artifacts](artifact/index.md) | Singular items of immense power and history. |
| [Unique](unique/index.md) | One-of-a-kind items with custom properties. |
