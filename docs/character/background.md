# Backgrounds
A **Background** represents the life a character led before adventuring.  You can create your own background, or you can modify an existing background to suit your character.
{ .subtitle }

## Parts of a Background
Each background includes the following parts:

- **3** Abilities, which each increase by **1**
- **1** Feat — an Origin Feat or Fighting Style
- **2** Skill Proficiencies
- **1** Trade Proficiency
- **1** Skill or Trade Expertise
- **3** languages: Common, **1** Standard, and **1** Exotic
- **1** Common Magic Item
- **50** gold to spend on equipment
