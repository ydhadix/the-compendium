##### Careful Spell
1 Sorcery Point
{ .subtitle }

Choose a number of creatures up to your Sorcerer Ability. The chosen creatures automatically succeed on Saving Throws against the Spell and take no damage from it.

##### Distant Spell
1 Sorcery Point
{ .subtitle }

The Spell's Range is doubled. If the Spell has a Range of Reach, its Range becomes **30** feet instead.

##### Empowered Spell
1 Sorcery Point
{ .subtitle }

The first time you make a Damage Roll for the Spell, you can reroll up to your Sorcerer Ability in Damage Dice. You can use this Metamagic even if you've already used a different Metamagic on the Spell.

##### Extended Spell
1 Sorcery Point
{ .subtitle }

The Spell's Duration is doubled, up to a maximum of **24** hours. You have Advantage on Concentration Saves for the Spell.

##### Heightened Spell
2 Sorcery Points
{ .subtitle }

Choose a Target of the Spell. That Target has Disadvantage on Saving Throws against the Spell.

##### Quickened Spell
2 Sorcery Points
{ .subtitle }

If the Spell has a Casting Time of an Action, you can change it to a Bonus Action.

##### Seeking Spell
1 Sorcery Point
{ .subtitle }

The first time you miss with an Attack Roll for the Spell, you can reroll the Attack Roll. You can use this Metamagic even if you've already used a different Metamagic on the Spell.

##### Subtle Spell
1 Sorcery Point
{ .subtitle }

The Spell has no Components, except Material Components that are consumed or have a gold value.

##### Transmuted Spell
1 Sorcery Point
{ .subtitle }

You can change all instances of one Elemental Damage Type in the Spell to a different Elemental Damage Type.

##### Twinned Spell
Spell's Level in Sorcery Points (minimum 1)
{ .subtitle }

If the Spell has exactly one Target, you can choose a second Target.
