##### Repelling Blast
Prerequisite: Level 2 Warlock, a Warlock Cantrip with an Attack Roll
{ .subtitle }

Choose a Warlock Cantrip that requires an Attack Roll.
###### Repel
**Free Action:** After you hit a creature with that Spell, if the target is no more than **1** Size larger than you, you can propel it up to **10** feet away from you.
###### Repeatable
You can learn this Invocation more than once, choosing a different Cantrip each time.
