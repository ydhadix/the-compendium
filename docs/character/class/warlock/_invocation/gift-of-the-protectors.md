##### Gift of the Protectors
Prerequisite: Level 7 Warlock, Pact of the Tome
{ .subtitle }

After you summon your Book of Shadows, a new page appears. It can hold up to **Warlock Ability** names _(minimum **1**)_, and a creature can write only its own name on it. You can erase a name by touching it.
###### Guardian's Ward
1 use per Long Rest
{ .subtitle }

Before a creature whose name is on the page would drop to **0** Hit Points or be killed, you can set its Hit Points to **1** instead.
