# Hero Handbook

The Hero Handbook covers everything you need to build a character: creating one step by step, choosing a formative background, selecting a race, and picking the feats that set your character apart.


| Sections | Description |
|---|---|
| [Character Creation](creation.md) | Building a character step by step, from abilities to finishing touches. |
| [Backgrounds](background.md) | Formative origins that grant abilities, a feat, proficiencies, and starting gear. |
| [Races](race/index.md) | Playable heritages and the Traits and Features each one grants. |
| [Feats](feat/index.md) | Special talents that customize your character beyond race and class. |
