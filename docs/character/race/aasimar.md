# Aasimar
Aasimar are mortals touched by the divine, carrying a spark of celestial power that can blaze forth in moments of need.
{ .subtitle }

## Aasimar Features
### Divine Revelation
Bonus Action, 1 use per Long Rest
{ .subtitle }

Choose one of the following revelations. You can choose a different revelation each time you use this feature.

You gain the following benefits for **1** minute or until you end this effect _(no action required)_:

- You have the revelation's effects.
- Before you deal damage, you can add **PB** Necrotic or Radiant Damage.
##### Winged
You gain a Fly Speed equal to your Speed.
##### Chosen
You emit Bright Light to **10** feet and Dim Light **10** feet further. Before your Turn ends, you deal **PB** Radiant Damage to each other creature within a **10**-foot Aura.
##### Fallen
Each creature within **10** feet makes a Will Save _(DC = **8 + CON + PB**)_.

| | |
|---|---|
| Fail | The target is Frightened by you until this revelation ends. |
