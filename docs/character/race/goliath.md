# Goliath
**Goliaths** are towering giant-kin of tremendous strength, able to call on the power of their giant ancestry and grow to an even greater size.
{ .subtitle }

| | |
|---|---|
| Abilities | Strength and choose **1** |
| Creature Type | Humanoid and Giant |
| Size | Medium |
| Speed | **30** ft. |
| Reach | **10** ft. |
| Hit Points | **10** |
| Resistances | the chosen Damage Type |
| Protections | Grapple |

## Goliath Features
### Powerful Build
You gain Advantage on Athletics Checks, and your Jump distance doubles.

### Large Form
Bonus Action, 1 use per Long Rest
{ .subtitle }

For **10** minutes or until you end this effect _(no action required)_, you are Large, you gain Advantage on Strength Checks, and your Speed increases by **10** feet.

### Giant Ancestry
Choose an ancestry.

Each ancestry determines the type of your Resistance and gives you a different effect.

##### Cloud Goliath
You gain Thunder Resistance.
###### Cloud Jaunt
Bonus Action, Proficiency Bonus uses per Long Rest
{ .subtitle }

You can teleport up to **30** feet.

##### Fire Goliath
You gain Fire Resistance.
###### Fire Smite
Free Action, Proficiency Bonus uses per Long Rest
{ .subtitle }

Before you deal damage, you can add **1d10** Fire Damage.

##### Frost Goliath
You gain Cold Resistance.
###### Frost Smite
Free Action, Proficiency Bonus uses per Long Rest
{ .subtitle }

Before you deal damage, you can add **1d6** Cold Damage. After you deal that damage, the target's Speed decreases by **10** feet until the start of your next Turn.

##### Hill Goliath
You gain Poison Resistance.
###### Hill Quake
Free Action, Proficiency Bonus uses per Long Rest
{ .subtitle }

After you damage a creature, you can knock the target Prone.

##### Stone Goliath
You gain Poison Resistance.
###### Stone Endurance
Reaction, Proficiency Bonus uses per Long Rest
{ .subtitle }

Before you take damage, you can reduce that damage by **1d12 + CON**.

##### Storm Goliath
You gain Lightning Resistance.
###### Storm Rebuke
Reaction, Proficiency Bonus uses per Long Rest
{ .subtitle }

After you take damage from a creature within **60** feet, you can deal **1d8** Thunder Damage to the target.
