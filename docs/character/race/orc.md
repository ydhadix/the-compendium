# Orc

Orcs are powerfully built and famously hard to put down, clinging to life when others would fall. A surge of adrenaline lets them charge into the fray with renewed vigor.

## Orc Features

### Powerful Build
Your carry capacity is doubled.

### Relentless Endurance
Free Action, 1 use per Long Rest
{ .subtitle }

Before you are reduced to **0** Hit Points but not killed outright, you can drop to **1** Hit Point instead.

### Orcish Adrenaline
Bonus Action, Proficiency Bonus uses per Short Rest
{ .subtitle }

You can Dash and gain **PB** Temporary Hit Points.
