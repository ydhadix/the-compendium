# Races
A character's Race is the people they were born among, forming their body, a heritage, and the innate traits that come with it.
{ .subtitle }

| Races | Description |
|---|---|
| [Aasimar](aasimar.md) | Mortals touched by celestial light. |
| [Dragonborn](dragonborn.md) | Proud kin of dragons, scales and breath alike. |
| [Dwarf](dwarf.md) | Hardy folk of stone and deep places. |
| [Elf](elf.md) | Long-lived people of grace and keen senses. |
| [Gnome](gnome.md) | Small, clever folk of restless curiosity. |
| [Goliath](goliath.md) | Towering giant-kin of great strength. |
| [Halfling](halfling.md) | Small, nimble folk of remarkable luck. |
| [Orc](orc.md) | Fierce, enduring warriors who never yield. |
| [Prime](prime.md) | Ordinary folk whose strength is adaptability. |
| [Synth](synth.md) | Constructed beings built for a purpose. |
| [Tiefling](tiefling.md) | Mortals marked by a fiendish bloodline. |
