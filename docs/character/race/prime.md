# Prime
**Primes** are ordinary folk with no supernatural gifts. Their strength lies in sheer adaptability, ready to turn their hand to whatever task an adventure demands.
{ .subtitle }

| | |
|---|---|
| Abilities | Choose **2** |
| Creature Type | Humanoid |
| Size Category | Medium |
| Speed | **30** ft. |
| Reach | **5** ft. |
| Hit Points | **8** |

## Prime Features
### Resourceful
Free Action, 1 use per Long Rest
{ .subtitle }

Before you roll a d20, you can roll an additional d20 and choose which d20 to use.

### Skillful
You gain Proficiency in one Skill.

### Versatile
You learn an Origin Feat.
