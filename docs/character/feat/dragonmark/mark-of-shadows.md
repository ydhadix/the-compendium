### Mark of Shadows
Prerequisite: No other Dragonmark
{ .subtitle }

#### Mark Proficiency
You have Deception or Performance Proficiency.

#### Mark Spells
You learn this Dragonmark's Spells at the corresponding Levels.  You can cast those Spells using Intelligence, Wisdom, or Charisma as your Spellcasting Ability.

| LV | Spells |
|---|---|
| 1st | _Minor Illusion_, _Disguise Self_ |
| 3rd | _Invisibility_ |
| 5th | _Major Image_ |
| 7th | _Greater Invisibility_ |
| 9th | _Mislead_ |

###### Free Casting
1 use each per Long Rest
{ .subtitle }

You can cast one of this Dragonmark's Spells without a Spell Slot.

###### Changing Spells
Whenever you level up, you can replace one of this Dragonmark's Spells with a Bard Spell of the same Level, provided that Spell doesn't deal damage.
