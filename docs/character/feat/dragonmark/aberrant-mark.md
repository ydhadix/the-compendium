### Aberrant Dragonmark
Prerequisite: No other Dragonmark
{ .subtitle }

#### Uncanny Fortitude
You add **1d4** to Fortitude Saves.

#### Aberrant Spells
You learn one Sorcerer Cantrip and one 1st-Level Sorcerer Spell.  You can cast those Spells using Intelligence, Wisdom, or Charisma as your Spellcasting Ability.

###### Free Casting
1 use per Short Rest
{ .subtitle }

You can cast this Dragonmark's Spell without a Spell Slot.

###### Changing Spells
Whenever you level up, you can replace one of this Dragonmark's Spells with a Sorcerer Spell of the same Level.
