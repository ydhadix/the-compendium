# Feats

Feats are special talents that customize your character beyond race and class. They come in several categories, each earned in a different way.


| Feats | Description |
|---|---|
| [Origin Feats](origin/index.md) | Broadly useful talents granted by your background. |
| [General Feats](general/index.md) | Wide-ranging feats, often gated behind an ability prerequisite. |
| [Fighting Styles](fighting-style/index.md) | Combat specializations that sharpen a particular way of fighting. |
| [Advanced Fighting Styles](advanced-fighting-style/index.md) | Higher-tier techniques that build on the basic fighting styles. |
| [Ancestry Feats](ancestry/index.md) | Feats tied to the traits of a specific race. |
| [Epic Boons](epic/index.md) | Powerful rewards gained at the highest levels of play. |
| [Dragonmarks](dragonmark/index.md) | Inherited magical sigils that grant themed spells and powers. |
