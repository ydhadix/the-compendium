# Feats
Feats are the special talents a character picks up along their adventures, distinct abilities that sharpen their strengths or open new options.
{ .subtitle }

| Feats | Description |
|---|---|
| [Origin Feats](origin/index.md) | Foundational talents gained at character creation. |
| [General Feats](general/index.md) | Broadly useful talents gained as a character levels. |
| [Fighting Styles](fighting-style/index.md) | Combat specialties for martial characters. |
| [Ancestry Feats](ancestry/index.md) | Talents drawn from a character's race. |
| [Epic Boons](epic/index.md) | Legendary rewards for the mightiest heroes. |
| [Dragonmarks](dragonmark/index.md) | Heritable magical sigils granting arcane gifts. |
