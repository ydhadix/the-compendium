### Crafter

Nonmagical items and materials you buy cost **20**% less.

You gain Proficiency with **3** of the following Artisan's Tools.

- Carpenter's Tools
- Leatherworker's Tools
- Mason's Tools
- Potter's Tools
- Smith's Tools
- Tinker's Tools
- Weaver's Tools
- Woodcarver's Tools

##### Quick Crafting
**Utilize Action; PB times per Long Rest:** You can create a nonmagical item associated with one of your Artisan's Tool Proficiencies, provided you have the tools in hand.

The crafted item can't be Armor, a Ranged or Martial Weapon, or cost more than **25** gold. Items crafted this way have no value to merchants and fall apart after you finish a Long Rest.
