### Actor
Prerequisite: **2** Charisma
{ .subtitle }

You gain Deception or Performance Proficiency.  If you already have the chosen Proficiency, you instead gain Expertise.

#### Mimicry

While you're disguised as another person, you gain Advantage on Deception and Performance Checks to convince others you aren't that person.

You can mimic the sounds of another creature. A creature that can hear you can make an Insight Check _(DC **8 + CHA + PB**)_ _(no action required)_.

| | |
|---|---|
| Success | The creature determines the mimicry is faked. |
