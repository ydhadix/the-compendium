# Dark Elf Names
Dark elves prefer names that flow off the tongue, though theirs carry a harsher sound.
{ .subtitle }

<div data-search-exclude markdown="1">

A dark elf name draws on a tradition of millennia of evil, and a surface-dwelling dark elf may carry a name that is harsher than their own nature. It is equally possible for a surface dweller to adopt a mix of both traditions. As this set of tables cannot possibly represent every name available to them, this list combined with the [elven name generator](/archive/utilities/elf-name-generator.md) can serve to generate names that reflect that blended convention as well as give a decent starting point.

## How it Works
These tables work in much the same way as the [elven name generator](/archive/utilities/elf-name-generator.md). Each dark elf name consists of a prefix (from [Table 2](#table-2-prefixes)) and one or more suffixes (from [Table 3](#table-3-suffixes)), and then a house name rolled on [Table 1B](#table-1b-house-names), which draws its prefix from [Table 4](#table-4-house-name-prefixes) and its suffixes from [Table 5](#table-5-house-name-suffixes). House standing carries weight among dark elves, so most carry a house name where an elf would take one only for an ancient noble line. Because all the tables can be used, feel free to choose which tables a prefix and suffix are generated from. Definitions have been included in these tables to help determine what a name means once it has been generated. In the case of suffixes, male and female endings have been included where appropriate. Alternate spellings have also been provided in some cases.

You may randomly generate a dark elf name by rolling on [Table 1](#table-1). If you prefer, it is also possible to pick a set of definitions you like and assemble the name that matches them. If your character is a wizard who is fond of spiders, you might decide their name should reflect this. Looking at the definitions, you decide the name will mean “Spider-Mage.” This results in the name “G’eldriina” or “G’eldree.”

If you don’t like a particular combination, try some of the alternate suffixes listed, or add an “a,” “e,” “i,” “l,” “r,” “s,” “sh,” or an apostrophe. Although not every combination of prefixes and suffixes will sound right, usually only a minor change is called for. If you can’t make a particular name work, try one with a similar meaning. If you didn’t like “G’eldriina,” try a name that means “Spider-Sister” instead. If you have randomly generated a name and don’t like its definition, try altering the order of the words. It is also possible to use the definition as just a starting place for the name’s meaning. Often the definitions can be combined in a poetic way for better results. In the case of a three or more syllable name, try dropping one or more of the definitions. Above all, remember that these names can be a mixture of two naming conventions, and may reflect the mix of personality and tradition rather than the personality alone.
