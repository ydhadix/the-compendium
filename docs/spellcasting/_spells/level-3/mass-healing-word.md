### *Mass Healing Word*

| 3rd-Level Abjuration | *bard, cleric* |
|---|---|
| components | v |
| cast time | bonus action |
| range | 60 feet |
| target | up to six creatures |
| duration | - |

each target heals 2d4 + your spellcasting ability.

**At Higher Levels:** add 1d4 healing per additional spell level.
