    #### Dispel Magic

    | 3rd-Level Abjuration | *artificer, bard, cleric, druid, paladin, ranger, sorcerer, warlock, wizard* |
    |---|---|
    | components | v, s |
    | cast time | full action |
    | range | 120 feet |
    | target | one magical effect or thing |
    | duration | - |

    All spells on the target end if their level is this spell's level or less. for each spell higher than this spell's level, make a check using your spellcasting ability against dc 10 + that spell's level. on a success, that spell ends.
