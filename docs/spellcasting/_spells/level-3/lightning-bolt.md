    #### Lightning Bolt

    | 3rd-Level Evocation | *sorcerer, wizard* |
    |---|---|
    | components | v, s, m |
    | cast time | full action |
    | range | reach |
    | target | everything in a 5 × 100-foot line |
    | duration | - |

    Each target makes a reflex save.

    Fail: you deal 8d6 lightning damage.

    Success: you deal half as much damage.

    **At Higher Levels:** add 1d6 lightning damage and 10 feet to the length per additional spell level.
