### *Fly*

| 3rd-Level Transmutation | *artificer, sorcerer, warlock, wizard* |
|---|---|
| components | v, s, m |
| cast time | full action |
| range | reach |
| target | one creature |
| duration | 10 minutes (concentration) |

the target has a 60 foot hover speed.

**At Higher Levels:** add one target per additional spell level.
