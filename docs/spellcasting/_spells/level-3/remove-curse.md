??? spell "Remove Curse | 3rd-Level Abjuration"

    #### Remove Curse

    | 3rd-Level Abjuration | *artificer, cleric, paladin, warlock, wizard* |
    |---|---|
    | components | v, s |
    | cast time | full action |
    | range | reach |
    | target | one thing |
    | duration | - |

    All curses on the target end. if the target is a cursed magic item, its curse remains, but all creatures are unattuned from the item.
