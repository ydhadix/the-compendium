    #### Levitate

    | 2nd-Level Transmutation | *artificer, sorcerer, wizard* |
    |---|---|
    | components | v, s, m |
    | cast time | full action |
    | range | 60 feet |
    | target | one thing |
    | duration | 10 minutes (concentration) |

    The target makes a fortitude save.

    Fail: the target rises 20 feet and remains suspended. the target can only move by climbing using a surface or fixed object within reach. when this spell ends, the target lands and takes no damage from the fall.

    Success: this spell ends.

    Magic action: you vertically move the target up to 20 feet. if you are the target, this action can be done as part of your movement instead.
