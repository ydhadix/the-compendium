### *Scorching Ray*

| 2nd-Level Evocation | *sorcerer, wizard* |
|---|---|
| components | v, s |
| cast time | full action |
| range | 120 feet |
| target | up to 3 creatures or objects |
| duration | - |

you make a ranged attack against each target.

hit: you deal 2d6 fire damage. a flammable object starts burning (1d4).

**At Higher Levels:** add one target per additional spell level.
