??? spell "Identify | 1st-Level Divination"

    #### Identify

    | 1st-Level Divination | *artificer, bard, wizard* |
    |---|---|
    | components | v, s, m (a pearl worth 100 gold) |
    | cast time | 1 minute, or ritual |
    | range | reach |
    | target | one thing |
    | duration | - |

    You learn the names of any ongoing spells currently affecting the target. if the target was created by a spell, you learn that spell's name.

    If the target is a magic item or some other magical object, you learn its properties and how to use them, whether it requires attunement, and how many charges it has.
