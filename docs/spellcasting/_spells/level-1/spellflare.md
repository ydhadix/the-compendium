??? spell "Spellflare | 1st-Level Evocation"

    #### Spellflare

    | 1st-Level Evocation | *sorcerer, wizard* |
    |---|---|
    | components | v, s |
    | cast time | full action |
    | range | 60 feet |
    | target | one thing |
    | duration | - |

    You make a ranged attack against the target, ignoring half or three-quarters cover.

    Hit: you deal 2d10 radiant damage.

    **At Higher Levels:** make one additional attack per additional spell level. each attack can have the same target or different targets.
