    #### Magic Missile

    | 1st-Level Evocation | *sorcerer, wizard* |
    |---|---|
    | components | v, s |
    | cast time | full action |
    | range | 120 feet |
    | target | up to 3 creatures or objects |
    | duration | - |

    You create three glowing darts, which simultaneously strike one target each. each dart can strike the same target, or they can strike different targets.

    You deal 1d4 + 1 force damage with each dart.

    **At Higher Levels:** add one dart and up to one target per additional spell level.
