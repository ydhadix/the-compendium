    #### Mage Hand

    | Conjuration Cantrip | *artificer, bard, sorcerer, warlock, wizard* |
    |---|---|
    | components | v, s |
    | cast time | full action |
    | range | 30 feet |
    | target | - |
    | duration | 1 minute |

    You create a spectral, floating hand and take the following magic action (no additional action required). the hand can't attack, activate magic items, or carry more than 10 pounds. this spell ends if you cast it again or if the hand is out of range.

    Magic action: you move the hand up to 30 feet. then, you can take the utilize action using the hand.
