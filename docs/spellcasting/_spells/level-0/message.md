### *Message*

| Transmutation Cantrip | *artificer, bard, druid, sorcerer, wizard* |
|---|---|
| components | s, m |
| cast time | full action |
| range | 120 feet |
| target | one creature |
| duration | - |

you point toward the target and whisper a message only it hears. the target can reply in a whisper only you hear.

this spell ignores cover if you know the target's location. this spell is blocked by magical silence; 1 foot of stone, metal, or wood; or a thin sheet of lead.
