### *Spare the Dying*

| Necromancy Cantrip | *artificer, cleric, druid* |
|---|---|
| components | v, s |
| cast time | full action |
| range | 15 feet |
| target | one downed creature |
| duration | - |

the target becomes stabilized.

**At Higher Levels:** double the range at levels 5, 11, and 17.
