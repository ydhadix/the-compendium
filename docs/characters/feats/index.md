# Feats

Feats represent specialized training and talents beyond your class and background, acquired at certain character levels.

| | |
|---|---|
| [Origin Feats](origin.md) | Feats available to any character at creation, tied to their origin. |
| [Racial Feats](racial.md) | Feats tied to your racial heritage and ancestry. |
| [Fighting Styles](fighting-style.md) | Combat techniques available to martially-trained characters. |
| [General Feats](general.md) | Broad feats available to any character meeting the prerequisites. |
| [Dragonmark Boons](dragonmarks.md) | Magical boons tied to the dragonmarks of the great houses. |
