# The Compendium
The Compendium is a collection of Tabletop RPG rules inspired by, but not directly compatible with, 5e Dungeons & Dragons.  The site describes the complete rules of play, as well as records of campaigns and characters played using these rules.
{ .subtitle }

| Section | Description |
|---|---|
| [Rules Rolodex](rules/index.md) | Every core rule in one place. |
| [Hero Handbook](character/index.md) | Everything that makes a character who they are. |
| [Item Index](item/index.md) | Everything a character can carry, wear, wield, or spend. |
| [Spell Selection](spell/index.md) | How to gain and cast magical spells. |
| [Bastion Blueprints](bastion/index.md) | Create a character's personal stronghold. |
| [Spelljammer Schematics](spelljammer/index.md) | Sailing magical ships through the Astral Sea. |
| [The Archive](archive/index.md) | Records of previous campaigns and the characters that played in them. |
