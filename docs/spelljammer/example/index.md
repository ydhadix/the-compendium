# Example Ships
Ready-to-use Ship profiles for reference during play.
{ .subtitle }

A Ship's stat block lists its size, maneuverability, hull, and capacity for Components. Some Ships come with specific Components; these don't count against the Ship's Component limits.

### Hammerhead
A robust Ship that prefers to Ram its opponents.
{ .subtitle }

| Weight | heavy |

| DT | 15 |
| Hull Points | 350 |
| Keel Points | 70 |
| Components | Pilot 2, Quartermaster 3, Spelljammer 1 |

**Standard.** No additional traits.

#### Hammer Ram
Pilot Component
{ .subtitle }

A wide, rectangular ram protrudes from the Ship's bow.

| AC | DT | HP | KP | Range | Attack |
|---|---|---|---|---|---|
| 20 | 10 | 100 | — | Close | special |

**Standard.** When you Ram, your Size Penalty doesn't apply to the Piloting check, and this Ram takes the damage instead of your hull.
