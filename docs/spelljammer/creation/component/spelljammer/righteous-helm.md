### Righteous Helm
Spelljammer Helm
{ .subtitle }

| | |
|---|---|
| Protocols | Eldritch Blaster, Targeting System, Warding Field, plus **2** others. |

Before your Ship deals Damage, you can expend a Spell Slot to deal an additional **1d10** Radiant Damage, plus **1d10** for each Level of the Spell Slot expended.
