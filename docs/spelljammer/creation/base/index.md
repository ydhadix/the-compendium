# Ship Bases
Ship Bases are the framework for Astral Sea vessels, each with its own stat block, strengths, and role in a fleet.
{ .subtitle }

A Ship's stat block lists its size, maneuverability, hull, and capacity for Components. Some Ships come with specific Components already installed; these don't count against the Ship's Component limits.

| Ship | Description |
|---|---|
| [Sailing Ship](sailing-ship.md) | A standard, highly customizable spelljamming vessel. |
| [Wasp](wasp.md) | A lightweight ship ideal for smaller crews. |
| [Hammerhead](hammerhead.md) | A rugged mercenary ship built to ram enemies. |
| [Skyliner](skyliner.md) | A compact, agile ship that flies without a Quartermaster. |
