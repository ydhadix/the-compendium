# Ship Bases
Ship Bases are the framework for Astral Sea vessels, each with its own stat block, strengths, and role in a fleet.
{ .subtitle }

A Ship's stat block lists its size, maneuverability, hull, and capacity for Components. Some Ships come with specific Components already installed; these don't count against the Ship's Component limits.
