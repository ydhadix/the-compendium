# Pilot Components
Sails, rams, and thrusters that shape how a Ship moves and evades. Pilot Components belong to the Pilot.
{ .subtitle }

| Component | Description |
|---|---|
| [Afterburners](#afterburners) | Reserve thrusters that push your Ship to its limits. |
| [Hunter's Sails](#hunters-sails) | Sharp sails that catch the wind best when prey is near. |
| [Mirage Sails](#mirage-sails) | Color-shifting sails that leave afterimages of your Ship. |
| [Naval Ram](#naval-ram) | A thick, angled grate that protects the Ship's bow from collisions. |
| [Wake Breakers](#wake-breakers) | Hull nodes that disrupt nearby Ships' movement. |
