# Ship Types
Basic Ships stats to build from.
{ .subtitle }

A Ship's stat block lists its size, maneuverability, hull, and capacity for Components. Some Ships come with specific Components; these don't count against the Ship's Component limits.

| Ship | Description |
|---|---|
| [Sailing Ship](sailing-ship.md) | A standard, customizable spelljamming vessel. |
| [Wasp](wasp.md) | A lightweight Ship ideal for smaller crews. |
| [Hammerhead](hammerhead.md) | A robust mercenary Ship that prefers to Ram its opponents. |
| [Skyliner](skyliner.md) | A compact, agile Ship designed to operate without a Quartermaster or crew. |
