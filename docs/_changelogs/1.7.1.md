### Version 1.7.1
July 17, 2026
{ .subtitle }

##### General { data-search-exclude }
###### Updates { data-search-exclude }
- [Dispositions](/bestiary/index.md#disposition) are now canonically **Ally**, **Independent**, and **Enemy**.  Effects that used to use "friendly", "indifferent", "hostile", "willing", etc. now use one of these three; Allies are always willing, Combat begins when an Enemy is in an Encounter, and Independent creatures aren't your friend or foe.
- Fixed a formatting issue with nested stat blocks (e.g. [Naval Ram](/spelljammer/creation/component/pilot.md#naval-ram) inside the [Hammerhead](/spelljammer/creation/base/index.md#hammerhead) stat block).

##### Bestiary { data-search-exclude }
###### New { data-search-exclude }
- Added the [Creature Codex](/bestiary/index.md): rules for [NPCs](/bestiary/index.md#non-player-characters), [Character Traits](/bestiary/index.md#traits), and [Creature Types](/bestiary/type/index.md) have migrated out of the [Rules Rolodex](/rules/index.md).
- [Summon Stat Blocks](/bestiary/summon/index.md) have been migrated into the Bestiary.  Each stat block links back to the spell, feature, or item that summons it.

##### Spells { data-search-exclude }
###### New { data-search-exclude }
- Added [4th-Level Spells](/spell/level/4/index.md).
###### Updates { data-search-exclude }
- Some 4th-Level spells demoted to 3rd to maintain half-caster access: [Aura of Life](/spell/level/3/aura-of-life.md), [Aura of Purity](/spell/level/3/aura-of-purity.md), [Fabricate](/spell/level/3/fabricate.md), [Secret Chest](/spell/level/3/secret-chest.md), [Stone Shape](/spell/level/3/stone-shape.md), [Summon Construct](/spell/level/3/summon-construct.md)
