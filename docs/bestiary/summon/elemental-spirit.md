# Elemental Spirit
An **Elemental Spirit** is a Companion conjured by the [Summon Elemental](/spell/level/4/summon-elemental.md) spell.
{ .subtitle }

### Elemental Spirit: Air
Medium Elemental, Neutral
{ .subtitle }

| Defenses | | | |
|---|---|---|---|
| HP | (10 + CON) × Spell Level | **Hit Dice** | 1d10 per Spell Level |
| AC | 11 + DEX + PB + Spell Level | **DR** | — |
| Armor | Natural | **Resistance** | Lighting, Thunder |
| Protection | — | **Immunity** | Poison; Exhaustion, Sickness, Paralysis, Petrification |

| Abilities | | | | | |
|---|---|---|---|---|---|
| STR | +4 | **DEX** | +2 | **CON** | +3 |
| INT | -3 | **WIS** | +0 | **CHA** | +3 |

| Traits | |
|---|---|
| Languages | Primordial; Understands and speaks the Languages you know |
| Senses | Darkvision (60 ft.) |
| Speed | 40 ft., Hover 40 ft. |
| Reach | 5 ft. |

| Features | |
|---|---|
| Amorphous Form | The spirit can move through a space as narrow as **1** inch without expending extra movement _(Items the spirit is wearing or carrying do not gain this benefit)_.  |
| Multiattack | The spirit makes **Spell Level ÷ 2** attacks, rounded down. |

#### Actions
| Slam | Melee Attack |
|---|---|
| Range | Reach |
| Attack | **+your Spell Attack** to hit |
| Damage | **1d10 + STR + Spell Level** Lightning Damage |
