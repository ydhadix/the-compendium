# Bestiary by Creature Type
A Creature Type is a broad family a creature belongs to. Every creature has at least one creature type, and some have two.  Most creature types share common traits, and some features and spells single out specific types.
{ .subtitle }

| Creature Type | Description |
|---|---|
| [Aberration](aberration.md) | Alien horrors that violate the natural order. |
| [Beast](beast.md) | Natural animals, acting on instinct. |
| [Celestial](celestial.md) | Embodiments of virtue from the Upper Planes. |
| [Construct](construct.md) | Objects animated to serve a purpose. |
| [Dragon](dragon.md) | Ancient reptiles of immense power and pride. |
| [Elemental](elemental.md) | Beings of raw fire, water, earth, and air. |
| [Fey](fey.md) | Capricious creatures of the Feywild. |
| [Fiend](fiend.md) | Corrupt natives of the Lower Planes. |
| [Giant](giant.md) | Towering humanoids of the ancient world. |
| [Humanoid](humanoid.md) | The peoples who comprise a world's civilizations. |
| [Monstrosity](monstrosity.md) | Unnatural creatures of magic and myth. |
| [Ooze](ooze.md) | Amorphous masses with voracious appetites. |
| [Plant](plant.md) | Vegetal and fungal creatures given life. |
| [Undead](undead.md) | The dead returned to life. |
