##### Aether Cannon
5th-Level Evocation
{ .subtitle }

| | |
|---|---|
| Base Spell | _Fireball_ |
| Activation Time | Ship Action |
| Range | Close or Long |
| Target | A Ship |
| Duration | — |

###### Protocol Effect
You make a Ranged Spell Attack against thecs target.

| | |
|---|---|
| Hit | You deal **12d10** Force Damage. |
| Miss | You deal half as much damage. |

###### At Higher Levels
Add **2d10** damage per additional Spell Level.
