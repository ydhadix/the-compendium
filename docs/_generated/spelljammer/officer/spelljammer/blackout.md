##### Blackout
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Base Spell | _Darkness_ |
| Activation Time | Ship Action |
| Range | — |
| Target | Self |
| Duration | **1** Hour (Concentration) |

###### Protocol Effect
Your Ship's microgravity fills with darkness. Darkvision can't see through it, and nonmagical light can't illuminate it.
