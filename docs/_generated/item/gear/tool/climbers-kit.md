##### Climber's Kit
Tool, 25 gold
{ .subtitle }

A Climber's Kit includes boot tips, gloves, pitons, and a harness.

###### Anchor
Utilize Action
{ .subtitle }

You can anchor yourself in place. While anchored, you can't be moved more than **25** feet from the anchor point.

###### Unanchor
Bonus Action
{ .subtitle }

You can undo the anchor.
