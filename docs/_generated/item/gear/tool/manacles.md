##### Manacles
Tool, 2 gold
{ .subtitle }

A set of Manacles comes with a key used to lock or unlock them.

###### Bind
Utilize Action
{ .subtitle }

You can choose a Small or Medium Grappled, Incapacitated, or Restrained creature within Reach and make a DC **13** Precision Check.

| | |
|---|---|
| **Success** | You bind the target's hands. While bound, the target gains Disadvantage on Attack Rolls, can't provide Somatic Components, and is Restrained if the Manacles are attached to a Chain or hook that is fixed in place. |

###### Escape
Utilize Action
{ .subtitle }

A bound creature can make a DC **20** Precision Check.

| | |
|---|---|
| **Success** | The creature escapes. |

###### Break Free
Utilize Action
{ .subtitle }

A creature that can reach a bound target can make a DC **25** Athletics Check.

| | |
|---|---|
| **Success** | The Manacles are destroyed. |

###### Pick Lock
Utilize Action
{ .subtitle }

A creature without a key that can reach the Manacles can make a DC **20** Precision Check.

| | |
|---|---|
| **Success** | The creature chooses whether the Manacles are locked or unlocked. |
