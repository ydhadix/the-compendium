##### Alchemist's Fire
Potion, Consumable, 50 gold
{ .subtitle }

Alchemist's Fire comes in a Vial.

###### Throw
A Vial filled with Alchemist's Fire can be wielded as a Simple Melee Weapon with Thrown _(**20**/**60** feet)_.

| | |
|---|---|
| **Hit** | You deal **1d4** Fire Damage. The target starts Burning _(**1d4**)_. |

After the Attack, the Alchemist's Fire is consumed and the Vial is destroyed.
