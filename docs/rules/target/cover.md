# Cover
**Cover** is the protection a creature gains with an obstacle between itself and an attack.
{ .subtitle }

| Cover | Effect |
|---|---|
| Half Cover | Your Armor Class and Reflex Saves increase by **2**. |
| Three-Quarters Cover | Your Armor Class and Reflex Saves increase by **5**. |
| Full Cover | You can't be seen or targeted directly by Attacks or Spells, and you automatically succeed on Reflex Saves. |

There are three levels of Cover. If a target is behind multiple sources of Cover, only the strongest applies.

## Creatures and Objects as Cover
A creature or object between an effect's source and its target provides Cover to that target.  How much it provides depends on their Sizes.  A creature fills only part of its space, while an object fills its space more completely, so an object provides more Cover than a creature of the same Size.

| Target's Size, compared to the obstacle | Creature | Object |
|---|---|---|
| More than one Size larger | None | None |
| One Size larger | None | Half Cover |
| The same Size | Half Cover | Three-Quarters Cover |
| Smaller | Half Cover | Full Cover |
