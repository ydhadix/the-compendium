# Languages
Languages are the tongues a creature can speak, read, and understand, from the Common speech of the Material Plane to the exotic languages of distant worlds.
{ .subtitle }

### Standard Languages
Standard Languages are widespread on the Material Plane.

| Language | Typical Speakers |
|---|---|
| Common | anyone |
| Common Sign Language | anyone |
| Dwarvish | Dwarves |
| Elvish | Elves |
| Giant | Giants |
| Gnomish | Gnomes |
| Goblin | goblinoids |
| Halfling | Halflings |
| Orc | Orcs |

### Exotic Languages
Exotic Languages are less common on the Material Plane but more common on the Outer Planes.

| Language | Typical Speakers |
|---|---|
| Abyssal | demons |
| Celestial | Celestials |
| Deep Speech | Aberrations |
| Draconic | Dragons |
| Druidic | Druids |
| Infernal | devils |
| Primordial | Elementals |
| Sylvan | Fey |
| Thieves' Cant | Rogues |
| Undercommon | Underdark citizens |

### Other Languages
Other Languages exist, but knowledge of them is rare outside their native speakers.  Your background or experiences during an adventure may let you learn them.
