# Skills

A Skill is an area of training that most Ability Checks draw on. Each Skill has a default Ability, but circumstances can pair a Skill with a different Ability — such as using Strength instead of Charisma to intimidate a creature.

## Skill Proficiency
Proficiency in a Skill lets you add your Proficiency Bonus to [Ability Checks](../dice/check.md) that use it.

## Skills by Ability

| Ability | Skills |
|---|---|
| Strength | Athletics |
| Dexterity | Acrobatics, Precision, Stealth |
| Constitution | — |
| Intelligence | Arcana, History, Medicine, Nature, Religion |
| Wisdom | Insight, Perception, Survival |
| Charisma | Deception, Intimidation, Performance, Persuasion |
