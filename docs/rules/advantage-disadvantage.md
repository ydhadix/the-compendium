# Advantage & Disadvantage

Sometimes a dice roll is affected by advantage or disadvantage, reflecting a positive or negative circumstance.

If a roll has either factor, roll the dice twice. For advantage, use the higher total. For disadvantage, use the lower total.

## Rerolling

When a d20 roll has advantage or disadvantage and an effect lets you reroll or replace the roll, you choose one of the d20s to replace, not both.

## Stacking Advantages

Multiple sources of advantage or disadvantage don't stack with each other. If a roll has advantage or disadvantage multiple times, you still only roll the dice twice.

A roll can't have both advantage and disadvantage. If a roll would have both factors, count the number of effects giving advantage and the number of effects giving disadvantage.

If the number of advantage effects and disadvantage effects is the same, the roll has neither. Otherwise, the roll keeps whichever factor has the higher number and loses the other.
