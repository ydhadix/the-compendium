# Advantage / Disadvantage

Sometimes a Dice Roll has Advantage or Disadvantage, reflecting a favorable or unfavorable circumstance. Roll the dice twice: with Advantage, use the higher total; with Disadvantage, use the lower total.

## Stacking

Multiple sources of Advantage or Disadvantage don't stack — however many you have, you still roll only twice.

A roll can't have both Advantage and Disadvantage. If a roll would have both, count the effects granting each. If the counts are equal, the roll has neither. Otherwise, the roll keeps whichever side has more and loses the other.
