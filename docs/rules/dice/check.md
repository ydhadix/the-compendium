# Ability Checks
An **Ability Check** determines the outcome when you attempt something with a chance of failure _(other than an attack)_.
{ .subtitle }

## Making an Ability Check
#### 1. Declare the Ability Check.
Describe what you're attempting to do.

#### 2. Determine modifiers.
Abilities, Proficiency, and other effects can add bonuses, penalties, Advantage, or Disadvantage to the Ability Check.

#### 3. Determine if the Ability Check succeeds.
Roll the d20 and add your modifiers. If the total equals or exceeds the Difficulty Class, the Ability Check succeeds.

#### 4. Resolve the Ability Check's effects.
The effect that required the Ability Check, or the DM, determines what effects succeeding or failing has.

## Types of Ability Checks
Most Ability Checks involve some type of Proficiency; usually a Skill or Trade.

### Skills
**Skills** are areas of training that apply to Ability Checks.

Each Skill has a default Ability, but circumstances can pair a Skill with a different Ability — such as using Strength instead of Charisma to intimidate a creature.

| Ability | Skills |
|---|---|
| Strength | Athletics |
| Dexterity | Acrobatics, Precision, Stealth |
| Constitution | — |
| Intelligence | Arcana, History, Medicine, Nature, Religion |
| Wisdom | Insight, Perception, Survival |
| Charisma | Deception, Intimidation, Performance, Persuasion |

### Passive Checks
A **Passive Check** represents the average result of a repeated task, or lets the DM secretly resolve an Ability Check.  A Passive Check doesn't require a roll: your total is **10** plus every bonus that normally applies to the Ability Check.

If you have Advantage on the Ability Check, the Passive Check increases by **5**.  Likewise, if you have Disadvantage, it decreases by **5**.
