# Defenses
Defenses are the Traits that keep a creature alive — the numbers that set how hard it is to hit or hurt, and the tiers that blunt, avoid, or ignore an incoming effect.
{ .subtitle }

| Defense | Description |
|---|---|
| [Armor Class](armor-class.md) | The number an attack must reach to hit you. |
| [Hit Points](hit-point.md) | The harm you can take before you fall, plus Hit Dice. |
| [Damage Reduction](reduction.md) | A flat reduction to Physical Damage. |
| [Damage Threshold](threshold.md) | Ignore damage that doesn't below a set value. |
| [Evasion](evasion.md) | Half or no damage from effects resolved by a Save. |
| [Immunity](immunity.md) | A category of effect can't affect you at all. |
| [Protection](protection.md) | Advantage on rolls to resist a category of effect. |
| [Resistance](resistance.md) | Half damage from a category — usually a Damage Type. |
| [Vulnerability](vulnerability.md) | Double damage from a category. |
