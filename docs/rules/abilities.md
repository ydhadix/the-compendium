# Abilities

## The Six Abilities
| **Ability** | Description |
|---|---|
| **Strength** | physical might |
| **Dexterity** | accuracy, agility, and balance |
| **Constitution** | health and stamina |
| **Intelligence** | reasoning, learning, and memory |
| **Wisdom** | awareness, empathy, and mental fortitude |
| **Charisma** | confidence, poise, and charm |

## Starting Abilities
Your abilities start at 0, the aptitude of a typical human.  When you create your character, choose four abilities to increase by 1 each.

## Ability Uses

Each ability governs different aspects of your character.

| ability | uses |
|---|---|
| strength | melee attacks, heavy armor, damage reduction, carrying capacity |
| dexterity | ranged attacks, light armor, initiative, reflex saves |
| constitution | hit points, fortitude saves |
| intelligence | spellcasting, learning and recalling information, additional proficiencies |
| wisdom | spellcasting, will saves, observing surroundings |
| charisma | spellcasting, influencing others |
| all | assorted features |

## Additional Proficiencies

You learn additional proficiencies and languages based on your Intelligence. If your Intelligence decreases, you don't lose any learned proficiencies, but you also don't learn more until your Intelligence exceeds the highest Intelligence you've gained a proficiency from.

If you would learn a skill proficiency, you can learn a trade or language instead.

If you would learn an expertise, you can learn a skill, trade, or language instead.

| intelligence | proficiency |
|---|---|
| 1 | one trade proficiency or language |
| 2 | one skill proficiency |
| 3 | one trade proficiency or language |
| 4 | expertise in a skill you're proficient with |
| 5 | one trade proficiency or language |
| 6 | one skill proficiency |
| 7 | expertise in a skill you're proficient with |
| 8 | one skill proficiency |
| 9 | one skill proficiency |
| 10+ | expertise in a skill you're proficient with |
