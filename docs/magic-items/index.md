## Magic Item Rules

## Using Magic Items

Using a magic item usually requires wearing or wielding it properly. The type of item determines how it should be worn, and how many of an item type you can wear at one time.

| Item Type | Usage | Limit |
|---|---|---|
| armor | donned | one |
| focus | held in hand | one per hand |
| potion | held in hand | - |
| scroll | held in hand | - |
| shield | donned | one |
| weapon | held in hand | one per hand |
| wondrous item | varies | - |
| **Clothing** | | |
| boots | on feet | one pair |
| bracers | on forearm | one pair |
| cloak | on shoulders | one |
| clothes | on body | one set |
| gloves | on hands | one pair |
| hat | on head | one |
| jewelry | varies | - |

## Keyword Properties

Many magic items share properties in common. The following table describes the most common ones.

| Property | Effect |
|---|---|
| attunement | the item requires attunement to use its magical properties. |
| charges | the item has charges that must be expended to use other properties. |
| command word | the item requires audibly speaking a short word or phrase to use other properties. |
| consumable | the item loses its magic after being used. |
| cursed | the item has a hidden, detrimental effect. most methods of identifying items don't reveal this effect. you can't voluntarily end your attunement to a cursed item. |
| spellcasting | the item can be used to cast spells. spells cast this way don't require spell slots or components but otherwise follow the normal rules for casting a spell. |
| spell effect | the item replicates the effect of a spell using the spell's description and duration but is not considered a spell. |

## Identification

Some magic items are indistinguishable from their nonmagical counterparts, while others are obviously magical.

The Identify spell is the fastest way to reveal an item's properties.

Wearing or attempting to use an item can also offer hints about its properties. In the specific case of Potions, a little taste is enough to tell the taster what a potion does.

Alternatively, you can focus on one magic item during a Short Rest while remaining in physical contact with the item. At the end of the rest, you learn the item's properties and how to use them.

## Attunement

Some magic items require a special bond — called Attunement — before you can use their magical properties.

#### Becoming Attuned

Attuning to an item requires you spend a Short Rest focused on only that item while being in physical contact with it. This can't be the same Short Rest used to identify the item.

When you finish the Short Rest, you become attuned to the item and can use its full magical capabilities.

#### Attunement Slots

You can be attuned to no more than three magic items at a time. Any attempt to attune to a fourth item fails; you must end one of your attunements first.

#### Ending Attunement

You can voluntarily end Attunement by spending another Short Rest focused on the item (unless the item is cursed).

Your attunement also ends if any of these conditions are met:

- The item is more than 100 feet away from you for 24 hours.
- Another creature attunes to the item.
- You die.
