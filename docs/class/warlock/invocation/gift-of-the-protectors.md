##### Gift of the Protectors
Prerequisite: Warlock 7, Pact of the Tome
{ .subtitle }

When you summon your Book of Shadows, a new page appears. It can hold a number of names equal to your Warlock Ability (minimum **1**), and a creature can write only its own name on it. You can erase a name by touching it.

###### Guardian's Ward
1 use per Long Rest
{ .subtitle }

Before a creature whose name is on the page would drop to **0** Hit Points or be killed, you can instead make it drop to **1** Hit Point.
