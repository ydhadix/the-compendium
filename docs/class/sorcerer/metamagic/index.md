# Metamagic

A Sorcerer bends their Spells with Metamagic, spending Sorcery Points to reshape a Spell as they cast it. Only one Metamagic can be applied to a Spell, unless a Metamagic says otherwise.

| Metamagic | Description |
|---|---|
| [Careful Spell](#careful-spell) | Shield chosen creatures from the Spell. |
| [Distant Spell](#distant-spell) | Double the Spell's Range. |
| [Empowered Spell](#empowered-spell) | Reroll low Damage Dice. |
| [Extended Spell](#extended-spell) | Double the Spell's Duration. |
| [Heightened Spell](#heightened-spell) | Give a Target Disadvantage on its Saving Throws. |
| [Quickened Spell](#quickened-spell) | Cast the Spell as a Bonus Action. |
| [Seeking Spell](#seeking-spell) | Reroll a missed Attack Roll. |
| [Subtle Spell](#subtle-spell) | Cast the Spell without Components. |
| [Transmuted Spell](#transmuted-spell) | Change the Spell's Elemental Damage Type. |
| [Twinned Spell](#twinned-spell) | Add a second Target to the Spell. |
