### Lantern of the Frost Watch
Rare Wondrous Item (Hooded Lantern)
{ .subtitle }

#### Command Word
Magic Action
{ .subtitle }

You can speak one of the following Command Words to use its effect:

##### Aduro
This lantern's flame is ignited or extinguished.

##### Calidum
1 use per Day
{ .subtitle }

This lantern's flame glows orange for up to **10** minutes.  While glowing, everything within the lantern's Bright Light gains Cold Resistance.

##### Micare
1 use per Day
{ .subtitle }

This lantern's flame glows impossibly bright.  Each other creature that can see the lantern makes a Fortitude Save _(DC **15**)_.

| | |
|---|---|
| Fail | You deal **4d6** Radiant Damage to the target. |
| Success | You deal half as much damage. |

##### Revelare
1 use per Day
{ .subtitle }

This lantern's flame glows green for up to **10** minutes.  While glowing, every magical effect within the lantern's Bright Light is outlined with a faint glow, and magical darkness and fog within the Bright Light are suppressed.

##### Vide
1 use per Day
{ .subtitle }

This lantern's flame glows magenta for up to **10** minutes.  While glowing, creatures within the lantern's Bright Light can't benefit from being Invisible, and are visible while on the Ethereal Plane _(ethereal creatures still can't be targeted)_.
