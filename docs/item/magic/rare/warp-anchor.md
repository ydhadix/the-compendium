### Warp Anchor
Rare Wondrous Item
{ .subtitle }

This pair of linked batons merge to form a complete rod.

#### Command Word
Magic Action
{ .subtitle }

You can speak one of the following Command Words to use its effect:

##### Split
You separate the rod into two batons.

##### Combine
You combine the two batons into a rod.

##### Return
1 use per Day
{ .subtitle }

While holding one of the separated batons, you teleport to within **5** feet of the other baton and combine them into a rod.

This effect can only regain uses while in rod form.
