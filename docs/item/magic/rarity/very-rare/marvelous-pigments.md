### Marvelous Pigments
Very Rare Wondrous Item, Consumable
{ .subtitle }

**1d4** uses
{ .subtitle }

##### Paint
10 minutes, 1 use
{ .subtitle }

You can paint any number of three-dimensional objects and terrain features confined to a **20**-foot Cube, which become real.  This requires Concentration, and you must remain in the Cube; otherwise the painted elements vanish and the use is wasted.

No painted object can be worth more than **25** gold, and the total worth of one use can't exceed **500** gold.  More valuable objects look authentic, but close inspection reveals worthless material.  Painted energy dissipates harmlessly as soon as you finish.
