### Staff of the Woodlands
Very Rare Weapon (Staff), Attunement (Druid)
{ .subtitle }

**6** Charges (regain **1d6** per Day)
{ .subtitle }

##### Cast
You can cast the following Spells:

| Spell | Action | Charges |
|---|---|---|
| _Animal Friendship_ | Magic Action | **1** Charge |
| _Speak with Animals_ | Magic Action | **1** Charge |
| _Barkskin_ | Magic Action | **2** Charges |
| _Locate Animals or Plants_ | Magic Action | **2** Charges |
| _Pass without Trace_ | Magic Action | **2** Charges |
| _Plant Growth_ | Magic Action, or **8** Hours | **3** Charges |
| _Speak with Plants_ | Magic Action | **3** Charges |
| _Awaken_ | Magic Action | **5** Charges |
| _Wall of Thorns_ | Magic Action | **6** Charges |

##### Tree Form
**Magic Action; 1 Charge:** You can plant one end of this staff in earth, transforming it into a tree **60** feet tall with a **5**-foot-diameter trunk and branches spreading in a **20**-foot radius.  While touching the tree, you can use this Action again to revert it, dropping any creature in it.
