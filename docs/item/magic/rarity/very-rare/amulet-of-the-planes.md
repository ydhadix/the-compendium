### Amulet of the Planes
Very Rare Clothing (Jewelry), Attunement
{ .subtitle }

##### Plane Shift
**Magic Action:** You can name a location you are familiar with on another plane and make an Arcana Check _(DC **17**)_.

| | |
|---|---|
| Success | You cast _Plane Shift_ to that location. |
| Fail | You and everything within **15** feet of you travel to a random destination.  Roll **1d100**. |

| 1d100 | Destination |
|---|---|
| 01–60 | A random location on the plane you named. |
| 61–80 | A random location on a random Inner Plane. |
| 81–95 | A random location on a random Outer Plane. |
| 96–00 | A random location on the Astral Plane. |
