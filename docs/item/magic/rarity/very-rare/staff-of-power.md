### Staff of Power
Very Rare Weapon (Staff), Attunement (Spellcaster)
{ .subtitle }

**20** Charges (regain **2d8 + 4** per Day)
{ .subtitle }

##### Cast
You can cast the following Spells:

| Spell | Action | Charges |
|---|---|---|
| _Magic Missile_ | Magic Action | **1** Charge |
| _Ray of Enfeeblement_ | Magic Action | **1** Charge |
| _Levitate_ | Magic Action | **2** Charges |
| _Cone of Cold_ | Magic Action | **5** Charges |
| _Fireball_ _(5th Level)_ | Magic Action | **5** Charges |
| _Hold Monster_ | Magic Action | **5** Charges |
| _Lightning Bolt_ _(5th Level)_ | Magic Action | **5** Charges |
| _Wall of Force_ | Magic Action | **5** Charges |
| _Globe of Invulnerability_ | Magic Action | **6** Charges |

##### Retributive Strike
Magic Action
{ .subtitle }

You can break this staff, destroying it and releasing its magic in a **30**-foot Aura originating from it.  Roll **1d10**; on a **5** or lower, you instantly travel to a random plane and avoid the explosion.  Otherwise, you take Force Damage equal to **16** times its remaining Charges.

Everything else in the Aura makes a Reflex Save _(DC **15**)_.

| | |
|---|---|
| Fail | You deal Force Damage to the target equal to **4** times the staff's remaining Charges. |
| Success | You deal half as much damage. |
