### Staff of Storms
Very Rare Weapon (Staff), Attunement (Spellcaster)
{ .subtitle }

**10** Charges (regain **1d6 + 4** per Day)
{ .subtitle }

Spells you cast add your Spellcasting Ability to Cold, Lightning, and Thunder Damage.

##### Cast
You can cast the following Spells:

| Spell | Action | Charges |
|---|---|---|
| _Fog Cloud_ | Magic Action | **1** Charge |
| _Thunderwave_ | Magic Action | **1** Charge |
| _Gust of Wind_ | Magic Action | **2** Charges |
| _Lightning Bolt_ | Magic Action | **3** Charges |
| _Sleet Storm_ | Magic Action | **3** Charges |
| _Wall of Wind_ | Magic Action | **3** Charges |
| _Ice Storm_ | Magic Action | **4** Charges |
| _Call Lightning_ (5th-Level) | Magic Action | **5** Charges |
