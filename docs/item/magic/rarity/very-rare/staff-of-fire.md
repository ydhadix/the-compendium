### Staff of Fire
Very Rare Weapon (Staff), Attunement (Spellcaster)
{ .subtitle }

**10** Charges (regain **1d6 + 4** per Day)
{ .subtitle }

You gain Fire Resistance.

##### Cast
You can cast the following Spells:

| Spell | Action | Charges |
|---|---|---|
| _Burning Hands_ | Magic Action | **1** Charge |
| _Fireball_ | Magic Action | **3** Charges |
| _Wall of Fire_ | Magic Action | **4** Charges |
