### Obsidian Steed Figurine
Very Rare Wondrous Item
{ .subtitle }

##### Summon Nightmare
Magic Action, 1 use per 5 Days
{ .subtitle }

You can throw the figurine to a point on the ground within **60** feet, where it transforms into a Companion Nightmare that fights only to defend itself.  It stays transformed for **24** hours, until it drops to **0** Hit Points, or until you use this Action again.

Then, roll **1d10**.  On a **1**, the nightmare becomes an Enemy and ignores your commands.  While you ride it, it instead transports you both to a random location on Hades, then reverts to figurine form.

###### Command
Free Action
{ .subtitle }

You can command the nightmare to move and take any Action available to it.
