### Instrument of Scribing
Common Wondrous Item
{ .subtitle }

##### Scribe
Magic Action, 3 uses per Day
{ .subtitle }

While you are playing this musical instrument, you write up to **6** words in a language you know on an object or surface within **30** feet. The words fade after **24** hours. If you are a Bard, you can write up to **7** additional words and can make the words glow slightly in nonmagical Darkness.
