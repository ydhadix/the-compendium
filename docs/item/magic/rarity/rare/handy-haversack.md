### Handy Haversack
Rare Container (Backpack)
{ .subtitle }

This backpack has a central pouch holding up to **500** pounds and two side pouches each holding up to **200** pounds, and always weighs **5** pounds.  Each pouch holds enough air for **10** minutes of breathing, divided by the number of breathing creatures inside.

##### Retrieve
Bonus Action or Utilize Action
{ .subtitle }

You can reach into the haversack for a specific item, which is always on top.
