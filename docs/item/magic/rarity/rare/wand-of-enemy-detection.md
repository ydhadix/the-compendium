### Wand of Enemy Detection
Rare Spellcasting Focus (Arcane Focus), Attunement
{ .subtitle }

**7** Charges (regain **1d6 + 1** per Day)
{ .subtitle }

##### Detect Enemies
Magic Action, 1 Charge
{ .subtitle }

While holding this wand, you know the direction of the nearest Enemy within **60** feet for **1** minute, but not its distance.  This wand senses Enemies that are Invisible, ethereal, disguised, or Hidden.
