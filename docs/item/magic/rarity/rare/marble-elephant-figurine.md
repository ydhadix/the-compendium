### Marble Elephant Figurine
Rare Wondrous Item
{ .subtitle }

##### Summon Elephant
Magic Action, 1 use per 7 Days
{ .subtitle }

You can throw the figurine to a point on the ground within **60** feet, where it transforms into a Companion Elephant.  It stays transformed for **24 hours**, until it drops to **0** Hit Points, or until you use this Action again.

###### Command
Free Action
{ .subtitle }

You can command the elephant to move and take any Action available to it.
