### Onyx Dog Figurine
Rare Wondrous Item
{ .subtitle }

##### Summon Mastiff
Magic Action, 1 use per 7 Days
{ .subtitle }

You can throw the figurine to a point on the ground within **60** feet, where it transforms into a Companion Mastiff.  It stays transformed for **6 hours**, until it drops to **0** Hit Points, or until you use this Action again.  The mastiff has an Intelligence of **-1**, speaks Common, and has **60** feet of Blindsight.

###### Command
Free Action
{ .subtitle }

You can command the mastiff to move and take any Action available to it.
