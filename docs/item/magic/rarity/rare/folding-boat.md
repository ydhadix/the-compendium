### Folding Boat
Rare Container (Box)
{ .subtitle }

This box floats and can store items inside.  While unfolded, it weighs as much as a normal vessel its size and keeps anything stored in it.

#### Command Word
Magic Action
{ .subtitle }

You can speak one of this item's three Command Words.

##### Rowboat
The box unfolds into a Rowboat.

##### Keelboat
The box unfolds into a Keelboat.

##### Fold
Provided no creature is aboard, the vessel folds back into a box.  Objects too large to fit inside remain outside it.

---

If either vessel drops to **0** Hit Points, this item is destroyed.
