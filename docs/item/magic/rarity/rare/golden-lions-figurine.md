### Golden Lions Figurine
Rare Wondrous Item
{ .subtitle }

These figurines are always created in pairs, and each is summoned separately.

##### Summon Lion
Magic Action, 1 use per 7 Days
{ .subtitle }

You can throw one figurine to a point on the ground within **60** feet, where it transforms into a Companion Lion.  It stays transformed for **1** hour, until it drops to **0** Hit Points, or until you use this Action again.

###### Command
Free Action
{ .subtitle }

You can command the lion to move and take any Action available to it.
