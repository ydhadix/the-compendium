### Golden Lions Figurine
Rare Wondrous Item
{ .subtitle }

These figurines are always created in pairs, and each is summoned separately.

##### Summon Lion
**Magic Action; Once per 7 Days:** You can throw one figurine to a point on the ground within **60** feet, where it transforms into a Lion Companion.  It stays transformed for **1** hour, until it drops to **0** Hit Points, or until you use this Action again.

###### Command
**Free Action:** You can command the lion to move and take any Action available to it.
