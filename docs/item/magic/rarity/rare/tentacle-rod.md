### Tentacle Rod
Rare Spellcasting Focus (Arcane Focus), Attunement
{ .subtitle }

##### Lash
Magic Action
{ .subtitle }

You can direct this rod's three tentacles to each Attack a creature within **15** feet, making a Melee Attack Roll _(**+7** to hit)_ for each.

| | |
|---|---|
| Hit | You deal **1d6** Psychic Damage. |

After all three tentacles hit the same target, it makes a Reflex Save _(DC **15**)_.

| | |
|---|---|
| Fail | You Restrain the target, dealing **3d6** Psychic Damage to it at the start of each of its Turns. |
| Success | No effect. |

This effect ends after you become Incapacitated, after you release the target as a Bonus Action, or after the target is more than **15** feet from you.

Before each of the target's Turns ends, it repeats this Saving Throw.  On a success, this effect ends on the target.
