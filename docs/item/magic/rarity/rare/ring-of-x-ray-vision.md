### Ring of X-ray Vision
Rare Clothing (Jewelry), Attunement
{ .subtitle }

##### See Through
Magic Action
{ .subtitle }

Solid objects within **30** feet of you become transparent to you for **1** minute.  This vision penetrates **1** foot of stone, **1** inch of common metal, or **3** feet of wood or dirt.  Thicker substances and lead block it.

After you use this Action again before finishing a Long Rest, you make a Fortitude Save _(DC **15**)_.

| | |
|---|---|
| Fail | You gain **1** Exhaustion level. |
| Success | No effect. |
