### Cube of Force
Rare Wondrous Item, Attunement
{ .subtitle }

**10** Charges (regain **1d6** per Day)
{ .subtitle }

Each face of this cube bears a distinct marking.

##### Cast
**Magic Action:** You can press a face to cast **1** of the following Spells _(DC **15**)_:

| Spell | Charges |
|---|---|
| _Mage Armor_ | **1** Charge |
| _Shield_ | **1** Charge |
| _Tiny Hut_ | **3** Charges |
| _Private Sanctum_ | **4** Charges |
| _Resilient Sphere_ | **4** Charges |
| _Wall of Force_ | **5** Charges |
