### Dimensional Shackles
Rare Wondrous Item
{ .subtitle }

##### Shackle
Utilize Action
{ .subtitle }

You can place these shackles on an Incapacitated creature from Small to Large.  The target can't teleport or travel to another plane, but can still pass through an interdimensional portal.

You and any creature you designate can use this Action to remove the shackles.

###### Break Free
Utilize Action, 1 use per 30 Days
{ .subtitle }

A shackled creature can make an Athletics Check _(DC **30**)_.  On a success, it breaks free and destroys the shackles.
