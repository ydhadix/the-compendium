### Engineer's Greatcoat
Rare Clothing (Cloak)
{ .subtitle }

You can target objects and Constructs with healing Spells.

##### Conjure Tools
**Utilize Action:** You can conjure a set of Artisan's Tools from the greatcoat.  The tools remain until you pull another tool from the greatcoat, until they're more than **15** feet away from you, or until you remove the greatcoat.  If you have Proficiency with a set of tools pulled from the greatcoat, you make Checks with them as though you had Expertise.
