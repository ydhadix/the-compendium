### Warp Anchor
Rare Wondrous Item
{ .subtitle }

This pair of linked batons merges into a complete rod.

##### Command Word
**Magic Action:** You can speak **1** of the following Command Words to use its effect.

| Command | |
|---|---|
| Split | You separate the rod into **2** batons. |
| Combine | You combine the **2** batons into a rod. |
| Return | **Once per Day:** While holding one of the separated batons, you teleport to within **5** feet of the other baton and combine them into a rod.  This effect only regains uses while in rod form. |
