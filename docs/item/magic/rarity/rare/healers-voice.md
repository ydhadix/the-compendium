### Healer's Voice
Rare Clothing (Jewelry)
{ .subtitle }

##### Healing Voice
Free Action
{ .subtitle }

Before you roll a **1** to heal a target using _Healing Word_ or _Mass Healing Word_, you can reroll the die.

##### Shielding Voice
Free Action
{ .subtitle }

After you cast _Healing Word_ or _Mass Healing Word_, choose **1** of the spell's targets.  The target gains **4** Temporary Hit Points for each **4** you rolled on a die to heal it.

##### Soothing Voice
Free Action
{ .subtitle }

Before you make an Ability Check to calm, heal, or otherwise soothe another creature, you can add **1d4** to the Ability Check.  You can't use this property again until you cast _Healing Word_ or _Mass Healing Word_.
