### Nine Lives Stealer
Rare Weapon (Any), Attunement
{ .subtitle }

**1d8 + 1** uses
{ .subtitle }

##### Life Steal
Free Action
{ .subtitle }

After you score a Critical Hit against a creature that has fewer than **100** Hit Points and isn't a Construct or Undead with this weapon, the target makes a Fortitude Save _(DC **15**)_.

| | |
|---|---|
| Fail | The target dies, and you expend **1** use. |
| Success | No effect. |

After this item's last use is expended, it loses this effect.
