### Nine Lives Stealer
Rare Weapon (Any), Attunement
{ .subtitle }

**1d8 + 1** uses
{ .subtitle }

After you score a Critical Hit with this weapon against a creature that has fewer than **100** Hit Points and isn't a Construct or Undead, the target makes a Fortitude Save _(DC **15**)_.

| | |
|---|---|
| Fail | The target dies, and you expend **1** use. |
| Success | No effect. |

After this item's last use is expended, it loses this effect.
