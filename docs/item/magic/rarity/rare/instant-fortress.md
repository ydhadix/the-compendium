### Instant Fortress
Rare Wondrous Item, Attunement
{ .subtitle }

##### Raise Tower
Magic Action
{ .subtitle }

You can place this statuette on the ground, growing it into an adamantine tower **20** feet on a side and **30** feet high, with arrow slits, a battlement, two floors, and a single door facing you.  You can use this Action again to revert the tower, provided it is empty.

Everything in the tower's area is propelled to the nearest unoccupied space outside it.

The roof, door, and walls each have Armor Class **20**, **100** Hit Points, Bludgeoning, Piercing, and Slashing Immunity except from siege equipment, and Resistance to all other damage.  Reverting the tower doesn't repair it.

###### Open Door
Bonus Action
{ .subtitle }

You can open or close the tower's door.  It has Immunity to _Knock_ and similar magic.
