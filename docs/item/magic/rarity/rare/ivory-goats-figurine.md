### Ivory Goats Figurine
Rare Wondrous Item
{ .subtitle }

These figurines are always created in sets of three, and each is summoned separately.

##### Summon Goat
Magic Action
{ .subtitle }

You can throw one figurine to a point on the ground within **60** feet, where it transforms into the Companion creature on its row of the table below.  It stays transformed for the listed duration, until it drops to **0** Hit Points, or until you use this Action again.

###### Command
Free Action
{ .subtitle }

You can command the goat to move and take any Action available to it.

##### Terror
The Goat of Terror can't Attack.  While you ride it, each Enemy that starts its Turn in a **30**-foot Aura originating from the goat makes a Will Save _(DC **15**)_.

| | |
|---|---|
| Fail | You frighten the target for **1** minute, until you stop riding the goat, or until the goat reverts. |
| Success | The target gains Immunity to this effect for **24** hours. |

Before each of the target's Turns ends, it repeats this Saving Throw.  On a success, this effect ends on the target.

###### Remove Horn
Magic Action
{ .subtitle }

You can harmlessly remove one of the goat's horns, which becomes a Polearm or a Blade until the goat reverts.
