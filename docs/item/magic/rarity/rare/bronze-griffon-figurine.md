### Bronze Griffon Figurine
Rare Wondrous Item
{ .subtitle }

##### Summon Griffon
Magic Action, 1 use per 5 Days
{ .subtitle }

You can throw the figurine to a point on the ground within **60** feet, where it transforms into a Companion Griffon.  It stays transformed for **6 hours**, until it drops to **0** Hit Points, or until you use this Action again.

###### Command
Free Action
{ .subtitle }

You can command the griffon to move and take any Action available to it.
