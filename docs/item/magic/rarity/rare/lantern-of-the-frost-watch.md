### Lantern of the Frost Watch
Rare Wondrous Item (Hooded Lantern)
{ .subtitle }

##### Command Word
**Magic Action:** You can speak **1** of the following Command Words to use its effect.

| Command | |
|---|---|
| Aduro | You ignite or extinguish this lantern's flame. |
| Calidum | **Once per Day:** This lantern's flame glows orange for up to **10** minutes.  While glowing, everything within the lantern's Bright Light gains Cold Resistance. |
| Micare | **Once per Day:** This lantern's flame glows impossibly bright.  Each other creature that can see the lantern makes a Fortitude Save _(DC **15**)_.<br>**Fail.** You deal **4d6** Radiant Damage to the target.<br>**Success.** You deal half as much damage. |
| Revelare | **Once per Day:** This lantern's flame glows green for up to **10** minutes.  While glowing, every magical effect within the lantern's Bright Light is outlined with a faint glow, and magical darkness and fog within the Bright Light are suppressed. |
| Vide | **Once per Day:** This lantern's flame glows magenta for up to **10** minutes.  While glowing, creatures within the lantern's Bright Light can't benefit from being Invisible, and are visible while on the Ethereal Plane _(ethereal creatures still can't be targeted)_. |
