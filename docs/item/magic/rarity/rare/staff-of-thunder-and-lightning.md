### Staff of Thunder and Lightning
Rare Weapon (Staff), Attunement
{ .subtitle }

##### Lightning
Free Action, 1 use per Day
{ .subtitle }

After you hit with a Melee Attack using this weapon, you can deal an additional **2d6** Lightning Damage to the target.

##### Thunder
Free Action, 1 use per Day
{ .subtitle }

After you hit with a Melee Attack using this weapon, you can emit a crack of thunder audible out to **300** feet.  The target makes a Fortitude Save _(DC **15**)_.

| | |
|---|---|
| Fail | The target is Stunned until the end of your next Turn. |
| Success | No effect. |

##### Thunder and Lightning
Bonus Action, 1 use per Day
{ .subtitle }

After you hit with a Melee Attack using this weapon, you can use Lightning and Thunder at the same time without expending their uses.

##### Lightning Strike
Magic Action, 1 use per Day
{ .subtitle }

You can leap a bolt of lightning from this weapon in a **120**-foot × **5**-foot Line.  Everything in the Line makes a Reflex Save _(DC **15**)_.

| | |
|---|---|
| Fail | You deal **9d6** Lightning Damage to the target. |
| Success | You deal half as much damage. |

##### Thunderclap
Magic Action, 1 use per Day
{ .subtitle }

You can produce a thunderclap audible out to **600** feet.  Everything in a **60**-foot Aura makes a Fortitude Save _(DC **15**)_.

| | |
|---|---|
| Fail | You deal **2d6** Thunder Damage to the target and deafen it for **1** minute. |
| Success | You deal half as much damage. |
