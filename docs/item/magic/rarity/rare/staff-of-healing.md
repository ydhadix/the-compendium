### Staff of Healing
Rare Weapon (Staff), Attunement (Spellcaster)
{ .subtitle }

**10** Charges (regain **1d6 + 4** per Day)
{ .subtitle }

##### Cast
You can cast the following Spells:

| Spell | Action | Charges |
|---|---|---|
| _Cure Wounds_ | Magic Action | **1** or more Charges |
| _Lesser Restoration_ | Magic Action | **2** Charges |
| _Mass Cure Wounds_ | Magic Action | **5** Charges |

_Cure Wounds_ costs **1** Charge per Spell Level, to a maximum of **4**.
