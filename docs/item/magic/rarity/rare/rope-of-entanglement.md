### Rope of Entanglement
Rare Wondrous Item
{ .subtitle }

This rope is **30** feet long, and has Armor Class **20**, **20** Hit Points, and Poison and Psychic Immunity.  It heals by **1** every **5** minutes while it has at least **1** Hit Point, and is destroyed at **0** Hit Points.

##### Entangle
Magic Action
{ .subtitle }

While holding one end, you can command the other end to entangle one creature within **20** feet.  The target makes a Reflex Save _(DC **15**)_.

| | |
|---|---|
| Fail | You Restrain the target. |
| Success | No effect. |

###### Escape
Utilize Action
{ .subtitle }

A Restrained creature can make an Athletics or Acrobatics Check _(DC **15**)_.  On a success, this effect ends on it.

###### Release
Bonus Action
{ .subtitle }

You can release the target, coiling the rope in your hand.  Letting go of your end instead coils the rope in the target's space.
