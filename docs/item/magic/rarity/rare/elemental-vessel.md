### Elemental Vessel
Rare Wondrous Item
{ .subtitle }

Each Elemental Vessel has an Elemental Type.

##### Summon Elemental
Magic Action, 1 use per Day
{ .subtitle }

While you are within **5** feet of the vessel, you can summon a Companion Elemental of the vessel's Elemental Type in the nearest unoccupied space.  It disappears after **1** hour, after it drops to **0** Hit Points, or after you dismiss it.

###### Command
Free Action
{ .subtitle }

You can command the elemental to move and take any Action available to it, or dismiss it.
