### Ebony Fly Figurine
Rare Wondrous Item
{ .subtitle }

##### Summon Giant Fly
Magic Action, 1 use per 2 Days
{ .subtitle }

You can throw the figurine to a point on the ground within **60** feet, where it transforms into a Companion Giant Fly.  It stays transformed for **12 hours**, until it drops to **0** Hit Points, or until you use this Action again.  You can ride the fly as a mount.

###### Command
Free Action
{ .subtitle }

You can command the fly to move and take any Action available to it.
