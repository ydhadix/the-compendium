### Elemental Gem
Uncommon Wondrous Item, Consumable
{ .subtitle }

This item contains a mote of elemental energy.  The gemstone determines the type of Elemental.

##### Release
Utilize Action
{ .subtitle }

You can destroy the item, summoning its contained Companion Elemental.  The elemental disappears after **1 hour** or after the elemental drops to **0** Hit Points.

###### Command
Free Action
{ .subtitle }

You can command the elemental to move and take any Action available to it.

---

#### Variants

| Gemstone | Elemental |
|---|---|
| Blue Sapphire | Air Elemental |
| Emerald | Water Elemental |
| Red Corundum | Fire Elemental |
| Yellow Diamond | Earth Elemental |
