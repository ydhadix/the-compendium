### Alchemy Jug
Uncommon Wondrous Item
{ .subtitle }

##### Name Liquid
**Magic Action; Once per Day:** You can choose **1** of the following liquids for this item's Pour property.

| Liquid | Maximum |
|---|---|
| Acid | **8** ounces |
| Basic Poison | **4** ounces |
| Beer | **4** gallons |
| Honey | **1** gallon |
| Mayonnaise | **2** gallons |
| Oil | **1** quart |
| Vinegar | **2** gallons |
| Fresh Water | **8** gallons |
| Salt Water | **12** gallons |
| Wine | **1** gallon |

##### Pour
**Utilize Action:** You can pour out up to **2** gallons per minute of the named liquid, up to its Maximum.
