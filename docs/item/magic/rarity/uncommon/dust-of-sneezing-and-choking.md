### Dust of Sneezing and Choking
Uncommon Wondrous Item, Consumable
{ .subtitle }

This dust resembles Dust of Disappearance.  _Identify_ reveals its true nature.

#### Scatter Dust
Utilize Action
{ .subtitle }

You can throw the dust into the air; you and every creature in a **30**-foot Aura make a Fortitude Save _(DC **13**)_. Constructs, Elementals, Oozes, Plants, and Undead automatically succeed.

| | |
|---|---|
| Fail | The target is Incapacitated and begins suffocating. |
| Success | No effect. |

Before each of the target's Turns ends, it repeats this Saving Throw.  On a success, this effect ends on the target.  _Lesser Restoration_ also ends this effect.
