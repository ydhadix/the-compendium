### Fan Token
Uncommon Wondrous Item, Consumable
{ .subtitle }

##### Summon Fan
**Utilize Action:** While on a boat or ship, you can toss this token up to **10** feet into the air, destroying it and summoning a giant flapping fan.  The fan fills the sails with wind, increasing the vessel's speed by **5** miles per hour for **8** hours.

###### Command
**Free Action:** You can command the fan to stop spinning, resume spinning, or vanish.
