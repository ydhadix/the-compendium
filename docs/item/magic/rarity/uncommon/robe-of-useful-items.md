### Robe of Useful Items
Uncommon Clothing (Clothes)
{ .subtitle }

##### Detach Patch
**Magic Action:** You can detach one of the robe's cloth patches, transforming it into the object it represents. Once the last patch is removed, the robe becomes an ordinary garment. The robe starts with **2** of each of the following patches, plus **4d4** more determined by the DM:

- Bullseye Lantern (filled and lit)
- Dagger
- Mirror
- Pole
- Rope (coiled)
- Sack
