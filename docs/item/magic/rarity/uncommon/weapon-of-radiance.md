### Weapon of Radiance
Uncommon Weapon (Any), Attunement
{ .subtitle }

**4** Charges (regain **1d4** per Day)
{ .subtitle }

##### Illuminate
Bonus Action
{ .subtitle }

This item emits light as the _Light_ Spell.

##### Flash
Reaction, 1 Charge
{ .subtitle }

Before you are attacked, you can make the attacker make a Fortitude Save _(DC **13**)_.

| | |
|---|---|
| Fail | You blind the attacker until the end of its next Turn. |
| Success | No effect. |
