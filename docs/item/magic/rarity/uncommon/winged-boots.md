### Winged Boots
Uncommon Clothing (Boots), Attunement
{ .subtitle }

**4** Charges (regain **1d4** per Day)
{ .subtitle }

##### Take Flight
Magic Action, 1 Charge
{ .subtitle }

You gain a **30**-foot Fly Speed for **1** hour. After it ends, if you are still aloft, you gain Falling Immunity and before your Turn ends, you descend **30** feet until you land.
