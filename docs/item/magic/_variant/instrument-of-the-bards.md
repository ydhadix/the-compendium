This instrument comes in several types, each named for a bard college.  The college determines this item's rarity, Spell Save DC, and the spells it can cast.

A creature that plays this instrument without being Attuned makes a Will Save against this item's DC.

| | |
|---|---|
| Fail | The instrument deals **2d4** Psychic Damage to the creature. |

##### Cast
Magic Action, 1 use each per Day
{ .subtitle }

You can play the instrument to cast one of its Spells.
