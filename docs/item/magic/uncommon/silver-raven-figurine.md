### Silver Raven Figurine
Uncommon Wondrous Item
{ .subtitle }

#### Summon Raven
Magic Action, 1 use per 2 Days
{ .subtitle }

You can throw the figurine to a point on the ground within **60** feet, where it transforms into a Companion Raven.  It stays transformed for **12** hours, until it drops to **0** Hit Points, or until you use this Action again.

###### Cast
Magic Action
{ .subtitle }

You can cast _Animal Messenger_, targeting the raven.

###### Command
Free Action
{ .subtitle }

You can command the raven to move and take any Action available to it.
