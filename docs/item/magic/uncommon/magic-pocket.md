### Magic Pocket
Uncommon Container (Pouch)
{ .subtitle }

You can bond this item to an extradimensional space by leaving it in the space for **1** hour.  This item can only be bonded to one space at a time. 

#### Retrieve Item
Utilize Action
{ .subtitle }

While the bonded space is within **60** feet, you can retrieve an item from the bonded space.
