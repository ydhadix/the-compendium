### Driftglobe
Uncommon Wondrous Item
{ .subtitle }

#### Command Word
Free Action
{ .subtitle }

You can speak one of the following Command Words to use its effect:

##### Illuminate
This item emits light as the _Light_ Spell.

##### Shine
1 use per Day
{ .subtitle }

This item emits light as the _Daylight_ Spell.

##### Follow
The illuminated globe rises and floats up to **5** feet above the ground, following you by the shortest route until you or another creature grasps it. If it can't move, it sinks to the ground and its light goes out.
