### Gem of Brightness
Uncommon Wondrous Item
{ .subtitle }

**50** uses
{ .subtitle }

#### Command Word
Magic Action
{ .subtitle }

You can speak one of the following Command Words to use its effect.  Once the gem's last use is expended, it becomes a nonmagical gem worth **50** gold.

##### Illuminate
This item emits light as the _Light_ Spell.

##### Beam
1 use
{ .subtitle }

One creature that can see you within **60** feet makes a Fortitude Save _(DC = **13**)_.

| | |
|---|---|
| Fail | The target is Blinded for **1** minute. |
| Success | No effect. |

Before each of the target's Turns ends, it repeats this Saving Throw.  On a success, this effect ends on the target.

##### Flare
5 uses
{ .subtitle }

Each creature that can see you in a **30**-foot Cone makes the same Saving Throw as the Beam command.
