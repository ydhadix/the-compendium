### Rope of Climbing
Uncommon Wondrous Item
{ .subtitle }

This rope is **60** feet long and can hold up to **3,000** pounds. It has an Armor Class of **20**, **20** Hit Points, and Poison and Psychic Immunity. It regains **1** Hit Point every **5** minutes, but is destroyed if it drops to **0** Hit Points.

#### Command
Magic Action
{ .subtitle }

While holding one end of the rope, you can speak one of the following Command Words. Speak its opposite to end the effect.

##### Move / Stop
Choose a point within **60** feet. Before each of your Turns end, the other end moves **10** feet toward the chosen point.

##### Fasten / Unfasten
The other end securely fastens to an object.

##### Knot / Unknot
Large knots appear at **1**-foot intervals, shortening the rope to **50** feet.  Athletics Checks to climb it gain Advantage.

##### Coil / Uncoil
All other effects end and the rope coils itself.
