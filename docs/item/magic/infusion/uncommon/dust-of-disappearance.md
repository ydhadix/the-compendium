### Dust of Disappearance
Uncommon Wondrous Item, Consumable
{ .subtitle }

#### Scatter Dust
Utilize Action
{ .subtitle }

You can throw the dust into the air; you and everything within a **10**-foot Aura become Invisible for **2d4** minutes.  After an affected creature makes an Attack Roll, deals damage, or casts a Spell, the condition ends for it.
