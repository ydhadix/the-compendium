### Dust of Sneezing and Choking
Uncommon Wondrous Item, Consumable
{ .subtitle }

This dust resembles Dust of Disappearance.  _Identify_ reveals its true nature.

#### Scatter Dust
Utilize Action
{ .subtitle }

You can throw the dust into the air; you and every creature in a **30**-foot Aura make a Fortitude Save _(DC = **13**)_. Constructs, Elementals, Oozes, Plants, and Undead succeed automatically.

| | |
|---|---|
| Fail | The target is Incapacitated and begins suffocating.  At the end of each of its Turns, it repeats the Saving Throw, ending the effect on a success; _Lesser Restoration_ also ends it. |
| Success | No effect. |
