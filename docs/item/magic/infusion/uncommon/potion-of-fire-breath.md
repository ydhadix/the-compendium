### Potion of Fire Breath
Uncommon Potion, Consumable
{ .subtitle }

After consuming this potion, you gain the following Action for **1** hour.

#### Breathe Fire
Bonus Action, 3 uses
{ .subtitle }

You can exhale fire at one creature within **30** feet.  That creature makes a Reflex Save _(DC **13**)_.

| | |
|---|---|
| Fail | You deal **4d6** Fire Damage to the target. |
| Success | You deal half as much damage. |
