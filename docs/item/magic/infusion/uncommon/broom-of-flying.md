### Broom of Flying
Uncommon Wondrous Item, Attunement
{ .subtitle }

#### Command Word
Magic Action
{ .subtitle }

You can speak one of the following Command Words to use its effect:

##### Ride
You mount the broom, giving it a **50**-foot Hover Speed _(**30** feet while carrying over **200** pounds)_ and a capacity of **400** pounds.  It stops hovering after you land or dismount.

##### Deliver
You send the broom to a familiar location within **1** mile.

##### Return
While within **1** mile, the broom moves to return to you.
