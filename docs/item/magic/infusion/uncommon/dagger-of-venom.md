### Dagger of Venom
Uncommon Weapon (Sidearm)
{ .subtitle }

**1** Charge (regain **1** per Day)
{ .subtitle }

###### Envenom
Bonus Action, 1 Charge
{ .subtitle }

You coat this weapon in magical venom for **1** minute. The next creature the weapon damages during that time makes a Fortitude Save _(DC = **13**)_, and the venom is spent.

| | |
|---|---|
| Fail | The target takes **2d10** Poison Damage and is Sickened for **1** minute. |
| Success | The target takes half as much Poison Damage. |
