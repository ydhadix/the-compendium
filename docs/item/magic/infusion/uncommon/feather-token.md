### Feather Token
Uncommon Wondrous Item, Consumable
{ .subtitle }

This token looks like a feather, and its variant determines its effect.

#### Activate
Utilize Action
{ .subtitle }

You can use the token's effect.

---

#### Variants

| Token | Effect |
|---|---|
| Anchor | You touch the token to a boat or ship.  The vessel can't be moved by any means for **24** hours. Touching the token to the vessel again ends the effect, and the token disappears. |
| Fan | While on a boat or ship, you toss the token up to **10** feet into the air.  The token disappears and a giant flapping fan takes its place, filling the sails with wind that increases the vessel's speed by **5** miles per hour for **8** hours. You can verbally command the fan to stop spinning, resume spinning, or vanish. |
| Tree | While outdoors, you can touch the token to an unoccupied space on the ground. The token disappears and a nonmagical oak tree springs up, **60** feet tall with a **5**-foot-diameter trunk and branches spreading in a **20**-foot radius. |
