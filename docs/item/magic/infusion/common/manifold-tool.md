### Manifold Tool
Common Wondrous Item, Attunement (Artificer)
{ .subtitle }

#### Transform Tool
Magic Action
{ .subtitle }

You can transform this tool into any Artisan's Tool you have Proficiency with.

#### Gain Proficiency
Magic Action, 1 use per Day
{ .subtitle }

You can gain Proficiency with one Artisan's Tool until you finish a Long Rest.
