### Wand Sheathe
Common Wondrous Item, Attunement (Construct)
{ .subtitle }

This item attaches to your arm and can't be removed from you while you're Attuned to it.

#### Insert or Remove Wand
Magic Action
{ .subtitle }

You can insert a wand into the sheathe or remove a wand from the sheathe. The sheathe can only hold **1** wand at a time. While you are Attuned to a wand in the sheathe, the wand and this item count as a single item for Attunement.

#### Extend or Retract Wand
Bonus Action
{ .subtitle }

You can extend or retract a wand in the sheathe. While extended, you can use the wand as if you were holding it, but your hand remains free.
