### Instrument of Scribing
Common Wondrous Item
{ .subtitle }

**3** Charges (regain **3** per Day)
{ .subtitle }

###### Scribe
Magic Action, 1 Charge
{ .subtitle }

While you are playing this musical instrument, you write up to **6** words in a language you know on an object or surface within **30** feet of you. The words fade after **24** hours. If you are a Bard, you can write up to **7** additional words and can make the words glow slightly in nonmagical Darkness.
