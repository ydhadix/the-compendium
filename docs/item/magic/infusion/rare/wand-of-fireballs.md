### Wand of Fireballs
Rare Spellcasting Focus (Arcane Focus), Attunement (Spellcaster)
{ .subtitle }

**7** Charges (regain **1d6 + 1** per Day)
{ .subtitle }

###### Cast
Magic Action, 1 or more Charges
{ .subtitle }

You can cast _Fireball_. Increase the Spell Level by **1** for each additional Charge expended.
