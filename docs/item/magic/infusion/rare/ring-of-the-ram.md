### Ring of the Ram
Rare Clothing (Jewelry), Attunement
{ .subtitle }

**3** Charges (regain **1d3** per Day)
{ .subtitle }

#### Ram
Magic Action, 1 or more Charges
{ .subtitle }

You conjure a force-driven ram and make a Ranged Attack Roll with a **+7** bonus against a target within **60** feet.

| | |
|---|---|
| Hit | You deal **2d10** Force Damage and propel the target up to **5** feet away from you. |

Increase the Force Damage by **2d10** and the distance propelled by **5** feet for each additional Charge expended.
