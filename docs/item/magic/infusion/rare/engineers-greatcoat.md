### Engineer's Greatcoat
Rare Clothing (Cloak)
{ .subtitle }

You can target objects and constructs with healing spells.

#### Summon Tools
Utilize Action
{ .subtitle }

You summon a set of Artisan's Tools from the greatcloak.  The tools remain until you pull another tool from the greatcloak, until they're more than **15** feet away from you, or until you remove the greatcloak.  If you have Proficiency with a set of tools pulled from the greatcloak, you make Checks with them as though you had Expertise.
