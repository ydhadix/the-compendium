### Ring of Spell Storing
Rare Clothing (Jewelry), Attunement (Spellcaster)
{ .subtitle }

**5** Charges (regain **1d4 + 1** per Day)
{ .subtitle }

#### Channel
Free Action, 1 or more Charges
{ .subtitle }

Before you cast a Spell using a Spell Slot whose Level is no more than this item's remaining Charges, you can roll **1d6**. If the roll is at least the Spell's Level, you cast the Spell spending **1** Charge per Spell Level instead of a Spell Slot. Otherwise, you cast the Spell using a Spell Slot as normal; without a Spell Slot, the casting fails _(the Casting Time is still expended)_.
