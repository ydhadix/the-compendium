## Using Equipment
Benefiting from items usually requires wearing or wielding them properly. An item's type determines how it should be used or worn, and how many items of the same type a typical Humanoid can wear at the same time.

### Item Types

|---|---|---|---|
| [Armor](/item/armor.md) | Donned on body | **1** | Leatherworker's Tools, Smith's Tools, or Weaver's Tools |
| [Clothing](/item/gear/clothing/index.md) | Varies by type | Varies by type | Varies by type |
| [Container](/item/gear/container/index.md) | Carried or held | — | Varies by material |
| [Shield](/item/armor.md#shields) | Donned in hand | **1** | Leatherworker's Tools, Smith's Tools, or Woodcarver's Tools |

### Currency
**Currency** is the coin a character earns and spends.

#### Denominations
Coins come in four metals of increasing worth.  Some settings may have different names for each coin, use different materials, or may not use physical currency at all.  Regardless, the same units can be used to compare relative value within a setting.

| Coin | Value |
|---|---|
| Copper | **1**/**100** gold |
| Silver | **1**/**10** gold |
| Gold | **1** gold |
| Platinum | **10** gold |

#### Exchange
Coins convert at a decimal scale: **100** copper equal **10** silver equal **1** gold, and **10** gold equal **1** platinum.


### Crafting Items
**Crafting** is how a character makes weapons, armor, and gear from raw materials.  Crafting an item costs less gold than buying it, but requires time and specialized Proficiencies.

#### Requirements
You can only craft an item if you have Proficiency with the corresponding Artisan's Tool and the tool is appropriate to the material used.

#### Time and Cost
The Cost of crafting an item is paid in raw materials and time based on the item's Value. You use half the item's Value in raw materials, and it takes **1** day to craft an item for every **25** gold it's worth, or half as much time for a Consumable.

Every day of crafting requires **8** hours of work, but the total hours and days don't need to be consecutive.

###### Working Together
You can work with other characters to shorten the crafting time, provided each character has the appropriate Proficiencies.  Each character's contribution reduces the total time as though they were working independently.

### Masterwork
**Masterwork** items have exceptional craftsmanship that gives a bonus to attacks, defenses, or spellcasting.

| Bonus | Value | Armor Value | Min. Level |
|---|---|---|---|
| **+1** | **+400** gold | **+4,000** gold | **5** |
| **+2** | **+4,000** gold | **+40,000** gold | **11** |
| **+3** | **+40,000** gold | **+400,000** gold | **17** |

#### Masterwork Bonuses
There are four types of Masterwork that determine what the item's bonus increases:

| Masterwork | Bonus to... |
|---|---|
| Physical | Weapon Attack and Damage Rolls |
| Spell Attack | Spell Attack Rolls |
| Spell Save | Spell Save DCs |
| Armor Class | Armor Class |

Any item can be created with one or all of these bonuses, but Masterwork doesn't change the item's capabilities; an item must be usable as a Weapon, Spellcasting Focus, or Armor to benefit from its Masterwork bonus.

#### Value
The Value of a Masterwork item is the item's base value, plus the value of each of its Masterwork bonuses.  For Armor Class bonuses on a set of Armor _(not a Shield)_, use the Armor Value column instead.

#### Crafting Requirements
Masterwork increases the value of an item, but not the amount of Time required to craft it.  Crafting a Masterwork bonus requires Expertise in the item's corresponding Artisan's Tool and a minimum Character Level based on the bonus.
