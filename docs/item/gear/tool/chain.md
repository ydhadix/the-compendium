### Chain
Tool, 5 gold
{ .subtitle }

##### Bind
**Utilize Action:** You can choose an object or a Grappled, Incapacitated, or Restrained creature within Reach and make an Athletics Check _(DC **13**)_.

| | |
|---|---|
| **Success** | You wrap the Chain around the target. If the target's legs are bound, the target is Restrained. |

###### Escape
Any bound creature can take this Action.

**Utilize Action:** The creature makes an Acrobatics Check _(DC **18**)_.

| | |
|---|---|
| **Success** | The creature escapes. |

###### Break Free
Any creature that can reach a bound target can take this Action.

**Utilize Action:** The creature makes an Athletics Check _(DC **20**)_.

| | |
|---|---|
| **Success** | The Chain is destroyed. |
