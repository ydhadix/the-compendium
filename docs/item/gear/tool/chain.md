### Chain
Tool, 5 gold
{ .subtitle }

##### Bind
Utilize Action
{ .subtitle }

You can choose an object or a Grappled, Incapacitated, or Restrained creature within Reach and make an Athletics Check _(DC **13**)_.

| | |
|---|---|
| **Success** | You wrap the Chain around the target. If the target's legs are bound, the target is Restrained. |

###### Escape
Utilize Action
{ .subtitle }

A bound creature can make an Acrobatics Check _(DC **18**)_.

| | |
|---|---|
| **Success** | The creature escapes. |

###### Break Free
Utilize Action
{ .subtitle }

A creature that can reach a bound target can make an Athletics Check _(DC **20**)_.

| | |
|---|---|
| **Success** | The Chain is destroyed. |
