### Grappling Hook
2 gold
{ .subtitle }

###### Hook
Utilize Action
{ .subtitle }

You can throw the Grappling Hook at a railing, ledge, or another fixture within **50** feet and make a DC **13** Acrobatics check.

| | |
|---|---|
| **Success** | The hook catches on. If you tied a Rope to the hook, you can then Climb it. |
