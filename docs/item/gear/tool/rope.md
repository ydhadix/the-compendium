### Rope
Tool, 1 gold
{ .subtitle }

##### Tie Knot
**Utilize Action:** You can make a Precision Check _(DC **10**)_.

| | |
|---|---|
| **Success** | You tie a knot with the Rope. |

##### Bind
**Utilize Action:** You can choose a Grappled, Incapacitated, or Restrained creature within Reach and make a Precision Check _(DC **10**)_.

| | |
|---|---|
| **Success** | You wrap the Rope around the target. If the target's legs are bound, the target is Restrained. |

###### Escape
Any bound creature can take this Action.

**Utilize Action:** The creature makes an Acrobatics Check _(DC **15**)_.

| | |
|---|---|
| **Success** | The creature escapes. |

###### Cut Free
Any creature that can reach the Rope can take this Action.

**Utilize Action:** The creature makes an Athletics Check _(DC **20**)_.

| | |
|---|---|
| **Success** | The Rope is destroyed. |
