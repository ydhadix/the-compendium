### Rope
Tool, 1 gold
{ .subtitle }

##### Tie Knot
Utilize Action
{ .subtitle }

You can make a Precision Check _(DC **10**)_.

| | |
|---|---|
| **Success** | You tie a knot with the Rope. |

##### Bind
Utilize Action
{ .subtitle }

You can choose a Grappled, Incapacitated, or Restrained creature within Reach and make a Precision Check _(DC **10**)_.

| | |
|---|---|
| **Success** | You wrap the Rope around the target. If the target's legs are bound, the target is Restrained. |

###### Escape
Utilize Action
{ .subtitle }

A bound creature can make an Acrobatics Check _(DC **15**)_.

| | |
|---|---|
| **Success** | The creature escapes. |

###### Cut Free
Utilize Action
{ .subtitle }

A creature that can reach the Rope can make an Athletics Check _(DC **20**)_.

| | |
|---|---|
| **Success** | The Rope is destroyed. |
