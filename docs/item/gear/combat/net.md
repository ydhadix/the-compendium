### Net
Other, 1 gold
{ .subtitle }

###### Ensnare
A Net can be wielded as a Simple Melee Weapon with Thrown _(**15** feet)_.

| | |
|---|---|
| **Hit** | You deal no damage. If the target is Large or smaller, until the target escapes or the Net is destroyed, the target is Restrained. |

###### Escape
Utilize Action
{ .subtitle }

A Restrained creature can make an Athletics Check _(DC **10**)_.

| | |
|---|---|
| **Success** | The creature escapes. |

###### Durability
The Net has Armor Class **10**, Hit Points **5**, and Immunity to Bludgeoning, Poison, and Psychic Damage. If it drops to **0** Hit Points, it is destroyed.
