### Scroll of Protection
Scroll, Consumable, 2,000 gold
{ .subtitle }

Each Scroll of Protection has a Creature Type.

##### Read
Magic Action
{ .subtitle }

You can read the scroll, creating a **5**-foot Aura for **5** minutes.  Creatures of the scroll's Creature Type can't enter the Aura or affect anything inside it.  After you move so that such a creature would be inside the Aura, this effect ends.

###### Overcome
Magic Action
{ .subtitle }

A creature within **5** feet of the Aura can make a Will Save _(DC **15**)_.  On a success, the Aura no longer affects it.
