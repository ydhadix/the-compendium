### Potion of Poison
Potion (Ingested), Consumable, 200 gold
{ .subtitle }

This poison looks, smells, and tastes like a beneficial Potion, though _Identify_ reveals its true nature.

This potion deals **4d6** Poison Damage to the target.  The target makes a Fortitude Save _(DC **13**)_.

| | |
|---|---|
| Fail | The potion sickens the target for **1** hour. |
| Success | No effect. |
