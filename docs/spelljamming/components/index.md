# Ship Components

Your ship's components define its physical capabilities. Each component belongs to one of the ship's officers — the Pilot, Quartermaster, or Spelljammer — and enhances that officer's ability to control the ship.

## Components in Combat

Some components can be attacked. Targetable components have their own Armor Class, Damage Threshold, Hull Points, and Keel Points, just as the ship's hull does. Components that don't have combat statistics can't be attacked.

## Disabling Components

When a component is reduced to 0 HP, it is Disabled. Disabled components don't offer any benefits, can't be used, and can't be easily repaired in combat.

When a component is reduced to 0 KP, it is destroyed. Destroyed components are irreparably damaged and must be replaced outside of combat.
