Each target makes a Will Save.  An Enemy gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | You charm the target and it becomes a Companion to you. |
| Success | No effect. |

##### Command
**Free Action:** You can command a Charmed target to move and take any Action available to it.

#### Ending Early
After a Charmed target takes damage, it repeats this Saving Throw.

| | |
|---|---|
| Fail | No additional effect. |
| Success | This Spell ends on the target. |
