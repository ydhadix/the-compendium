### Toll the Dead
Necromancy Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | **1** Creature or Object |
| Duration | — |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | You deal **1d8** Necrotic Damage, or **1d12** Necrotic Damage if the target is missing any Hit Points. |
| Success | No effect. |

#### At Higher Levels
Add **1** Damage Die to the damage at Level 5, Level 11, and Level 17.
