### Shocking Grasp
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | **1** Creature or Object |
| Duration | Until the end of the target's next Turn |

---

You make a Melee Spell Attack against each target.

| | |
|---|---|
| Hit | You deal **1d8** Lightning Damage, and the target can't take Reactions. |

#### At Higher Levels
Add **1d8** to the damage at Level 5, Level 11, and Level 17.
