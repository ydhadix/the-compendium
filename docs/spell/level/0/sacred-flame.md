### Sacred Flame
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | One thing |
| Duration | — |

##### Spell Effect
The target makes a Reflex Save and gains no benefit from Half Cover or Three-Quarters Cover.

| | |
|---|---|
| Fail | You deal **1d8** Radiant Damage. |
| Success | No effect. |

##### At Higher Levels
Add **1d8** to the damage at Level 5, Level 11, and Level 17.
