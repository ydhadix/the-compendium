### Resistance
Abjuration Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Cleric, Druid |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | **1** Creature |
| Duration | 1 minute (Concentration) |

---

Choose a Damage Type other than Psychic or Force.

Before the target takes damage of the chosen type, you reduce that damage by **1d4**.
