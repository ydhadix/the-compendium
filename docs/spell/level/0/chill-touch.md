### Chill Touch
Necromancy Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | Reach |
| Target | One thing |
| Duration | Until the end of your next Turn |

##### Spell Effect
You make a Melee Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **1d10** Necrotic Damage, and the target can't regain Hit Points. |

##### At Higher Levels
Add **1d10** to the damage at Level 5, Level 11, and Level 17.
