### Chill Touch
Necromancy Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | **1** Creature or Object |
| Duration | Until the end of your next Turn |

---

You make a Melee Spell Attack against each target.

| | |
|---|---|
| Hit | You deal **1d10** Necrotic Damage, and the target can't heal. |

#### At Higher Levels
Add **1d10** to the damage at Level 5, Level 11, and Level 17.
