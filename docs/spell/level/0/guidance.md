### Guidance
Divination Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Cleric, Druid |
| Components | V, S |
| Casting Time | Normal Action |
| Range | Reach |
| Target | One creature |
| Duration | 1 minute (Concentration) |

Choose a Skill or Trade. Whenever the target makes a Check using the chosen Proficiency, you add **1d4** to the check.
