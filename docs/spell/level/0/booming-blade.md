### Booming Blade
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Warlock, Wizard |
| Components | S, M _(a melee weapon)_ |
| Casting Time | Magic Action |
| Range | The Material Component's Reach |
| Area | |
| Target | **1** Creature or Object |
| Duration | Until the end of your next Turn |

---

You make a Melee Weapon Attack against each target using the Material Component.

| | |
|---|---|
| Hit | You deal the Material Component's damage, and you can change the Damage Type to Thunder. The next time the target expends movement, you deal **1d8** Thunder Damage, then this Spell ends on the target. |

#### At Higher Levels
Add **1d8** Thunder Damage to the Attack and effect at Level 5, Level 11, and Level 17.
