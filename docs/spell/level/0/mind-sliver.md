### Mind Sliver
Enchantment Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Warlock, Wizard |
| Components | V |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One thing |
| Duration | Until the end of your next Turn |

The target makes a Will Save.

| | |
|---|---|
| Fail | You deal **1d6** Psychic Damage, and the next time the target makes a Save, you subtract **1d4** from the save, then this Spell ends. |
| Success | No effect. |

##### At Higher Levels

Add **1d6** to the damage at Level 5, Level 11, and Level 17.
