### Mind Sliver
Enchantment Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Warlock, Wizard |
| Components | V |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | **1** Creature or Object |
| Duration | Until the end of your next Turn |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | You deal **1d6** Psychic Damage, and the target's next Saving Throw decreases by **1d4**, then this Spell ends on the target. |
| Success | No effect. |

#### At Higher Levels
Add **1d6** to the damage at Level 5, Level 11, and Level 17.
