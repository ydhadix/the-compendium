### Fire Bolt
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | One thing |
| Duration | 1 minute |

You make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **1d10** Fire Damage. A flammable object starts Burning (**1d4**). |

##### At Higher Levels

Add **1d10** to the damage at Level 5, Level 11, and Level 17.
