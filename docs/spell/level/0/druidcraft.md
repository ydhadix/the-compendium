### Druidcraft
Transmutation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Druid |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 30 ft. |
| Target | — |
| Duration | — |

Choose one of the following effects:

- **Fire Play.** You light or snuff out a candle, torch, or small campfire.
- **Bloom.** You cause a flower to blossom, a seed pod to open, or a leaf bud to bloom.
- **Weather Sensor.** You create a harmless sensory effect that predicts the local weather for the next **24** hours.
- **Nature Effect.** You create a harmless sensory effect, such as falling leaves, a gentle breeze, an animal's sound, or a faint odor.
