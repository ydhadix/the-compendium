### Friends
Enchantment Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Warlock, Wizard |
| Components | S, M |
| Casting Time | Magic Action |
| Range | 10 ft. |
| Area | |
| Target | **1** Humanoid |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save. If you've damaged a target or cast this Spell on it within the last **24** hours, the target automatically succeeds.

| | |
|---|---|
| Fail | You charm the target. |
| Success | No effect. |

#### Ending Early
This Spell ends on a target if it takes damage.

This Spell ends if you attack, deal damage, or cause a Saving Throw.
