### Greenflame Blade
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Warlock, Wizard |
| Components | S, M _(a melee weapon)_ |
| Casting Time | Magic Action |
| Range | The material component's Reach |
| Target | One thing |
| Duration | — |

##### Spell Effect
You make a Melee Weapon Attack against the target using the material component.

| | |
|---|---|
| Hit | You deal the material component's damage, and you can change the Damage Type to Fire. Then, you deal **Spellcasting Ability** Fire Damage to a second creature within **5** feet of the target. |

##### At Higher Levels
Add **1d8** Fire Damage to the Attack and effect at Level 5, Level 11, and Level 17.
