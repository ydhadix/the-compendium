### Sapping Sting
Necromancy Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Target | One thing |
| Duration | — |

##### Spell Effect
The target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **1d6** Necrotic Damage, and you knock the target Prone. |
| Success | No effect. |

##### At Higher Levels
Add **1d6** to the damage at Level 5, Level 11, and Level 17.
