### True Strike
Divination Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Sorcerer, Warlock, Wizard |
| Components | S, M _(a weapon you're proficient with)_ |
| Casting Time | Magic Action |
| Range | The Material Component's Reach or Range |
| Area | |
| Target | **1** Creature or Object |
| Duration | — |

---

You make a Spell Attack against each target using the Material Component.

| | |
|---|---|
| Hit | You deal the Material Component's damage, and you can change the Damage Type to Radiant. You don't add your Spellcasting Ability to the damage. |

#### At Higher Levels
Add **1** Damage Die to the damage at Level 5, Level 11, and Level 17.
