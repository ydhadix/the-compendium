### Ray of Frost
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | One thing |
| Duration | Until the end of your next Turn |

##### Spell Effect
You make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **1d8** Cold Damage, and the target's Speed decreases by **10** feet. |

##### At Higher Levels
Add **1d8** to the damage at Level 5, Level 11, and Level 17.
