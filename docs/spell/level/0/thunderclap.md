### Thunderclap
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Druid, Sorcerer, Warlock, Wizard |
| Components | S |
| Casting Time | Magic Action |
| Range | — |
| Target | Everything in a 5-ft. Aura |
| Duration | — |

##### Spell Effect
Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **1d6** Thunder Damage. |
| Success | No effect. |

This Spell's thunder is audible out to **100** feet.

##### At Higher Levels
Add **1d6** to the damage at Level 5, Level 11, and Level 17.
