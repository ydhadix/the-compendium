### Sorcerous Burst
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Area | |
| Target | **1** Creature or Object |
| Duration | — |

---

Choose an Elemental Damage Type or Psychic Damage.

You make a Ranged Spell Attack against each target.

| | |
|---|---|
| Hit | You deal **1d8** damage of the chosen type.  After you roll an **8** on a Damage Die for this Spell, you can roll another **1d8** and add it to the damage.  An added die can trigger this effect again, and you can add up to **Spellcasting Ability** dice this way. |

#### At Higher Levels
Add **1d8** to the damage at Level 5, Level 11, and Level 17.
