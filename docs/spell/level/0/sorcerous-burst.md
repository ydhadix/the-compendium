### Sorcerous Burst
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | One thing |
| Duration | — |

##### Spell Effect
Choose an Elemental Damage Type or Psychic Damage. You make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **1d8** damage of the chosen type. Whenever you roll an **8** on a Damage Die for this Spell, you can roll another **1d8** and add it to the damage. The maximum number of dice you can add this way equals your Spellcasting Ability. |

##### At Higher Levels
Add **1d8** to the damage at Level 5, Level 11, and Level 17.
