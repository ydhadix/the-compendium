### Sword Burst
Conjuration Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | — |
| Target | Everything in a 5-ft. Aura |
| Duration | — |

##### Spell Effect
Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **1d6** Force Damage. |
| Success | No effect. |

##### At Higher Levels
Add **1d6** to the damage at Level 5, Level 11, and Level 17.
