### Lightning Lure
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Warlock, Wizard |
| Components | V |
| Casting Time | Normal Action |
| Range | 30 ft. |
| Target | One thing |
| Duration | — |

The target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **1d6** Lightning Damage, and a Large or smaller target is moved up to **10** feet closer to you. |
| Success | No effect. |

##### At Higher Levels

Add **1d6** to the damage at Level 5, Level 11, and Level 17.
