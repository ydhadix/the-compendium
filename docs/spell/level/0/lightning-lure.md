### Lightning Lure
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Warlock, Wizard |
| Components | V |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | |
| Target | **1** Creature or Object |
| Duration | — |

---

Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **1d6** Lightning Damage, and if the target is of your Size or smaller, you propel it up to **10** feet closer to you. |
| Success | No effect. |

#### At Higher Levels
Add **1d6** to the damage at Level 5, Level 11, and Level 17.
