### Acid Splash
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | Each creature in a 5-ft. radius Sphere |
| Duration | — |

##### Spell Effect
Each creature in a **5**-foot radius Sphere makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **1d6** Acid Damage. |
| Success | No effect. |

##### At Higher Levels

Add **1d6** to the damage at Level 5, Level 11, and Level 17.
