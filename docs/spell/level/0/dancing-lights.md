### Dancing Lights
Illusion Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | — |
| Duration | 1 minute (Concentration) |

##### Spell Effect
You create up to **4** hovering lights. Each light emits Dim Light out to **10** feet and vanishes if it moves out of Range or isn't within **20** feet of another light.

###### Move
Bonus Action
{ .subtitle }

You can move the lights up to **60** feet. You can combine the lights into **1** Medium, vaguely humanoid form or separate them.
