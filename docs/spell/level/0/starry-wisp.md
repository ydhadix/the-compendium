### Starry Wisp
Evocation Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One thing |
| Duration | Until the end of your next Turn |

##### Spell Effect
You make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **1d8** Radiant Damage, and the target emits Dim Light out to **10** feet and can't benefit from being Invisible. |

##### At Higher Levels
Add **1d8** to the damage at Level 5, Level 11, and Level 17.
