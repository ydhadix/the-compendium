### Vicious Mockery
Enchantment Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Bard |
| Components | V |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | **1** Creature or Object |
| Duration | Until the end of your next Turn |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | You deal **1d6** Psychic Damage, and the target gains Disadvantage on its next Attack Roll, then this Spell ends on the target. |
| Success | No effect. |

#### At Higher Levels
Add **1d6** to the damage at Level 5, Level 11, and Level 17.
