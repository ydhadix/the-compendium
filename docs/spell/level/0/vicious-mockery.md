### Vicious Mockery
Enchantment Cantrip
{ .subtitle }

| | |
|---|---|
| Classes | Bard |
| Components | V |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One thing |
| Duration | Until the end of your next Turn |

##### Spell Effect
The target makes a Will Save.

| | |
|---|---|
| Fail | You deal **1d6** Psychic Damage, and the target's next Attack Roll gains Disadvantage, then this effect ends. |
| Success | No effect. |

##### At Higher Levels
Add **1d6** to the damage at Level 5, Level 11, and Level 17.
