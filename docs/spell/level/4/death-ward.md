### Death Ward
4th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Target | One creature |
| Duration | 8 hours |

##### Spell Effect
Before the target's Hit Points become **0**, they instead become **1**, then this effect ends.

If an effect would kill the target without dealing damage, that effect fails against the target, then this effect ends.
