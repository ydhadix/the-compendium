### Death Ward
4th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Area | — |
| Target | **1** Creature |
| Duration | 8 hours |

---

Before a target would drop to **0** Hit Points or be killed, it instead survives with **1** Hit Point, then this Spell ends on that target.
