### Aura of Purity
4th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V |
| Casting Time | Normal Action |
| Range | — |
| Target | You and each ally in a 30-ft. Aura |
