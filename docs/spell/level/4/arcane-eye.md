### Arcane Eye
4th-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M _(a bit of bat fur)_ |
| Casting Time | Normal Action |
| Range | 30 ft. |
| Target | — |
| Duration | 1 hour (Concentration) |

##### Spell Effect
You create an Invisible, invulnerable eye in an unoccupied space.  You see through it in every direction, and it has Darkvision out to **30** feet.

###### Move
Bonus Action
{ .subtitle }

You can move the eye up to **30** feet in any direction.  A solid barrier blocks it, but it can pass through an opening as small as **1** inch across.
