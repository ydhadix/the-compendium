### Arcane Eye
4th-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M _(a bit of bat fur)_ |
| Casting Time | Normal Action |
| Range | 30 ft. |
| Target | — |
| Duration | 1 hour (Concentration) |

##### Spell Effect
You create a scrying sensor.  The sensor is a Tiny, Invisible and invulnerable object with **30** feet of Darkvision.  You can see through its sight _(Your normal senses are unaffected)_.

###### Move
Bonus Action
{ .subtitle }

You can move the sensor up to **30** feet in any direction.  A solid barrier blocks it, but it can pass through an opening as small as **1** inch across.
