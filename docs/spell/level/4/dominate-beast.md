### Dominate Beast
4th-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Sorcerer |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | **1** Beast |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save. If you or an Ally is fighting a target, it gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | You charm the target and it becomes a Companion to you. |
| Success | No effect. |

##### Command
**Free Action:** You can command the target to move and take any Action available to it.

#### Ending Early
After a target takes damage, it makes a Will Save.

| | |
|---|---|
| Fail | No additional effect. |
| Success | This Spell ends on the target. |

#### At Higher Levels
When Upcast to 5th-Level, the Concentration can last up to **10** minutes.

When Upcast to 6th-Level, it can last up to **1** hour.

When Upcast to 7th-Level or higher, it can last up to **8** hours.
