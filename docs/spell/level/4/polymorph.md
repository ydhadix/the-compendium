### Polymorph
4th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | — |
| Target | **1** Creature |
| Duration | 1 hour (Concentration) |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | Choose any Beast with a Level no higher than the target's.  The target gains the following effects:<ul><li>The target's game statistics are replaced by the Beast's, but it keeps its alignment, personality, Creature Type, Hit Points, and Hit Dice.</li><li>The target gains **the Beast's Maximum Hit Points** Temporary Hit Points.</li><li>The target can't speak or cast Spells, and can act only as its new form's anatomy allows.</li><li>The target's gear melds into the new form and can't be used.</li></ul> |
| Success | No effect. |

#### Ending Early
This Spell ends on a target if it has no Temporary Hit Points left.
