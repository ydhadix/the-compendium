### Polymorph
4th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid, Sorcerer, Wizard |
| Components | V, S, M _(a caterpillar cocoon)_ |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | One creature |
| Duration | 1 hour (Concentration) |

##### Spell Effect
The target makes a Will Save.

| | |
|---|---|
| Fail | You transform the target into a Beast.  Choose any Beast with a Level no higher than the target's.  The target gains the following effects:<ul><li>The target's game statistics are replaced by the Beast's, but it keeps its alignment, personality, Creature Type, Hit Points, and Hit Dice.</li><li>The target can't speak or cast Spells, and it can act only as its new form's anatomy allows.</li><li>The target's gear melds into the new form and can't be used.</li><li>The target gains Temporary Hit Points equal to the Beast's Hit Points.  This effect ends on the target if it has no Temporary Hit Points left.</li></ul> |
| Success | No effect. |
