### Polymorph
4th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid, Sorcerer, Wizard |
| Components | V, S, M _(a caterpillar cocoon)_ |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One creature |
| Duration | 1 hour (Concentration) |

##### Spell Effect
The target makes a Will Save.

| | |
|---|---|
| Fail | You transform the target into a Beast. |
| Success | No effect. |

Choose any Beast with a CR no higher than the target's, or its Level if the target has no CR.  The target's game statistics are replaced by the Beast's, but it keeps its alignment, personality, Creature Type, Hit Points, and Hit Dice.  It can't speak or cast Spells, and it can act only as its new form's anatomy allows.  Its gear melds into the new form and can't be used.

The target gains Temporary Hit Points equal to the Beast's Hit Points.  This effect ends on the target if it has no Temporary Hit Points left.
