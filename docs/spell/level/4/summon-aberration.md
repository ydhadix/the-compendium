### Summon Aberration
4th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Warlock, Wizard |
| Components | V, S, M _(a pickled tentacle and an eyeball in a platinum-inlaid vial worth 400 Gold)_ |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | — |
| Duration | 1 hour (Concentration) |

##### Spell Effect
You summon an Aberrant Spirit. Choose Beholderkin, Mind Flayer, or Slaad.

This Spell ends if the Spirit has **0** Hit Points.

###### Command
Free Action
{ .subtitle }

You can command the Spirit to move and take any Action available to it.

##### At Higher Levels
The Spell Level determines the Spirit's Armor Class, Hit Points, and attack damage.
