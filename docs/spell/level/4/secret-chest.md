### Leomund's Secret Chest
4th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M _(a chest worth 5,000 Gold and a Tiny replica worth 50 Gold)_ |
| Casting Time | Normal Action |
| Range | Reach |
| Target | — |
| Duration | Until dispelled |

##### Spell Effect
You hide a chest and its contents on the Ethereal Plane.  The chest holds up to **12** cubic feet of nonliving material.  This Spell ends if you cast it again or the replica is destroyed, and after **60** days, each day has a cumulative **5**% chance of ending it.

###### Recall
Magic Action
{ .subtitle }

You touch the replica to recall the chest, which appears in an unoccupied space on the ground within **5** feet of you.

###### Send Back
Magic Action
{ .subtitle }

You touch the chest and the replica to send the chest back to the Ethereal Plane.
