### Black Tentacles
4th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M _(a tentacle)_ |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | Everything in a 20-ft. Square |
| Duration | 1 minute (Concentration) |

##### Spell Effect
The area is Difficult Terrain.

After a target enters the area __(including when this Spell is cast)__, it makes a Fortitude Save.  After your Turn starts, each target also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You deal **3d6** Bludgeoning Damage and restrain the target.  The target can Utilize to make an Athletics Check against your Spell Save DC; on a success, this effect ends on it. |
| Success | No effect. |
