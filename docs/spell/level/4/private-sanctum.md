### Private Sanctum
4th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M |
| Casting Time | 10 minutes |
| Range | 120 ft. |
| Area | Up to a 100-ft. Cube |
| Target | — |
| Duration | 24 hours |

---

The area gains any number of the following effects:

| Effect | |
|---|---|
| Obscured | The area is Heavily Obscured from the outside. |
| Ward Divination | Creatures in the area can't be targeted by Divination Spells. |
| Ward Scrying | A Scrying Sensor can't enter the area. |
| Ward Sound | No sound can pass into or out of the area. |
| Ward Travel | Nothing can enter or leave the area by teleportation or Planar Travel. |

#### Permanence
If you cast this Spell on the same area every day for **365** days, the effect lasts until dispelled.

#### At Higher Levels
Add **100** feet to the area's maximum size per additional Spell Level.
