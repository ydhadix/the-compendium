### Private Sanctum
4th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M |
| Casting Time | 10 minutes |
| Range | 120 ft. |
| Target | A 5- to 100-ft. Cube |
| Duration | 24 hours |

##### Spell Effect
Choose any number of the following properties for the area:

| | |
|---|---|
| Silence | No sound can pass into or out of the area. |
| Obscured | The area is Heavily Obscured from the outside. |
| Ward Sensors | Sensors created by Divination Spells can't enter the area. |
| Ward Scrying | Creatures in the area can't be targeted by Divination Spells. |
| Seal Teleportation | Nothing can teleport into or out of the area. |
| Seal Planar Travel | Planar travel is blocked within the area. |

If you cast this Spell on the same area every day for **365** days, the effect lasts until dispelled.

##### At Higher Levels
Add **100** feet to the Cube's maximum size per additional Spell Level.
