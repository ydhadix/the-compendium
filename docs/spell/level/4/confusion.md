### Confusion
4th-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid, Sorcerer, Wizard |
| Components | V, S, M _(three nut shells)_ |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | Everything in a 10-ft. radius Sphere |
| Duration | 1 minute (Concentration) |

##### Spell Effect
Each target makes a Will Save.

| | |
|---|---|
| Fail | The target can't take Bonus Actions or Reactions. |
| Success | No effect. |

After an affected target's Turn begins, it rolls **1d10** to determine its behavior for that Turn:

| | |
|---|---|
| 1 | The target takes no Action and uses all its movement to move in a random direction.  Roll **1d4**: **1** north, **2** east, **3** south, or **4** west. |
| 2–6 | The target doesn't move or take Actions. |
| 7–8 | The target attacks one random creature within Reach.  If none is within Reach, it takes no Action. |
| 9–10 | The target chooses its behavior. |

Before each of the target's Turns ends, it repeats this Saving Throw.  On a success, this effect ends on the target.

##### At Higher Levels
Add **5** feet to the radius per additional Spell Level.
