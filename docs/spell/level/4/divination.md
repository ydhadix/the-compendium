### Divination
4th-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid, Wizard |
| Components | V, S, M _(consumes incense worth 25 Gold)_ |
| Casting Time | Normal Action, or Ritual |
| Range | Self |
| Target | Self |
| Duration | — |

##### Spell Effect
You ask one question about a specific goal, event, or activity to occur within **7** days, and you receive a truthful answer.  The answer might be a short phrase or a cryptic rhyme, and it doesn't account for circumstances that could later change it, such as another Spell's casting.

After the first casting before a Long Rest, each casting has a cumulative **25**% chance of giving no answer.
