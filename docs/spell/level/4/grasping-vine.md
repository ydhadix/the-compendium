### Grasping Vine
4th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid |
| Components | V, S |
| Casting Time | Bonus Action |
| Range | 60 ft. |
| Target | One creature within 30 ft. of the vine |
| Duration | 1 minute (Concentration) |

##### Spell Effect
A vine sprouts in an unoccupied space.  You make a Melee Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **4d8** Bludgeoning Damage and propel the target up to **30** feet toward the vine.  If the target is Huge or smaller, you Grapple it _(escape DC equal to your Spell Save DC)_. |

The vine can Grapple only one creature at a time.  You can release a Grappled creature _(no action required)_.

###### Lash
Bonus Action
{ .subtitle }

You can repeat the Attack against a creature within **30** feet of the vine.

##### At Higher Levels
Add **1** creature the vine can Grapple per additional Spell Level.
