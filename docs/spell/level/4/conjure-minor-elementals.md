### Conjure Minor Elementals
4th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | — |
| Target | Anything you choose in a 15-ft. Aura |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
A target's Speed becomes halved while in the area.

Before you deal damage to a target in the area with an Attack, you add **2d8** Acid, Cold, Fire, or Lightning Damage.

##### At Higher Levels
Add **2d8** damage per additional Spell Level.
