### Darkvision
1st-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Druid, Ranger, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | Reach |
| Target | One creature |
| Duration | 8 hours |

##### Spell Effect
The target gains **120** feet of Darkvision.

##### At Higher Levels
Add **1** target per additional Spell Level.
