### Darkvision
1st-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Druid, Ranger, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | **1** Creature |
| Duration | 8 hours |

---

Each target gains **120** feet of Darkvision.

#### At Higher Levels
Add **1** target per additional Spell Level.
