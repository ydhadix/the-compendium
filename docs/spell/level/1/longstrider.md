### Longstrider
1st-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Druid, Ranger, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | Reach |
| Target | One creature |
| Duration | 1 hour |

##### Spell Effect
The target's Speed increases by **10** feet.

##### At Higher Levels
Add **1** target per additional Spell Level.
