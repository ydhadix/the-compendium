### Witch Bolt
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Warlock, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One thing |
| Duration | 1 minute (Concentration) |

##### Spell Effect
You make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **2d12** Lightning Damage. This Spell ends if the target has Full Cover from you or leaves this Spell's range. |
| Miss | This Spell ends. |

As a Bonus Action, you deal **1d12** Lightning Damage to the target.

##### At Higher Levels
Add **1d12** Lightning Damage and **15** feet to the Range per additional Spell Level.
