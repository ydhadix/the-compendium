### Arms of Hadar
1st-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Warlock |
| Components | V, S |
| Casting Time | Normal Action |
| Range | — |
| Target | Each creature in a 10-ft. Aura |
| Duration | Until the end of the target's next Turn |

Each creature in a **10**-foot Aura makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **2d6** Necrotic Damage, and the target can't take Reactions. |
| Success | You deal half as much damage. |

##### At Higher Levels

Add **1d6** Necrotic Damage and **5** feet to the Aura per additional Spell Level.
