### Animal Friendship
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid, Ranger |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 30 ft. |
| Target | One Beast |

| | |
|---|---|
