### Hex
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Warlock |
| Components | V |
| Casting Time | Bonus Action |
| Range | 90 ft. |
| Area | |
| Target | **1** Creature |
| Duration | 1 hour (Concentration) |

---

You mark each target. Choose an Ability.

You gain the following effects against Marked targets:

- Each target gains Disadvantage on Checks using the chosen Ability.
- Your Attacks against each target deal an additional **1d6** Necrotic Damage.

##### Mark
**Bonus Action:** If the target has **0** Hit Points, you can move the mark to a new target _(you don't choose a different Ability)_.

#### At Higher Levels
When Upcast to 2nd- or 3rd-Level, the Duration is **8** hours (Concentration).

When Upcast to 4th-Level or higher, the Duration is **24** hours (Concentration).
