### Command
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Paladin |
| Components | V |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One creature |
| Duration | Until the end of the target's next Turn |

Choose one of the following commands, then the target makes a Will Save.

| | |
|---|---|
| Fail | On its next Turn, the target follows the command, then immediately ends its Turn. |
| Success | No effect. |

- **Approach.** The target moves toward you by the shortest route.
- **Drop.** The target drops anything it's holding.
- **Flee.** The target moves as far from you as it can.
- **Grovel.** The target falls Prone.
- **Halt.** The target doesn't move or take actions.

##### At Higher Levels

Add **1** target per additional Spell Level.
