### Cure Wounds
1st-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Cleric, Druid, Paladin, Ranger |
| Components | V, S |
| Casting Time | Normal Action |
| Range | Reach |
| Target | One creature |
| Duration | — |

##### Spell Effect
You heal the target by **2d8 + Spellcasting Ability**.

##### At Higher Levels
Add **2d8** to the healing per additional Spell Level.
