### Charm Person
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid, Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 30 ft. |
| Target | One humanoid |
| Duration | 1 hour |

##### Spell Effect
The target makes a Will Save. If you've damaged the target within the last **24** hours, it gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | You charm the target. This Spell ends on the target if you or an ally damage it. |
| Success | No effect. |

##### At Higher Levels
Add **1** target per additional Spell Level.
