### Magic Missile
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | Up to 3 creatures or objects |
| Duration | — |

You create **3** glowing darts that strike simultaneously, one target each. The darts can strike the same target or different targets. You deal **1d4 + 1** Force Damage with each dart.

##### At Higher Levels

Add **1** dart and up to **1** target per additional Spell Level.
