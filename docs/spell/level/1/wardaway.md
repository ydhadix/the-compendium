### Wardaway
1st-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Paladin, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One non-Construct, non-Undead creature |
| Duration | Until the end of your next Turn |

The target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **2d4** Force Damage, and you daze the target and halve its Speed until this Spell ends. |
| Success | You deal half as much damage. |

##### At Higher Levels

Add **2d4** Force Damage per additional Spell Level.
