### Ray of Sickness
1st-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One thing |
| Duration | Until the end of your next Turn |

You make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **3d8** Poison Damage, and you sicken the target until this Spell ends. |

##### At Higher Levels

Add **1d8** Poison Damage per additional Spell Level.
