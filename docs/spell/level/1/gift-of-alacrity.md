### Gift of Alacrity
1st-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Ranger, Wizard |
| Components | V, S |
| Casting Time | 1 minute |
| Range | Reach |
| Target | One creature |
| Duration | 8 hours |

Whenever the target makes an Initiative Check, you add **1d8** to the check.
