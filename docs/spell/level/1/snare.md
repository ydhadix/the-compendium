### Snare
1st-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Druid, Ranger, Wizard |
| Components | S, M _(consumes rope)_ |
| Casting Time | Normal Action, or Ritual |
| Range | Reach |
| Target | Special |
| Duration | 8 hours |

##### Spell Effect
The material component surrounds a **5**-foot radius circle on the ground and becomes Invisible. 

The first Small, Medium, or Large creature that touches or enters the area makes a Reflex Save.

You can designate creatures that don't trigger this effect.

| | |
|---|---|
| Fail | You restrain the target and hoist it into the air, hanging upside down **3** feet above the ground. A creature within Reach of the target can Utilize to make an Athletics Check against your Spell Save DC; on a success, this Spell ends on the target. |
| Success | The rope vanishes without effect and this Spell ends. |

###### Search
Search Action
{ .subtitle }

A creature that can see the area can make a Perception or Survival Check against your Spell Save DC.

| | |
|---|---|
| Success | The rope becomes visible to that creature. |
