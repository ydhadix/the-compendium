### Snare
1st-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Druid, Ranger, Wizard |
| Components | S, M _(consumes rope)_ |
| Casting Time | Magic Action, or Ritual |
| Range | Reach |
| Area | |
| Target | Special |
| Duration | 8 hours |

---

The Material Component surrounds a **5**-foot radius circle on the ground and is Invisible and Hidden _(Hide DC **Spell Save DC**)_.

The first Small, Medium, or Large creature that touches or enters the area makes a Reflex Save.

You can designate creatures that don't trigger this effect.

| | |
|---|---|
| Fail | You restrain the target and hoist it into the air, hanging upside down **3** feet above the ground. |
| Success | The rope vanishes without effect and this Spell ends. |
