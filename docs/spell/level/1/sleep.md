### Sleep
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | Each Creature in a 5-ft. radius Sphere |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | You incapacitate the target. |
| Success | No effect. |

Before a target's Turn ends, it makes a Will Save.

| | |
|---|---|
| Fail | You put the target to Sleep. |
| Success | This Spell ends on the target. |

#### At Higher Levels
Add **5** feet to the radius per additional Spell Level.
