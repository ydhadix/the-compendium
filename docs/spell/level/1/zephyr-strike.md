### Zephyr Strike
1st-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V |
| Casting Time | Bonus Action |
| Range | — |
| Area | |
| Target | Self |
| Duration | 1 minute (Concentration) |

---

Your Speed increases by **10** feet, and your movement doesn't provoke Opportunity Attacks.

##### Exert
**Free Action:** You can shorten this Spell's Duration to the end of the Turn. If you do, your Speed increases by an additional **30** feet, and the next Weapon Attack you make gains Advantage and deals an additional **1d8** Force Damage.
