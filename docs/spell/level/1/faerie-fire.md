### Faerie Fire
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Druid |
| Components | V |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | Each Creature or Object in a 20-ft. Cube |
| Duration | 1 minute (Concentration) |

---

Each target makes a Reflex Save.

| | |
|---|---|
| Fail | The target is outlined in light and gains the following effects:<ul><li>It emits Bright Light out to **5** feet.</li><li>It can't benefit from being Invisible.</li><li>Creatures gain Advantage on Attack Rolls against it.</li></ul> |
| Success | No effect. |
