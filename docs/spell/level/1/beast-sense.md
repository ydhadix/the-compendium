### Beast Sense
1st-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Ranger |
| Components | S |
| Casting Time | Magic Action, or Ritual |
| Range | Reach |
| Area | — |
| Target | **1** Ally Beast |
| Duration | 1 hour (Concentration) |

---

You can perceive through the target's senses; while doing so, you are Blinded and Deafened to your own senses.

##### Switch Senses
**Free Action; Once per Turn:** You can switch between your own senses and the target's.
