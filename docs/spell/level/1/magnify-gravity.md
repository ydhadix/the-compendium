### Magnify Gravity
1st-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | Each creature in a 10-ft. radius Sphere |
| Duration | Until the end of your next Turn |

Objects in the area that aren't worn or carried can't be moved or picked up. A creature can make an Athletics Check against your Spell Save DC to end this Spell on such an object _(no action required)_.

Each creature in a **10**-foot radius Sphere makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **2d8** Force Damage, and the target's Speed is halved. |
| Success | You deal half as much damage. |

##### At Higher Levels

Add **1d8** Force Damage and **5** feet to the radius per additional Spell Level.
