### Hunter's Mark
1st-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V |
| Casting Time | Bonus Action |
| Range | 90 ft. |
| Target | One creature |
| Duration | 1 hour (Concentration) |

You have Advantage on Perception and Survival Checks to find the target.

Before you deal damage to the target with an Attack, you add **1d6** Force Damage.

As a Bonus Action, if the target has **0** Hit Points, you can move the mark to a new target.

##### At Higher Levels

When Upcast to 2nd- or 3rd-Level, the Duration is 8 hours (Concentration).

When Upcast to 4th-Level or higher, the Duration is 24 hours (Concentration).
