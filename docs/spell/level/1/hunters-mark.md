### Hunter's Mark
1st-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V |
| Casting Time | Bonus Action |
| Range | 90 ft. |
| Area | |
| Target | **1** Creature |
| Duration | 1 hour (Concentration) |

---

You mark each target.

You gain the following effects against Marked targets:

- You gain Advantage on Perception and Survival Checks to find the target.
- Your Attacks against each target deal an additional **1d6** Force Damage.

##### Mark
**Bonus Action:** If the target has **0** Hit Points, you can move the mark to a new target.

#### At Higher Levels
When Upcast to 2nd- or 3rd-Level, the Duration is **8** hours (Concentration).

When Upcast to 4th-Level or higher, the Duration is **24** hours (Concentration).
