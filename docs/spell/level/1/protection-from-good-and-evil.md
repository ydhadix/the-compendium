### Protection from Good & Evil
1st-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid, Paladin, Warlock, Wizard |
| Components | V, S, M _(consumes holy water worth 25 Gold)_ |
| Casting Time | Normal Action |
| Range | Reach |
| Target | One creature |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
The target is protected against Aberrations, Celestials, Elementals, Fey, Fiends, and Undead.

Those creatures have Disadvantage on Attack Rolls against the target.

The target can't be possessed, Charmed, or Frightened by those creatures, and has Advantage on Saves against those conditions if already affected.

##### At Higher Levels
Add **1** target per additional Spell Level.
