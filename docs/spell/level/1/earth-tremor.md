### Earth Tremor
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | — |
| Target | Everything on the ground in a 10-ft. Aura |
| Duration | — |

##### Spell Effect
Loose earth or stone in the area becomes nonmagical Difficult Terrain.

Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **1d6** Bludgeoning Damage, and you knock the target Prone. |
| Success | No effect. |

##### At Higher Levels
Add **1d6** damage and **5** feet to the Aura per additional Spell Level.
