### Binding Ice
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | Reach |
| Target | Everything in a 15-ft. Cone |
| Duration | — |

##### Spell Effect
Nonmagical liquid in the area freezes. Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **2d8** Cold Damage. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d8** Cold Damage and **15** feet of Cone size per additional Spell Level.

When Upcast to 2nd-Level or higher, a target that fails also has its Speed become **0** feet for **1** minute. A creature other than the target can take a Utilize Action to end this Spell on that target.
