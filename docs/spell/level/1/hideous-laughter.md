### Hideous Laughter
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Warlock, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | |
| Target | **1** Creature |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | You incapacitate the target and knock it Prone, and it can't stand up. |
| Success | No effect. |

Before a target's Turn ends, it makes a Will Save. After a target takes damage, it also makes a Will Save with Advantage.

| | |
|---|---|
| Fail | No additional effect. |
| Success | This Spell ends on the target. |

#### At Higher Levels
Add **1** target per additional Spell Level.
