### Healing Word
1st-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid |
| Components | V |
| Casting Time | Bonus Action |
| Range | 60 ft. |
| Target | One creature |
| Duration | — |

##### Spell Effect
You heal the target by **2d4 + Spellcasting Ability**.

##### At Higher Levels
Add **2d4** to the healing per additional Spell Level.
