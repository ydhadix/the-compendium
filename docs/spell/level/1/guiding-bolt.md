### Guiding Bolt
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | One thing |
| Duration | Until the end of your next Turn |

##### Spell Effect
You make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **4d6** Radiant Damage, and the next Attack Roll against the target gains Advantage, then this Spell ends. |

##### At Higher Levels
Add **1d6** Radiant Damage per additional Spell Level.
