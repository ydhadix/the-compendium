### Chromatic Orb
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M _(a diamond worth 50 Gold)_ |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | One thing |
| Duration | — |

##### Spell Effect
Choose an Elemental Damage Type and make a Ranged Spell Attack against the target.

| | |
|---|---|
| Hit | You deal **3d8** damage of the chosen type. If you roll the same number on two of the Damage Dice, you can choose a new target within **30** feet of the previous target and repeat this attack. You can repeat this attack only once per Level of this Spell. |

##### At Higher Levels
Add **1d8** damage per additional Spell Level.
