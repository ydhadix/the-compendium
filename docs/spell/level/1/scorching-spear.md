### Scorching Spear
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | Reach |
| Target | Everything in a 5-ft. × 30-ft. Line |
| Duration | — |

##### Spell Effect
Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **3d8** Fire Damage. A flammable object starts Burning (**1d4**). |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d8** Fire Damage and **15** feet to the Line per additional Spell Level.
