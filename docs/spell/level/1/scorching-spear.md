### Scorching Spear
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | Each Creature or Object in a 30-ft. × 5-ft. Line |
| Duration | — |

---

Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **3d8** Fire Damage. You burn _(**1d4**)_ a flammable object. |
| Success | You deal half as much damage. |

#### At Higher Levels
Add **1d8** damage and **15** feet to the Line per additional Spell Level.
