### Caustic Brew
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | — |
| Target | Each creature in a 5-ft. × 30-ft. Line |
| Duration | 1 minute (Concentration) |

##### Spell Effect
Each creature in a **5**-foot × **30**-foot Line makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **2d4** Acid Damage, and you corrode the target (**2d4**). A creature within Reach of the target can Utilize to end this Spell on it. |
| Success | This Spell ends on the target. |

##### At Higher Levels
Add **2d4** Acid Damage and **2d4** Corrosion damage per additional Spell Level.
