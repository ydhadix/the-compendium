### Caustic Brew
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | — |
| Area | |
| Target | Each Creature or Object in a 30-ft. × 5-ft. Line |
| Duration | 1 minute (Concentration) |

---

Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **2d4** Acid Damage, and you corrode _(**2d4**)_ the target. |
| Success | This Spell ends on the target. |

##### Scrape Off
**Utilize Action:** Any creature that can reach a Corroded target can end this Spell on it.

#### At Higher Levels
Add **2d4** Acid Damage and **2d4** Corrosion Damage per additional Spell Level.
