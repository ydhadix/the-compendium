### Caustic Brew
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | — |
| Target | Everything in a 30-ft. × 5-ft. Line |
| Duration | 1 minute (Concentration) |

##### Spell Effect
Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **2d4** Acid Damage, and you corrode _(**2d4**)_ the target; a creature with the target within its Reach can Utilize to end this effect on it. |
| Success | This effect ends on the target. |

##### At Higher Levels
Add **2d4** Acid Damage and **2d4** Corrosion Damage per additional Spell Level.
