### Entangle
1st-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Ranger |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | Each creature in a 20-ft. Square on the ground |
| Duration | 1 minute (Concentration) |

##### Spell Effect
The area is Difficult Terrain. Each creature in a **20**-foot Square makes a Fortitude Save.

| | |
|---|---|
| Fail | You restrain the target. A creature within Reach of the target can Utilize to make an Athletics Check against your Spell Save DC; on a success, this Spell ends on the target. |
| Success | No effect. |
