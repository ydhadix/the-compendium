### Unseen Servant
1st-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Warlock, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action, or Ritual |
| Range | 60 ft. |
| Area | |
| Target | — |
| Duration | 1 hour |

---

You create an invisible, mindless, shapeless, Medium force that performs simple tasks at your command. The servant has Armor Class **10**, **1** Hit Point, Strength -5, and can't attack.

##### Command
**Bonus Action:** You can command the servant to move up to **15** feet and interact with an object. It performs the task to the best of its ability until complete, then awaits your next command.

#### Ending Early
This Spell ends if the servant has **0** Hit Points or you command it to move outside this Spell's range.
