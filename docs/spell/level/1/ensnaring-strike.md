### Ensnaring Strike
1st-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V |
| Casting Time | Bonus Action, when you hit with a Weapon Attack |
| Range | — |
| Area | |
| Target | The target of the Attack |
| Duration | 1 minute (Concentration) |

---

Each target makes a Fortitude Save. A creature larger than you gains Advantage.

| | |
|---|---|
| Fail | You restrain the target. After the target's Turn starts, you deal **1d6** Piercing Damage. |
| Success | No effect. |
