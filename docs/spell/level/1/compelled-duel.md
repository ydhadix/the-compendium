### Compelled Duel
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Paladin |
| Components | V |
| Casting Time | Bonus Action |
| Range | 30 ft. |
| Target | One creature |
| Duration | 1 minute (Concentration) |

##### Spell Effect
The target makes a Will Save.

| | |
|---|---|
| Fail | The target gains Disadvantage on Attack Rolls that don't target you, and it can't willingly move out of Range. This Spell ends if you attack or cast a Spell on an Enemy other than the target, if an Ally damages the target, or if you end your Turn while the target is out of Range. |
| Success | No effect. |
