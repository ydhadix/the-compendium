### Thunderous Smite
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Paladin |
| Components | V |
| Casting Time | Bonus Action, when you hit with a Melee Weapon Attack |
| Range | — |
| Target | The target of the attack |
| Duration | — |

You deal **2d6** Thunder Damage, and the target makes a Fortitude Save.

| | |
|---|---|
| Fail | You push the target **10** feet away from you and knock it Prone. |
| Success | No effect. |

This Spell's thunder is audible out to **300** feet.

##### At Higher Levels

Add **1d6** Thunder Damage per additional Spell Level.
