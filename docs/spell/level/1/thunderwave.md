### Thunderwave
1st-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Druid, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | Each Creature or Object in a 15-ft. Cube |
| Duration | — |

---

Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **2d8** Thunder Damage, and you propel the target **10** feet away from you and knock it Prone. |
| Success | You deal half as much damage. |

This Spell's thunder is audible out to **300** feet.

#### At Higher Levels
Add **1d8** damage and **5** feet to the Cube per additional Spell Level.
