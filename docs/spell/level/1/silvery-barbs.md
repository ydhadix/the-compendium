### Silvery Barbs
1st-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard |
| Components | V |
| Casting Time | Reaction, when a creature succeeds on a d20 roll |
| Range | 60 ft. |
| Target | The succeeding creature |
| Duration | — |

##### Spell Effect
The target rerolls the d20 and uses the lower roll.
