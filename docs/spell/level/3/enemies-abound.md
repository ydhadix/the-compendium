### Enemies Abound
3rd-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Area | — |
| Target | **1** Creature |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save. If a target has Fear Immunity, it automatically succeeds.

| | |
|---|---|
| Fail | The target chooses the targets of its Attacks, Spells, and other effects at random from among the creatures it can see, and it makes an Opportunity Attack against any Creature that provokes one, if able. |
| Success | No effect. |

#### Ending Early
After a target takes damage, it repeats this Saving Throw.

| | |
|---|---|
| Fail | No additional effect. |
| Success | This Spell ends on the target. |
