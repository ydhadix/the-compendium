### Sleet Storm
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 150 ft. |
| Target | Each other creature in a 40-ft. radius, 20-ft. Cylinder from above |
| Duration | 1 minute (Concentration) |

##### Spell Effect
The area is Heavily Obscured, exposed flames in it are doused, and the ground in the area is Difficult Terrain.

After a target enters the area __(including when this Spell is cast)__, it makes a Reflex Save.  After your Turn starts, each target also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You knock the target Prone, and it loses Concentration. |
| Success | No effect. |
