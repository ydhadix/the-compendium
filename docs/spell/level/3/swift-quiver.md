### Swift Quiver
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V, S, M _(a Quiver worth 1 Gold)_ |
| Casting Time | Bonus Action |
| Range | — |
| Target | Self |
| Duration | 1 minute (Concentration) |

##### Spell Effect
You make two Attacks using a Bow or Crossbow. This Spell creates the ammunition for each Attack, and you can change the Damage Type to Force; the ammunition vanishes after the Attack.

###### Draw
Bonus Action
{ .subtitle }

You repeat the Attacks _(you can choose new targets)_.
