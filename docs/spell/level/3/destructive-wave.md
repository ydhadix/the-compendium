### Destructive Wave
5th-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Paladin |
| Components | V |
| Casting Time | Normal Action |
| Range | — |
| Target | Each creature you choose in a 30-ft. Aura |
| Duration | — |

##### Spell Effect
Choose Radiant or Necrotic.  Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **3d6** Thunder Damage and **3d6** damage of the chosen type, and you knock the target Prone. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d6** to both damage rolls per additional Spell Level.
