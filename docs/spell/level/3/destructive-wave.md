### Destructive Wave
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Paladin |
| Components | V |
| Casting Time | Magic Action |
| Range | — |
| Area | A 30-ft. Aura |
| Target | Each Creature you choose |
| Duration | — |

---

Choose Radiant or Necrotic Damage.

Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **3d6** Thunder Damage and **3d6** damage of the chosen type, and you knock the target Prone. |
| Success | You deal half as much damage. |

#### At Higher Levels
Add **1d6** to both damage rolls per additional Spell Level.
