### Minute Meteors
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | Self |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
You create **6** meteors that orbit you for the Duration.

###### Launch
Bonus Action
{ .subtitle }

You expend up to **2** meteors, sending each toward a point within Range. Each creature in a **5**-foot radius Sphere around a point makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **2d6** Fire Damage. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **2** meteors per additional Spell Level.
