### Hypnotic Pattern
3rd-Level Illusion
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Warlock, Wizard |
| Components | S, M |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Target | Each creature in a 30-ft. Cube |
| Duration | 1 minute (Concentration) |

##### Spell Effect
Each target makes a Will Save.

| | |
|---|---|
| Fail | You charm the target. While Charmed by you, it is Immobile and Incapacitated. |
| Success | No effect. |

This effect ends on a target if it takes damage or a creature with the target within its Reach Utilizes to shake it awake.
