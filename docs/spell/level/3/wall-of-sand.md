### Wall of Sand
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 90 ft. |
| Area | A 30-ft. × 10-ft. × 10-ft. Wall |
| Target | — |
| Duration | 10 minutes (Concentration) |

---

The area is Heavily Obscured, and each foot a creature moves through or out of the area costs **2** extra feet.
