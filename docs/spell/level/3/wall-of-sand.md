### Wall of Sand
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | — |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
You create a wall of swirling sand on the ground, up to **30** feet long, **10** feet high, and **10** feet thick. It blocks vision but not movement.

While in the wall's space, a creature is Blinded and spends **3** feet of movement for every **1** foot it moves.
