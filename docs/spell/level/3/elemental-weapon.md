### Elemental Weapon
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Druid, Paladin, Ranger |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Area | — |
| Target | **1** Weapon |
| Duration | 1 hour (Concentration) |

---

Choose an Elemental Damage Type.

The target deals an additional **1d4** damage of the chosen type and can deal the chosen Damage Type instead of its normal Damage Type.

#### At Higher Levels
Add **1d4** damage per additional Spell Level.
