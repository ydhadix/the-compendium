### Dispel Magic
3rd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Cleric, Druid, Paladin, Ranger, Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Area | — |
| Target | **1** Creature, Object, or magical effect with a duration |
| Duration | — |

---

If the target is a magical effect, you make an Ability Check using your Spellcasting Ability _(DC **10 + the target's Spell Level**)_.  If the target's Spell Level is no higher than this Spell's, you automatically succeed.

| | |
|---|---|
| Success | You dispel the target. |
| Fail | No effect. |

If the target is a Creature or Object, you make this Ability Check for each magical effect with a duration on the target.

| | |
|---|---|
| Success | You dispel the effect on the target. |
| Fail | No effect. |
