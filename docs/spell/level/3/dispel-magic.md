### Dispel Magic
3rd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Cleric, Druid, Paladin, Ranger, Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Target | One magical effect or thing |
| Duration | — |

##### Spell Effect
All Spells on the target end if their Level is no higher than this Spell's. For each Spell of a higher Level, make an Ability Check using your Spellcasting Ability against a DC of **10** plus that Level; on a success, that Spell ends.
