### Slow
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | Up to six creatures |
| Duration | 1 minute (Concentration) |

##### Spell Effect
Each target makes a Will Save.

| | |
|---|---|
| Fail | The target has the following effects:<ul><li>its Speed becomes halved.</li><li>its Armor Class decreases by **2**, and its Reflex Saves decrease by **2**.</li><li>it is Dazed.</li><li>if it Attacks, it can make only one attack.</li><li>a Spell it casts with a Somatic Component fails on a d20 roll of **5** or lower.</li></ul> |
| Success | No effect. |

Before each of a target's Turns ends, it repeats this Saving Throw.  On a success, this effect ends on the target.
