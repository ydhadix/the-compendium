### Slow
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Area | — |
| Target | Up to **6** Creatures |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | The target gains the following effects:<ul><li>You daze the target.</li><li>Its Speed becomes halved.</li><li>Its Armor Class decreases by **2**, and its Reflex Saves decrease by **2**.</li><li>If it Attacks, it can make only **1** attack.</li><li>A Spell it casts with a Somatic Component has a **25**% chance to have no effect.</li></ul> |
| Success | No effect. |

#### Ending Early
Before a target's Turn ends, it repeats this Saving Throw.

| | |
|---|---|
| Fail | No additional effect. |
| Success | This Spell ends on the target. |
