### Animate Objects
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Target | Up to 3 objects |
| Duration | 1 minute (Concentration) |

##### Spell Effect
You animate nonmagical objects that aren't worn, carried, fixed in place, or Gargantuan.  A Large object counts as **2** of your targets, and a Huge object as **3**.

Each target becomes a Companion Construct that uses the Animated Object stat block.  When a target has **0** Hit Points, it reverts to an object and any remaining damage carries over.

###### Command
Bonus Action
{ .subtitle }

You can command your animated objects within **500** feet to move and take any Action available to them.

##### At Higher Levels
Add **1** target per additional Spell Level.

The Spell Level determines the objects' Slam damage.
