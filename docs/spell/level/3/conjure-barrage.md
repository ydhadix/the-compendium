### Conjure Barrage
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V, S, M _(a Melee or Ranged Weapon)_ |
| Casting Time | Normal Action |
| Range | Reach |
| Target | Each creature you choose in a 60-ft. Cone |
| Duration | — |

##### Spell Effect
Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **5d8** Force Damage. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d8** damage per additional Spell Level.
