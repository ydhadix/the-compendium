### Daylight
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid, Paladin, Ranger, Sorcerer |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | A 60-ft. radius Sphere |
| Target | Up to **1** Object |
| Duration | 1 hour |

---

If a target is an Object, the Area is a **60**-foot Aura centered on the target.

The area is filled with Bright Sunlight and emits Dim Sunlight **60** feet further.

If the area overlaps any Darkness conjured by a lower-Level Spell, you dispel it.
