### Daylight
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid, Paladin, Ranger, Sorcerer |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | A 60-ft. radius Sphere, or one object |
| Duration | 1 hour |

If the target is an object, the area is a **60**-foot Aura centered on the target, which can be covered or hidden. The area is filled with bright sunlight and emits Dim Light for an additional **60** feet.

When the area overlaps Darkness created by a Spell of a lower Level than this one, that Spell ends early.
