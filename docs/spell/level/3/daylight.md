### Daylight
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid, Paladin, Ranger, Sorcerer |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | A 60-ft. radius Sphere, or **1** Object |
| Duration | 1 hour |

---

If a target is an object, the area is a **60**-foot Aura centered on the target, which can be covered or hidden.

The area is filled with Bright Sunlight and emits Dim Sunlight **60** feet further.

If the area overlaps any Darkness conjured by a lower-Level Spell, that Spell ends early.
