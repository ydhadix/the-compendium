### Animate Dead
3rd-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Wizard |
| Components | V, S, M |
| Casting Time | 1 minute |
| Range | 10 ft. |
| Area | — |
| Target | **1** Humanoid Corpse, or up to **4** Undead you animated |
| Duration | 24 hours |

---

You can cast this Spell only at night.

If a target is a Corpse, you animate it as a Skeleton Companion if it is just bones, or a Zombie Companion otherwise.

If a target is an Undead you animated, it becomes your Companion.

After this Spell ends, each target stops being your Companion but remains animated.

##### Command Undead
**Bonus Action:** You can command any of your Undead companions within **60** feet to move and take any Action available to them.  You give the same command to each target.

#### At Higher Levels
Add **2** targets per additional Spell Level.
