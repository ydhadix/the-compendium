### Banishing Smite
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Paladin |
| Components | V |
| Casting Time | Bonus Action, when you hit with a Melee Weapon Attack |
| Range | — |
| Area | |
| Target | The target of the Attack |
| Duration | 1 minute (Concentration) |

---

You deal **3d10** Force Damage.

If the Attack reduces the target to **30** Hit Points or fewer, it makes a Will Save.

| | |
|---|---|
| Fail | You banish the target to a harmless demiplane and incapacitate it.  After this Spell ends, it returns to the space it left, or the nearest unoccupied space. |
| Success | No effect. |

#### At Higher Levels
Add **1d10** damage and **10** to the Hit Point threshold per additional Spell Level.
