### Antagonize
3rd-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Warlock, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | |
| Target | **1** Creature |
| Duration | — |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | You deal **4d4** Psychic Damage, and the target immediately uses its Reaction to make a Melee Attack against another creature within its Reach.<br>If the target can't make the Attack, it instead gains Disadvantage on its next Attack Roll before the start of your next Turn. |
| Success | You deal half as much damage. |

#### At Higher Levels
Add **1d4** damage per additional Spell Level.
