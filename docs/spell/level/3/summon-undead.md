### Summon Undead
3rd-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Warlock, Wizard |
| Components | V, S, M _(a gilded skull worth 300 Gold)_ |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | — |
| Duration | 1 hour (Concentration) |

##### Spell Effect
You summon an Undead Spirit. Choose Ghostly, Putrid, or Skeletal.

This Spell ends if the Spirit has **0** Hit Points.

###### Command
Free Action
{ .subtitle }

You command the Spirit to move and take any Action available to it.

##### At Higher Levels
The Spell's Level determines the Spirit's Armor Class, Hit Points, and attack damage.
