### Aura of Purity
3rd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Paladin |
| Components | V |
| Casting Time | Magic Action |
| Range | — |
| Area | A 30-ft. Aura |
| Target | You and each Ally |
| Duration | 10 minutes (Concentration) |

---

Each target gains Poison Resistance and Blinded, Charmed, Deafened, Frightened, Paralyzed, Sickened, and Stunned Protection.
