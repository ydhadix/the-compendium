### Clairvoyance
3rd-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Sorcerer, Wizard |
| Components | V, S, M _(a jeweled horn or glass eye worth 100 Gold)_ |
| Casting Time | 10 minutes |
| Range | 1 mile |
| Target | — |
| Duration | 10 minutes (Concentration) |

Choose seeing or hearing. You create an intangible, Invisible, invulnerable sensor and can perceive using the chosen sense from the sensor's space.

As a Bonus Action, you switch between seeing and hearing.
