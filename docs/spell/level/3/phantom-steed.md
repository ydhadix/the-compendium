### Phantom Steed
3rd-Level Illusion
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S |
| Casting Time | 1 minute, or Ritual |
| Range | 30 ft. |
| Target | — |
| Duration | 1 hour |

##### Spell Effect
A Large, horselike Phantom Steed appears in an unoccupied space, equipped with a saddle, bit, and bridle. You or another creature can ride it. Any of this equipment vanishes if it is carried more than **10** feet from the Steed.

This Spell ends if the Steed takes any damage. After this Spell ends, the Steed fades over **1** minute, giving its rider time to dismount.
