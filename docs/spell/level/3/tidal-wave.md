### Tidal Wave
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Area | A 30-ft. × 10-ft. Line |
| Target | Each Creature and Object |
| Duration | — |

---

Exposed flames in the area and within **30** feet of it are doused.

Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **4d8** Bludgeoning Damage, propel the target up to **15** feet, and knock the target Prone. |
| Success | You deal half as much damage. |
