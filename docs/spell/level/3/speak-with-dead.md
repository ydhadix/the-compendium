### Speak with Dead
3rd-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 10 ft. |
| Target | One corpse with a mouth |
| Duration | 10 minutes |

You can ask the target up to **5** questions. The target is animated enough to respond, knows only what it knew in life, and isn't compelled to answer truthfully. Its soul isn't returned to its body; it can't learn new information, comprehend anything that happened since it died, or speculate about the future.
