### Mass Healing Word
3rd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric |
| Components | V |
| Casting Time | Bonus Action |
| Range | 60 ft. |
| Target | Up to six creatures |
| Duration | — |

You heal each target by **2d4 + Spellcasting Ability**.

##### At Higher Levels

Add **1d4** to the healing per additional Spell Level.
