### Silver Lance
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Sorcerer, Wizard |
| Components | V, S, M _(a silver pin worth 250 Gold)_ |
| Casting Time | Normal Action |
| Range | — |
| Target | Each creature in a 5-ft. × 120-ft. Line |
| Duration | — |

Each creature you choose in a **5**-foot × **120**-foot Line makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **3d10** Force Damage, and you knock the target Prone. |
| Success | You deal half as much damage. |

##### At Higher Levels

Add **1d10** damage per additional Spell Level.
