### Erupting Earth
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 120 ft. |
| Target | Everything in a 20-ft. Cube |
| Duration | — |

##### Spell Effect
The area becomes Difficult Terrain indefinitely.

Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **3d12** Bludgeoning Damage. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d12** damage per additional Spell Level.
