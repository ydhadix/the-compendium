### Blink
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | — |
| Target | Self |
| Duration | 1 minute |

##### Spell Effect
Before each of your Turns ends, roll a d6. On a **4** or higher, you vanish into the Ethereal Plane.

While on the Ethereal Plane, you perceive the plane you left in shades of gray out to **60** feet, and you can affect and be affected only by other creatures on the Ethereal Plane.

After your next Turn begins, you return to an unoccupied space within **10** feet of the space you left, or the nearest unoccupied space if none is available. If this Spell ends while you are on the Ethereal Plane, you return the same way.
