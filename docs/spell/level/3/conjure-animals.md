### Conjure Animals
3rd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Ranger |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | Anything you choose in a 15-ft. radius Sphere |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
You gain Advantage on Fortitude Saves while in the area.

After a target enters the area __(including when this Spell is cast or the area moves)__, it makes a Reflex Save.  After your Turn starts, each target also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You deal **3d10** Slashing Damage. |
| Success | You deal half as much damage. |

###### Move
Free Action
{ .subtitle }

You can move the area up to **30** feet.

##### At Higher Levels
Add **1d10** damage per additional Spell Level.
