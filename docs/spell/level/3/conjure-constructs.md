### Conjure Constructs
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | Each Creature or Object in a 5-ft. radius Sphere |
| Duration | 10 minutes (Concentration) |

---

After a target enters the area _(including when this Spell is cast or the area moves)_, choose **1** of the following effects for it.  After your Turn starts, you also make this choice for each target.  A target can only be affected once until the start of your next Turn.

| Effect | |
|---|---|
| Orderly Ward | The target gains **1d6 + Spellcasting Ability** Temporary Hit Points. |
| Clockwork Force | The target makes a Reflex Save.<br>**Fail.** You deal **3d6** Force Damage.<br>**Success.** You deal half as much damage. |

##### Move
**Free Action:** You can move the area up to **30** feet.

#### At Higher Levels
Add **1d6** damage and Temporary Hit Points per additional Spell Level.
