### Conjure Constructs
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | Everything in a 5-ft. radius Sphere |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
After your Turn starts, choose one of the following effects for each target.  After a target enters the area (including when this Spell is cast or the area moves), you also make this choice.  A target can only be affected once until the start of your next Turn.

| | |
|---|---|
| Orderly Ward | The target gains **1d6 + Spellcasting Ability** Temporary Hit Points. |
| Clockwork Force | The target makes a Reflex Save. |

| | |
|---|---|
| Fail | You deal **3d6** Force Damage. |
| Success | You deal half as much damage. |

###### Move
Free Action
{ .subtitle }

You can move the area up to **30** feet.

##### At Higher Levels
Add **1d6** damage and Temporary Hit Points per additional Spell Level.
