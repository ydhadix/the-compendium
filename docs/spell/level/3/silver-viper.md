### Silver Viper
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Wizard |
| Components | V, S, M |
| Casting Time | Bonus Action |
| Range | — |
| Target | Self |
| Duration | 1 hour |

You gain **15** Temporary Hit Points and a Climb Speed equal to your Speed. This Spell ends if you have no Temporary Hit Points.

As a Magic Action, you make a Ranged Spell Attack against a target within **50** feet.

| | |
|---|---|
| Hit | You deal **1d6** Poison Damage, and you sicken the target until the end of your next Turn. While Sickened this way, the target is also Incapacitated. |

##### At Higher Levels

Add **5** Temporary Hit Points and **1d6** damage per additional Spell Level.
