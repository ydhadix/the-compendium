### Lightning Bolt
3rd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | Reach |
| Target | Everything in a 100-ft. × 5-ft. Line |
| Duration | — |

##### Spell Effect
Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **8d6** Lightning Damage. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d6** damage and **10** feet to the length per additional Spell Level.
