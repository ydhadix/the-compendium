### Secret Chest
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M _(a chest worth 5,000 Gold and a Tiny replica worth 50 Gold)_ |
| Casting Time | Magic Action |
| Range | Reach |
| Area | — |
| Target | The Chest used as a Material Component |
| Duration | Until dispelled |

---

You teleport the target and its contents to the Ethereal Plane.

After the replica is destroyed, this Spell ends.  After you cast this Spell again, the previous casting ends.  After **60** days, each day has a cumulative **5**% chance of ending this Spell.

##### Recall
**Magic Action:** While holding the replica, you can recall the target, which appears on the ground within **5** feet of you.

##### Send Back
**Magic Action:** While holding the replica and the target, you can send the target back to the Ethereal Plane.
