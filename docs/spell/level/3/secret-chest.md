### Secret Chest
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M _(a chest worth 5,000 Gold and a Tiny replica worth 50 Gold)_ |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | — |
| Duration | Until dispelled |

---

You hide a chest and its contents on the Ethereal Plane. The chest holds up to **12** cubic feet of nonliving material.

##### Recall
**Magic Action:** While holding the replica, you can recall the chest, which appears on the ground within **5** feet of you.

##### Send Back
**Magic Action:** While holding the replica and the chest, you can send the chest back to the Ethereal Plane.

#### Ending Early
This Spell ends if you cast it again or the replica is destroyed, and after **60** days, each day has a cumulative **5**% chance of ending it.
