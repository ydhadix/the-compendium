### Aura of Vitality
3rd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid, Paladin |
| Components | V |
| Casting Time | Magic Action |
| Range | — |
| Area | A 30-ft. Aura |
| Target | Each Creature |
| Duration | 1 minute (Concentration) |

---

After you cast this Spell and after your Turn starts, you can heal **1** target by **2d6**.
