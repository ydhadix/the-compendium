### Life Transference
3rd-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | — |
| Target | **1** Creature |
| Duration | — |

---

You reduce your Hit Points by **4d8** _(this is not damage)_ and heal the target by twice as much.

#### At Higher Levels
Add **1d8** per additional Spell Level.
