### Call Lightning
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Area | |
| Target | Each Creature or Object in a 10-ft. radius, 60-ft. Cylinder from above |
| Duration | 10 minutes (Concentration) |

---

If you cast this Spell while outdoors in a storm, the storm and the area beneath it become this Spell's area instead.

Choose a **5**-foot radius Sphere within the area.

Each Creature in it makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **3d10** Lightning Damage, or an additional **1d10** if this Spell's area is a storm. |
| Success | You deal half as much damage. |

##### Lightning Strike
**Bonus Action:** You can repeat this Spell's effect.

#### At Higher Levels
Add **1d10** damage per additional Spell Level.
