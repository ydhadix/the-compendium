### Conjure Volley
3rd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V, S, M _(a Melee or Ranged Weapon worth at least 1 Copper)_ |
| Casting Time | Magic Action |
| Range | 150 ft. |
| Area | |
| Target | Each Creature you choose in a 40-ft. radius, 20-ft. Cylinder from above |
| Duration | — |

---

Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **6d8** Force Damage. |
| Success | You deal half as much damage. |

#### At Higher Levels
Add **1d8** damage per additional Spell Level.
