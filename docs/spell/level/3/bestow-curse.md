### Bestow Curse
3rd-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | **1** Creature |
| Duration | 1 minute (Concentration) |

---

Choose **1** of the following effects:

| Effect | |
|---|---|
| Cowardice | After the target's Turn starts, it makes a Will Save; on a failure, it Dodges. |
| Rot | After the target takes damage, you deal an additional **1d8** Necrotic Damage. |
| Sloth | Choose an Ability. The target gains Disadvantage on Checks and Saves using that Ability. |
| Weakness | The target gains Disadvantage on Attack Rolls. |

Each target makes a Will Save.

| | |
|---|---|
| Fail | You curse the target with the chosen effect. |
| Success | No effect. |

#### At Higher Levels
When Upcast to 4th-Level, the Duration becomes **10** minutes.

When Upcast to 5th- or 6th-Level, the Duration becomes **8** hours and doesn't require Concentration.

When Upcast to 7th- or 8th-Level, the Duration becomes **24** hours and doesn't require Concentration.

When Upcast to 9th-Level, the Duration becomes until dispelled and doesn't require Concentration.
