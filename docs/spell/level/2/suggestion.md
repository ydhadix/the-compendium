### Suggestion
2nd-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Warlock, Wizard |
| Components | V, M |
| Casting Time | Normal Action |
| Range | 30 ft. |
| Target | One creature who understands you |
| Duration | 8 hours (Concentration) |

You suggest a course of activity to the target, then it makes a Will Save.

| | |
|---|---|
| Fail | You charm the target. While Charmed, it follows the suggestion to the best of its ability. This Spell ends when the target completes the suggested activity, or when you or an ally deal damage to it. |
| Success | No effect. |

##### At Higher Levels

Add **1** target per additional Spell Level.
