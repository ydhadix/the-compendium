### Web
2nd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | A 20-ft. Cube |
| Target | Each Creature and Object |
| Duration | 1 hour (Concentration) |

---

You conjure sticky webbing in the area.  The area is Difficult Terrain and Lightly Obscured.

The webs are flammable.  Any **5**-foot Cube of webs exposed to fire burns away in **1** Round, dealing **2d4** Fire Damage to everything that enters or starts its Turn in the fire.

After a target enters the area _(including when this Spell is cast)_, it makes a Reflex Save.  After your Turn starts, each target also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You restrain the target. |
| Success | No effect. |
