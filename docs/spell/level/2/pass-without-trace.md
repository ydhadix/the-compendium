### Pass Without Trace
2nd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Ranger |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | — |
| Target | Each Creature you choose |
| Duration | 1 hour (Concentration) |

---

Each target's Stealth Checks increase by **10**, and it leaves no tracks.
