### Earthen Grasp
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | — |
| Target | — |
| Duration | 1 minute (Concentration) |

---

You conjure an earthen hand.  The hand is a Medium Object with Immunity to all damage.

You take the following Action as part of casting this Spell.

##### Grasp
**Magic Action:** You can move the hand up to **30** feet, then choose **1** of the following effects:

| Effect | |
|---|---|
| Grappling Hand | A Large or smaller Creature or Object within **5** feet of the hand makes a Reflex Save; on a failure, you deal **2d6** Bludgeoning Damage and the hand grapples the target _(DC **Spell Save DC**)_.  While Grappled by the hand, a target is Restrained.  The hand can only grapple **1** target at a time. |
| Crushing Hand | While the hand is grappling, you can deal **2d6** Bludgeoning Damage to the Grappled target. |

#### At Higher Levels
Add **1d6** to the Grappling Hand and Crushing Hand damage per additional Spell Level.
