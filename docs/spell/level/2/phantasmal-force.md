### Phantasmal Force
2nd-Level Illusion
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | One creature |
| Duration | 1 minute (Concentration) |

##### Spell Effect
The target makes a Will Save.

| | |
|---|---|
| Fail | You create an illusory phantasm no larger than a **10**-foot Cube, including sound, temperature, and other stimuli, that only the target can perceive. The target treats the phantasm as real and rationalizes any illogical outcomes from interacting with it. |
| Success | No effect. |

###### Torment
Free Action
{ .subtitle }

If the target is within **5** feet of the phantasm, you deal **2d8** Psychic Damage to it; the target perceives the damage as a type appropriate to the phantasm.

##### At Higher Levels
Add **1** target per additional Spell Level.
