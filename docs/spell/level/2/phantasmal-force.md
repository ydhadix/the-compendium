### Phantasmal Force
2nd-Level Illusion
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | — |
| Target | **1** Creature |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save.

| | |
|---|---|
| Fail | You conjure a Large or smaller illusion that only the target can perceive.  The target believes the illusion is real and rationalizes any illogical outcomes from interacting with it. |
| Success | No effect. |

##### Torment
**Free Action:** If a target is within **5** feet of the illusion, you can deal **2d8** Psychic Damage to it; the target perceives the damage as a type appropriate to the illusion.
