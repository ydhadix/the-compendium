### Zone of Truth
2nd-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Paladin |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | Each creature in a 15-ft. radius Sphere |
| Duration | 10 minutes |

##### Spell Effect
A creature that enters the area (including when this Spell is cast) or ends its Turn there makes a Will Save. You know whether each target succeeds or fails.

| | |
|---|---|
| Fail | The target can't speak a deliberate lie while in the area. It is aware of this effect and isn't forced to speak. |
| Success | No effect. |
