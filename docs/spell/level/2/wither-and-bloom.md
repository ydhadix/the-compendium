### Wither and Bloom
2nd-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Warlock |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | Each creature in a 10-ft. radius Sphere |
| Duration | 1 minute (Concentration) |

##### Spell Effect
One target can expend and roll up to **1** Hit Die, then heals by the total rolled plus your Spellcasting Ability.

Each other target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **2d6** Necrotic Damage. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add up to **1** Hit Die, **1d6** damage, and **10** feet to the radius per additional Spell Level.
