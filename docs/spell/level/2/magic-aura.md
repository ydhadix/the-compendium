### Magic Aura
2nd-Level Illusion
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | Reach |
| Target | One creature or object |
| Duration | 24 hours |

##### Spell Effect
You alter how the target appears to Spells and magical effects.

| | |
|---|---|
| Creature | Choose a Creature Type. The target is treated as a creature of the chosen type instead of its usual type _(Spells and effects that affect only the chosen type can affect the target)_. |
| Object | Choose one School of Magic, or none. The target appears to contain magic of the chosen School, or to be nonmagical. |

##### At Higher Levels
Add **1** target per additional Spell Level.
