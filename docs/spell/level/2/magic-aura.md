### Magic Aura
2nd-Level Illusion
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | Reach |
| Area | |
| Target | **1** Creature or Object |
| Duration | 24 hours |

---

You alter how the target appears to magical effects.

| Effect | |
|---|---|
| Creature | Choose a Creature Type. Each target is treated as a creature of the chosen type instead of its usual type _(Spells and effects that affect only the chosen type can affect the target)_. |
| Object | Choose a School of Magic, or none. Each target appears to contain magic of the chosen School, or to be nonmagical. |

#### At Higher Levels
Add **1** target per additional Spell Level.
