### Aid
2nd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Cleric, Druid, Paladin, Ranger |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Target | Up to 3 creatures |
| Duration | 8 hours |

##### Spell Effect
Each target's Hit Point maximum and current Hit Points increase by **5**.

##### At Higher Levels
Add **5** Hit Points per additional Spell Level.
