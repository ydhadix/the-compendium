### Snowball Swarm
2nd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Normal Action |
| Range | 90 ft. |
| Target | Everything in a 10-ft. radius Sphere |
| Duration | 1 minute |

##### Spell Effect
Each target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **3d6** Cold Damage, and the target's Speed decreases by **10** feet. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d6** Cold Damage and **30** feet to the Range per additional Spell Level.
