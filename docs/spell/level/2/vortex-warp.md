### Vortex Warp
2nd-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 90 ft. |
| Target | One other creature or object |
| Duration | — |

##### Spell Effect
The target makes a Fortitude Save.

| | |
|---|---|
| Fail | You teleport the target to an unoccupied space on a surface or in a liquid that can support it without squeezing. |
| Success | No effect. |

##### At Higher Levels
Add **30** feet of Range per additional Spell Level.
