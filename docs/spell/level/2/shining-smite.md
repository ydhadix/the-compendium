### Shining Smite
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Paladin |
| Components | V |
| Casting Time | Bonus Action, when you hit with a Melee Weapon Attack |
| Range | — |
| Target | The target of the Attack |
| Duration | 1 minute (Concentration) |

##### Spell Effect
You deal **2d6** Radiant Damage and the target gains the following effects:

- It emits Bright Light out to **5** feet.
- It can't benefit from being Invisible.
- Attack Rolls against it gain Advantage.

##### At Higher Levels
Add **1d6** Radiant Damage per additional Spell Level.
