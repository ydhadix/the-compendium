### Lesser Restoration
2nd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Bard, Cleric, Druid, Paladin, Ranger |
| Components | V, S |
| Casting Time | Bonus Action |
| Range | Reach |
| Area | — |
| Target | **1** Creature |
| Duration | — |

---

You end **1** Blindness, Deafness, Paralysis, or Sickness on the target.

#### At Higher Levels
Add **1** target per additional Spell Level.
