### Immovable Object
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M _(consumes gold dust worth 25 Gold)_ |
| Casting Time | Normal Action |
| Range | Reach |
| Target | One object that weighs 10 pounds or less |
| Duration | 1 hour |

##### Spell Effect
You anchor the target, even defying gravity. You can designate creatures that ignore this effect. You can also set a verbal password that suppresses this effect for **1** minute.

This Spell ends if more than **8,000** pounds of weight is held by the target; less weight than that doesn't affect it.

###### Overpower
Utilize Action
{ .subtitle }

A creature within Reach of the target can make an Athletics Check against your Spell Save DC.

| | |
|---|---|
| Success | It can move the target up to **10** feet, ignoring any weight the target holds. |

##### At Higher Levels
When Upcast to 3rd-Level, the weight limit is **10,000** pounds and the Duration is 8 hours.

When Upcast to 4th- or 5th-Level, the weight limit is **12,500** pounds, the Duration is 24 hours, and the Ability Check's DC increases by **5**.

When Upcast to 6th-Level or higher, the weight limit is **20,000** pounds, the Duration is until dispelled, and the Ability Check's DC increases by **10**.
