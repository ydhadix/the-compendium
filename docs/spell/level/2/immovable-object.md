### Immovable Object
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Wizard |
| Components | V, S, M _(consumes gold dust worth 25 Gold)_ |
| Casting Time | Magic Action |
| Range | Reach |
| Area | — |
| Target | **1** Object that weighs 10 pounds or less |
| Duration | 1 hour |

---

You anchor each target, even defying gravity.  After a target holds more than **8,000** pounds of weight, this Spell ends on it; less weight than that doesn't affect it.

##### Overpower
**Utilize Action:** Any creature that can reach the target can make an Athletics Check against your Spell Save DC.

| | |
|---|---|
| Success | The creature can propel the target up to **10** feet, ignoring any weight the target holds. |
| Fail | No effect. |

#### Password
After you cast this Spell, you can choose a password.  After a creature speaks this password, or presents it visually, the creature ignores this Spell's effects.

#### At Higher Levels
When Upcast to 3rd-Level, the weight limit is **10,000** pounds and the Duration is **8** hours.

When Upcast to 4th- or 5th-Level, the weight limit is **12,500** pounds, the Duration is **24** hours, and the Ability Check's DC increases by **5**.

When Upcast to 6th-Level or higher, the weight limit is **20,000** pounds, the Duration is until dispelled, and the Ability Check's DC increases by **10**.
