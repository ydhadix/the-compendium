### Warding Bond
2nd-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Paladin |
| Components | V, S, M _(two platinum rings worth 50 Gold each)_ |
| Casting Time | Magic Action |
| Range | — |
| Area | A 60-ft. Aura |
| Target | Any Creature |
| Duration | 1 hour |

---

While you and a target each wear one of the Material Components, the target gains the following effects:

- You increase the target's Armor Class and Saves by **1**.
- The target gains Resistance to all damage.
- After the target takes damage, you take the same amount.

After you are Downed, this Spell ends.  After this Spell is cast again on you or on a target, the previous casting ends.
