### Alter Self
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Normal Action |
| Range | — |
| Target | Self |
| Duration | 1 hour (Concentration) |

##### Spell Effect
Choose one of the following transformations:

- **Aquatic Adaptation.** You can breathe underwater and gain a Swim Speed equal to your Speed.
- **Change Appearance.** You make yourself look and sound different. You can't change your Size Category and must keep the same basic arrangement of limbs; otherwise, the extent of the transformation is up to you.
- **Natural Weapons.** You grow claws, fangs, horns, or hooves. Unarmed Strikes using the transformed appendage use your Spellcasting Ability and deal **1d6** Bludgeoning, Piercing, or Slashing Damage.
