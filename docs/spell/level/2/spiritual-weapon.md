### Spiritual Weapon
2nd-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Bonus Action |
| Range | 60 ft. |
| Target | — |
| Duration | 1 minute (Concentration) |

##### Spell Effect
You create a floating, spectral force resembling a weapon.  While the weapon shares your space, it moves with you.

###### Attack
Bonus Action
{ .subtitle }

You can move the weapon up to your Speed, then make a Melee Attack against a target within **5** feet of it.

| | |
|---|---|
| Hit | You deal **1d8 + Spellcasting Ability** Force Damage. |

##### At Higher Levels
Add **1d8** damage per additional Spell Level.
