### Magic Weapon
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Artificer, Paladin, Ranger, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Bonus Action |
| Range | Reach |
| Target | One weapon |
| Duration | 1 hour |

##### Spell Effect
The target is treated as a magic weapon and gains a **+1** bonus to Weapon Attack and Damage Rolls, unless it already has an equivalent or greater bonus.

##### At Higher Levels
When Upcast to 3rd- or 4th-Level, the bonus increases to **+2**.

When Upcast to 5th-Level or higher, the bonus increases to **+3**.
