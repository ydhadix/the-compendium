### Dragon's Breath
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Bonus Action |
| Range | Reach |
| Area | — |
| Target | **1** Creature |
| Duration | 1 minute (Concentration) |

---

Choose an Elemental Damage Type.

##### Breath Weapon
**Magic Action:** Any target can force each Creature and Object in a **15**-foot Cone to make a Reflex Save.

| | |
|---|---|
| Fail | You deal **3d6** damage of the chosen type. |
| Success | You deal half as much damage. |

#### At Higher Levels
Add **1d6** damage per additional Spell Level.
