### Cordon of Arrows
2nd-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Ranger |
| Components | V, S, M |
| Casting Time | Magic Action, or Ritual |
| Range | Reach |
| Area | A 30-ft. radius Sphere |
| Target | Each Creature |
| Duration | 8 hours |

---

After a target enters the area _(including when this Spell is cast)_, it makes a Reflex Save.  After your Turn starts, each target also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You deal **2d4** Piercing Damage. |
| Success | No effect. |

After this Spell triggers **4** times, this Spell ends.

#### Password
After you cast this Spell, you can choose a password.  After a creature speaks this password, or presents it visually, the creature ignores this Spell's effects.

#### At Higher Levels
Add **2** triggers per additional Spell Level.
