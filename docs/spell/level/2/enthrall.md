### Enthrall
2nd-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Warlock |
| Components | V, S |
| Casting Time | Normal Action |
| Range | 60 ft. |
| Target | Each creature you choose within 60 ft. |
| Duration | 1 minute |

##### Spell Effect
Each target makes a Will Save.  A creature you or an Ally is fighting automatically succeeds.

| | |
|---|---|
| Fail | The target's Perception Checks and Passive Perception decrease by **10**. |
| Success | No effect. |
