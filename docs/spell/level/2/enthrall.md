### Enthrall
2nd-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Warlock |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | |
| Target | Each Creature you choose within 60 ft. |
| Duration | 1 minute |

---

Each target makes a Will Save.  If you or an Ally is fighting a target, it automatically succeeds.

| | |
|---|---|
| Fail | The target's Perception Checks and Passive Perception decrease by **10**. |
| Success | No effect. |
