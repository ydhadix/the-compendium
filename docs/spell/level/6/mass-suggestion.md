### Mass Suggestion
6th-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Wizard |
| Components | V, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | — |
| Target | Up to **12** Creatures who understand you |
| Duration | 24 hours |

---

Each target gains the effect of _Suggestion_ _(you suggest the same activity for each target)_.

#### At Higher Levels
When Upcast, the duration is **10** days _(7th-Level)_, **30** days _(8th-Level)_, or **366** days _(9th-Level)_.
