### Conjure Fey
6th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | — |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
You conjure an intangible Medium spirit from the Feywild in an unoccupied space, taking the appearance of any Fey creature.

###### Attack
Bonus Action
{ .subtitle }

You can teleport the spirit up to **30** feet, then make a Melee Spell Attack against a target within **5** feet of it.

| | |
|---|---|
| Hit | You deal **3d12 + Spellcasting Ability** Psychic Damage and frighten the target until the start of your next Turn. |

##### At Higher Levels
Add **1d12** damage per additional Spell Level.
