### Blade Barrier
6th-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 90 ft. |
| Target | A 100-ft. × 5-ft. × 20-ft. Wall, or a 30-ft.-radius, 20-ft. Cylinder |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
The area provides Three-Quarters Cover and is Difficult Terrain.

After a target enters the area _(including when this Spell is cast)_, it makes a Reflex Save.  After your Turn starts, everything in the area also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You deal **6d10** Force Damage. |
| Success | You deal half as much damage. |
