### Instant Summons
6th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | V, S, M _(a sapphire worth 1,000 Gold)_ |
| Casting Time | 1 minute, or Ritual |
| Range | Reach |
| Target | One object that weighs 10 pounds or less and is no more than 6 ft. across |
| Duration | Until dispelled |

##### Spell Effect
You place an Invisible mark on the target and inscribe its name on the sapphire used to cast this Spell.  Each casting requires a different sapphire.

###### Summon
Magic Action
{ .subtitle }

You can speak the target's name and crush the sapphire, ending this Spell.  The target appears in your hand, regardless of physical or planar distance.

If another creature holds or carries the target, the target isn't transported; instead, you learn who that creature is and where it is.
