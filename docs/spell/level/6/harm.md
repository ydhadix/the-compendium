### Harm
6th-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | — |
| Target | **1** Creature |
| Duration | — |

---

Each target makes a Fortitude Save.

| | |
|---|---|
