### Harm
6th-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | One creature |
| Duration | — |

##### Spell Effect
The target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **14d6** Necrotic Damage, and the target's Hit Point Maximum decreases by that amount, to a minimum of **1**. |
| Success | You deal half as much damage. |
