### Wind Walk
6th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Druid |
| Components | V, S, M |
| Casting Time | 1 minute |
| Range | 30 ft. |
| Area | — |
| Target | You and up to **10** Allies |
| Duration | 8 hours |

---

Each target gains the effect of _Gaseous Form_ _(it gains a **300**-foot Hover Speed instead)_.

After this Spell ends, a falling target gains the effect of _Feather Fall_.

##### Change Form
**Utilize Action:** Any target can stun itself for **1** minute.  Then, it loses or regains the effect of _Gaseous Form_.
