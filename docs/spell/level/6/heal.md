### Heal
6th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | One creature |
| Duration | — |

##### Spell Effect
You heal the target by **70**, and end any Blindness, Deafness, and Sickness affecting it.

##### At Higher Levels
Add **10** to the healing per additional Spell Level.
