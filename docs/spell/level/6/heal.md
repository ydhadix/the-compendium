### Heal
6th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | — |
| Target | **1** Creature |
| Duration | — |

---

You heal each target by **70**, and end each Blindness, Deafness, and Sickness on it.

#### At Higher Levels
Add **10** to the healing per additional Spell Level.
