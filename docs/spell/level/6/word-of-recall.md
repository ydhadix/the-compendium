### Word of Recall
6th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V |
| Casting Time | Magic Action |
| Range | 5 ft. |
| Area | — |
| Target | You and up to **5** Allies |
| Duration | — |

---

Choose **1** of the following effects:

| Effect | |
|---|---|
| Designate | Your current location becomes your Recall Sanctuary, provided it qualifies. |
| Recall | Each target teleports to your Recall Sanctuary, appearing in the nearest unoccupied spaces to the spot you designated.  If you don't have a Recall Sanctuary, this effect does nothing. |

---

#### Recall Sanctuaries
Any Location dedicated to or strongly linked to a deity you worship, such as a temple or shrine, can become a **Recall Sanctuary**.  You can have only one Recall Sanctuary at a time.
