### Word of Recall
6th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V |
| Casting Time | Magic Action |
| Range | 5 ft. |
| Target | You and up to 5 Allies |
| Duration | — |

##### Spell Effect
Each target teleports to your sanctuary, appearing in the nearest unoccupied spaces to the spot you designated.  This Spell has no effect if you have no sanctuary.

You designate a location as your sanctuary by casting this Spell there.
