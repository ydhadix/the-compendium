### Summon Fiend
6th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Warlock, Wizard |
| Components | V, S, M _(a bloody vial worth 600 Gold)_ |
| Casting Time | Magic Action |
| Range | 90 ft. |
| Target | — |
| Duration | 1 hour (Concentration) |

##### Spell Effect
You summon a Companion Fiendish Spirit. Choose Demon, Devil, or Yugoloth.

This Spell ends if the Spirit has **0** Hit Points.

###### Command
Free Action
{ .subtitle }

You can command the Spirit to move and take any Action available to it.

##### At Higher Levels
The Spell Level determines the Spirit's Armor Class, Hit Points, and attack damage.
