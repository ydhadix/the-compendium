### Programmed Illusion
6th-Level Illusion
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Wizard |
| Components | V, S, M _(jade dust worth 25 Gold)_ |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Target | A 30-ft. Cube |
| Duration | Until dispelled |

##### Spell Effect
You create an imperceptible image of an object, creature, or other visible phenomenon in the area, describing how it behaves and what sounds it makes for up to **5** minutes.  You also specify a trigger, based on visual or audible phenomena occurring within **30** feet of the area.

After the trigger occurs, the image performs as you described, then vanishes and lies dormant for **10** minutes before it can be triggered again.

###### Search
Search Action
{ .subtitle }

A creature that perceives the illusion can make a Perception Check against your Spell Save DC.

| | |
|---|---|
| Success | The illusion becomes faint to that creature. |
