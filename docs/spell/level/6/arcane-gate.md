### Arcane Gate
6th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Warlock, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 500 ft. |
| Target | — |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
You create **2** linked portals in unoccupied Large spaces on the ground, one within range and the other within **10** feet of you.  Each portal is a ring of mist that blocks sight, hovering just above the ground.

A portal is open on one side only.  Anything that enters the open side of one portal exits from the open side of the other.

###### Turn Portals
Bonus Action
{ .subtitle }

You can change which side of each portal is open.
