### Disintegrate
6th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M _(a lodestone and dust)_ |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | One creature, nonmagical object, or creation of magical force |
| Duration | — |

##### Spell Effect
A creature target makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **10d6 + 40** Force Damage.  If the target has **0** Hit Points, it and everything nonmagical it wears and carries are disintegrated into gray dust, and it can't be revived by a Spell of 6th-Level or lower. |
| Success | No effect. |

An object or creation of magical force is disintegrated instead of making a Saving Throw.  If it is Huge or larger, only a **10**-foot Cube of it is disintegrated.

##### At Higher Levels
Add **3d6** damage per additional Spell Level.
