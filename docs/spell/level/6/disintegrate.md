### Disintegrate
6th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | — |
| Target | **1** Creature or Object |
| Duration | — |

---

If a target is an Object, you disintegrate it, even if it has Immunity to all damage.  You disintegrate only a **10**-foot Cube of a Huge or larger Object, and you disintegrate an Object created by a Spell only if that Spell's Level is no higher than this Spell's.

If a target is a Creature, it makes a Reflex Save.

| | |
|---|---|
| Fail | You deal **10d6 + 40** Force Damage. If the target has **0** Hit Points, it and everything nonmagical it wears and carries are disintegrated into dust, and it can't be resurrected by a lower-Level Spell. |
| Success | No effect. |

#### At Higher Levels
Add **3d6** damage per additional Spell Level.
