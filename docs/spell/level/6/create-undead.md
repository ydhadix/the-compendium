### Create Undead
6th-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Warlock, Wizard |
| Components | V, S, M _(one black onyx stone worth 150 Gold per target)_ |
| Casting Time | 1 minute |
| Range | 10 ft. |
| Target | up to 3 Medium or Small Humanoid corpses, or up to 3 Undead you created with this Spell |
| Duration | 24 hours |

##### Spell Effect
You can cast this Spell only at night.

Each target becomes a Ghoul that obeys your commands.  If you don't issue a command, it Dodges and moves to avoid danger.

After this Spell ends on a creature, it remains animated but stops obeying you.  You can cast this Spell to regain control of creatures you created with it, instead of animating new ones.

###### Command
Bonus Action
{ .subtitle }

You can command any creatures within **120** feet that you created with this Spell.

##### At Higher Levels
When Upcast, each casting animates or controls **4** Ghouls _(7th-Level)_, **5** Ghouls or **2** Ghasts or Wights _(8th-Level)_, or **6** Ghouls, **3** Ghasts or Wights, or **2** Mummies _(9th-Level)_.
