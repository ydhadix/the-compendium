### Create Undead
6th-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Warlock, Wizard |
| Components | V, S, M _(one black onyx stone worth 150 Gold per target)_ |
| Casting Time | 1 minute |
| Range | 10 ft. |
| Area | — |
| Target | Up to **3** Medium or Small Humanoid Corpses, or up to **3** Undead you created with this Spell |
| Duration | 24 hours |

---

You can cast this Spell only at night.

If a target is a corpse, it becomes a Ghoul.

If a target is an Undead you created with this Spell, you regain control of it.

Each target obeys your commands.  If you don't issue a command, it Dodges and moves to avoid danger.

After this Spell ends on a creature, it remains animated but stops obeying you.

##### Command
**Bonus Action:** You can command any Creatures within **120** feet that you created with this Spell.

#### At Higher Levels
When Upcast, each casting animates or controls **4** Ghouls _(7th-Level)_, **5** Ghouls or **2** Ghasts or Wights _(8th-Level)_, or **6** Ghouls, **3** Ghasts or Wights, or **2** Mummies _(9th-Level)_.
