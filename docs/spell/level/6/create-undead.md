### Create Undead
6th-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Warlock, Wizard |
| Components | V, S, M _(one black onyx stone worth 150 Gold per target)_ |
| Casting Time | 1 minute |
| Range | 10 ft. |
| Area | — |
| Target | Up to **3** Humanoid Corpses, or up to **3** Undead you animated |
| Duration | 24 hours |

---

You can cast this Spell only at night.

If a target is a Corpse, you animate it as a Ghoul Companion.

If a target is an Undead you animated, it becomes your Companion.

After this Spell ends, each target stops being your Companion but remains animated.

##### Command Undead
**Bonus Action:** You can command any of your Undead companions within **120** feet to move and take any Action available to them.  You give the same command to each target.

#### At Higher Levels
When Upcast, each casting animates or controls **4** Ghouls _(7th-Level)_, **5** Ghouls or **2** Ghasts or Wights _(8th-Level)_, or **6** Ghouls, **3** Ghasts or Wights, or **2** Mummies _(9th-Level)_.
