### Sunbeam
6th-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Cleric, Druid, Sorcerer, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | — |
| Area | — |
| Target | Self |
| Duration | 1 minute (Concentration) |

---

You emit Bright Sunlight out to **30** feet and Dim Sunlight **30** feet further.

You take the following Action as part of casting this Spell.

##### Beam
**Magic Action:** You can choose a **60**-foot × **5**-foot Line originating from you.  Each Creature and Object in it makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **6d8** Radiant Damage and blind the target until the start of your next Turn. |
| Success | You deal half as much damage. |
