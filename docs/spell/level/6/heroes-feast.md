### Heroes' Feast
6th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid |
| Components | V, S, M _(consumes a gem-encrusted bowl worth 1,000 Gold)_ |
| Casting Time | 10 minutes |
| Range | Reach |
| Target | up to 12 creatures |
| Duration | — |

##### Spell Effect
You conjure a feast on a surface in an unoccupied **10**-foot Cube next to you.  The feast takes **1** hour to consume, then disappears.

After a target partakes of the feast, it gains the following benefits for **24** hours:

- Poison Resistance.
- Fear Immunity and Sickness Immunity.
- Its Hit Point Maximum increases by **2d10**, and it gains the same number of Hit Points.
