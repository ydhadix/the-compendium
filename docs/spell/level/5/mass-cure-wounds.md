### Mass Cure Wounds
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Area | A 30-ft. radius Sphere |
| Target | Up to **6** Creatures |
| Duration | — |

---

You heal each target by **5d8 + Spellcasting Ability**.

#### At Higher Levels
Add **1d8** to the healing per additional Spell Level.
