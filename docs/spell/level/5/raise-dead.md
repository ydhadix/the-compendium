### Raise Dead
5th-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric |
| Components | V, S, M _(consumes a diamond worth 500 Gold)_ |
| Casting Time | 1 hour |
| Range | Reach |
| Area | — |
| Target | **1** Corpse that died within the past 10 days |
| Duration | — |

---

You resurrect each target with **1** Hit Point and end each Sickness on it.  The target's Exhaustion level becomes **5**.

This Spell closes mortal wounds, but doesn't restore missing body parts or reverse the effects of old age; it has no effect on a target that can't sustain life.
