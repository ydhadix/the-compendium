### Raise Dead
5th-Level Necromancy
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric |
| Components | V, S, M _(consumes a diamond worth 500 Gold)_ |
| Casting Time | 1 hour |
| Range | Reach |
| Target | One non-Undead creature that died within the past 10 days |
| Duration | — |

##### Spell Effect
You revive the target with **1** Hit Point and remove any Sickness affecting it.  The target's Exhaustion level becomes **5**.

This Spell closes mortal wounds, but doesn't restore missing body parts or reverse the effects of old age; if the target's body could not sustain life, the casting fails.
