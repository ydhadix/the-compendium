### Dispel Evil and Good
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S, M _(powdered silver and iron)_ |
| Casting Time | Magic Action |
| Range | — |
| Target | Self |
| Duration | 1 minute (Concentration) |

##### Spell Effect
Aberrations, Celestials, Elementals, Fey, Fiends, and Undead gain Disadvantage on Attack Rolls against you.

You can end this Spell with either of the following effects:

###### Break Enchantment
Magic Action
{ .subtitle }

You touch a creature that is possessed, Charmed, or Frightened by one of the above creatures.  The target is no longer possessed, Charmed, or Frightened by such creatures.

###### Dismissal
Magic Action
{ .subtitle }

One of the above creatures within Reach makes a Will Save.

| | |
|---|---|
| Fail | You banish the target to its home plane, unless it is already there.  An Undead is instead sent to the Shadowfell, and a Fey to the Feywild. |
| Success | No effect. |
