### Regal Presence
5th-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Wizard |
| Components | V, S, M _(a miniature tiara)_ |
| Casting Time | Normal Action |
| Range | — |
| Target | Each creature you choose in a 10-ft. Aura |
| Duration | 1 minute (Concentration) |

##### Spell Effect
After a target enters the area __(including when this Spell is cast or the area moves)__, it makes a Will Save.  After your Turn starts, each target also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You deal **4d6** Psychic Damage, knock the target Prone, and can propel it up to **10** feet away from you. |
| Success | You deal half as much damage. |
