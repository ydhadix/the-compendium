### Scrying
5th-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid, Warlock, Wizard |
| Components | V, S, M _(a focus worth 1,000 Gold, such as a crystal ball, mirror, or water-filled font)_ |
| Casting Time | 10 minutes |
| Range | The same Plane |
| Area | — |
| Target | **1** Creature or Location you have heard of |
| Duration | 10 minutes (Concentration) |

---

Each target makes a Will Save, adding the modifier for your strongest physical connection to it.  If you have only heard of the target, it gains Advantage on the Saving Throw.  If you know the target well, it gains Disadvantage on the Saving Throw.  If a target is a location, it automatically fails.

| Physical Connection | Save Modifier |
|---|---|
| None | **+0** |
| A picture or likeness of the target | **−2** |
| A garment or possession of the target | **−4** |
| A body part, lock of hair, or nail clipping of the target | **−10** |

| | |
|---|---|
| Fail | You conjure a Scrying Sensor within **10** feet of the target, and can see and hear through it.  If the target is a creature, the sensor moves to stay within **10** feet of the target. |
| Success | You can't target the target with this Spell for **24** hours. |

---

#### Scrying Sensors
A **Scrying Sensor** is a Tiny, floating eye that you can perceive through.  It is Invisible and intangible, and has **30** feet of Darkvision.  While you perceive through a Scrying Sensor, your own senses are unaffected.
