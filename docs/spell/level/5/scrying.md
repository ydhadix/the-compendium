### Scrying
5th-Level Divination
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid, Warlock, Wizard |
| Components | V, S, M _(a focus worth 1,000 Gold, such as a crystal ball, mirror, or water-filled font)_ |
| Casting Time | 10 minutes |
| Range | — |
| Target | One creature or location on your plane |
| Duration | 10 minutes (Concentration) |

##### Spell Effect
The target makes a Will Save, modified by how well you know it and what physical connection you have to it.  A noncreature target automatically fails. 

| Your Knowledge of the Target | Save Modifier |
|---|---|
| Secondhand _(heard of it)_ | +5 |
| Firsthand _(met it)_ | +0 |
| Extensive _(know it well)_ | −5 |

| You Have the Target's... | Save Modifier |
|---|---|
| Picture or likeness | −2 |
| Garment or possession | −4 |
| Body part, lock of hair, or nail clipping | −10 |

| | |
|---|---|
| Fail | You create a scrying sensor within **10** feet of the target.  The sensor is a Tiny, Invisible and intangible object with **30** feet of Darkvision.  You can see and hear through its senses _(Your normal senses are unaffected)_.  If the target is a creature, the sensor moves to stay within **10** feet of the target. |
| Success | The target is unaffected, and you can't target it with this Spell again for **24** hours. |
