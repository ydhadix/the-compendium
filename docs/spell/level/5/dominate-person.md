### Dominate Person
5th-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 60 ft. |
| Target | One Humanoid |
| Duration | 1 minute (Concentration) |

##### Spell Effect
The target makes a Will Save.  If you or an Ally is fighting the target, it gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | You charm the target and it becomes a Companion to you. |
| Success | No effect. |

After the target takes damage, it repeats this Saving Throw.  On a success, this effect ends on the target.

###### Command
Free Action
{ .subtitle }

You can command the target charmed by you to move and take any Action available to it.

##### At Higher Levels
When Upcast to 6th-Level, the Concentration can last up to 10 minutes.

When Upcast to 7th-Level, it can last up to 1 hour.

When Upcast to 8th-Level or higher, it can last up to 8 hours.
