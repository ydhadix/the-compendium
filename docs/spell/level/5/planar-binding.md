### Planar Binding
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid, Warlock, Wizard |
| Components | V, S, M _(consumes a jewel worth 1,000 Gold)_ |
| Casting Time | 1 hour |
| Range | 60 ft. |
| Area | — |
| Target | **1** Planar Creature |
| Duration | 24 hours |

---

Each target makes a Will Save.  If a target wasn't in Range for the entire casting time, it gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | The target is bound to serve you, following your commands to the best of its ability.  An Enemy target twists your commands toward its own ends.  If the target was conjured by another effect, that effect's duration is extended to match this Spell. |
| Success | No effect. |

#### At Higher Levels
When Upcast, the duration is **10** days _(6th-Level)_, **30** days _(7th-Level)_, **180** days _(8th-Level)_, or **366** days _(9th-Level)_.
