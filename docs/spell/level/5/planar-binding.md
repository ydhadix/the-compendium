### Planar Binding
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid, Warlock, Wizard |
| Components | V, S, M _(consumes a jewel worth 1,000 Gold)_ |
| Casting Time | 1 hour |
| Range | — |
| Target | One Celestial, Elemental, Fey, or Fiend in a 60-ft. Aura |
| Duration | 24 hours |

##### Spell Effect
The target makes a Will Save.   If the target was not in the area for the entire casting time, it gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | The target is bound to serve you for the duration, following your commands to the best of its ability.  An Enemy target twists your commands toward its own ends.<br>If the target was summoned or created by another Spell, that Spell's duration is extended to match this Spell. |
| Success | No effect. |

##### At Higher Levels
When Upcast, the duration is **10** days _(6th-Level)_, **30** days _(7th-Level)_, **180** days _(8th-Level)_, or **366** days _(9th-Level)_.
