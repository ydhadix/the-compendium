### Cone of Cold
5th-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Druid, Sorcerer, Wizard |
| Components | V, S, M _(a small crystal or glass cone)_ |
| Casting Time | Normal Action |
| Range | Reach |
| Target | Everything in a 60-ft. Cone |
| Duration | — |

##### Spell Effect
Each target makes a Fortitude Save.

| | |
|---|---|
| Fail | You deal **8d8** Cold Damage. |
| Success | You deal half as much damage. |

##### At Higher Levels
Add **1d8** damage per additional Spell Level.
