### Greater Restoration
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid |
| Components | V, S, M _(consumes diamond dust worth 100 Gold)_ |
| Casting Time | Magic Action |
| Range | Reach |
| Area | — |
| Target | **1** Creature |
| Duration | — |

---

Choose **1** of the following effects:

- **1** level of Exhaustion.
- **1** Charm or Petrification.
- **1** curse _(including the target's Attunement to a cursed magic item)_.
- Each reduction to **1** of its Ability scores.
- Each reduction to its Hit Point Maximum.

You end the chosen effect on each target.
