### Greater Restoration
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Cleric, Druid |
| Components | V, S, M _(consumes diamond dust worth 100 Gold)_ |
| Casting Time | Magic Action |
| Range | Reach |
| Target | One creature |
| Duration | — |

##### Spell Effect
Choose one effect to end on the target:

- **1** level of Exhaustion.
- Charm or Petrification.
- A curse, including the target's Attunement to a cursed magic item.
- Any reduction to one of its Ability scores.
- Any reduction to its Hit Point Maximum.
