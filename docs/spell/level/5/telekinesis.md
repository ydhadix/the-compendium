### Telekinesis
5th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Sorcerer, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | — |
| Area | — |
| Target | Self |
| Duration | 10 minutes (Concentration) |

---

You take the following Action as part of casting this Spell.

##### Manipulate
**Magic Action:** You can choose **1** Huge or smaller Creature or Object within **60** feet.  The target, or a Creature wearing or carrying it, makes a Fortitude Save.

| | |
|---|---|
| Fail | You propel the target up to **30** feet in any direction and restrain it until the end of your next Turn.  If the target is an object, you can Utilize using it _(no additional Action required)_. |
| Success | No effect. |
