### Steel Wind Strike
5th-Level Conjuration
{ .subtitle }

| | |
|---|---|
| Classes | Wizard |
| Components | S, M _(a Melee Weapon worth 1 Silver)_ |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | — |
| Target | Up to **5** Creatures |
| Duration | — |

| | |
|---|---|
