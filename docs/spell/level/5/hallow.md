### Hallow
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Cleric |
| Components | V, S, M _(consumes incense worth 1,000 Gold)_ |
| Casting Time | 24 hours |
| Range | Reach |
| Area | Up to a 60-ft. radius Sphere |
| Target | Each Creature and Object |
| Duration | Until dispelled |

---

Choose **1** or more Planar Creature Types.  The chosen Creature Types become sealed.

Each target gains the effect of _Protection from Good and Evil_ _(only against sealed creatures)_.

A sealed creature can't enter the area or reach into it _(Spells, Ranged Attacks, and Reach Weapons still pass through)_.

The area gains **1** of the following effects:

| Effect | |
|---|---|
| Courage | Each target gains Fear Immunity. |
| Darkness | The area gains the effect of _Darkness_. |
| Fear | While a sealed creature is in the area, the area frightens it. |
| Gentle Repose | Corpse targets gain the effect of _Gentle Repose_. |
| Resistance | Choose any Damage Type.  Each target gains Resistance to the chosen Damage Type. |
| Sunlight | Bright Sunlight fills the area. |
| Tongues | Each target gains the effect of _Tongues_. |
| Vulnerability | A sealed creature gains Vulnerability to damage that originates from the area. |
| Ward Sound | No sound can pass into or out of the area. |
| Ward Travel | Nothing can enter or leave the area by teleportation or Planar Travel. |

#### Permanence
If you cast this Spell on the same area every day for **365** days, the effect lasts until dispelled.
