### Antilife Shell
5th-Level Abjuration
{ .subtitle }

| | |
|---|---|
| Classes | Druid |
| Components | V, S |
| Casting Time | Magic Action |
| Range | — |
| Target | A 10-ft. Aura |
| Duration | 1 minute (Concentration) |

##### Spell Effect
Each non-Construct, non-Undead creature in the area is propelled to the nearest unoccupied space outside of the area.  Non-Construct, non-Undead creatures can't enter the area or reach into it _(Spells, Ranged Attacks, and Reach Weapons can still pass through the barrier)_.

This Spell ends if you move so that a blocked creature would be forced into the area.
