### Storm of Radiance
5th-Level Evocation
{ .subtitle }

| | |
|---|---|
| Classes | Warlock, Wizard |
| Components | V, S, M |
| Casting Time | Magic Action |
| Range | 120 ft. |
| Area | A 10-ft. radius, 40-ft. Cylinder, from above |
| Target | Each Creature and Object |
| Duration | 1 minute (Concentration) |

---

The area is Heavily Obscured.

Each target is Deafened and can't cast Spells with Verbal components.

After a target enters the area _(including when this Spell is cast)_, it makes a Fortitude Save.  After your Turn starts, each target also makes this Saving Throw.  A target only makes this Saving Throw once until the start of your next Turn.

| | |
|---|---|
| Fail | You deal **2d10** Radiant Damage and **2d10** Thunder Damage. |
| Success | You deal half as much damage. |

#### At Higher Levels
Add **1d10** Radiant Damage and **1d10** Thunder Damage per additional Spell Level.
