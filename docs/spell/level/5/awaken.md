### Awaken
5th-Level Transmutation
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Druid |
| Components | V, S, M _(consumes an agate worth 1,000 Gold)_ |
| Casting Time | 8 hours |
| Range | Reach |
| Area | — |
| Target | **1** Beast or Plant Creature with an Intelligence of **-4** or less, or **1** Plant Object |
| Duration | — |

---

If a target is a Plant Object, you animate it as a Plant Creature, using statistics the DM chooses.

Each target's Intelligence becomes **0**, and it learns to speak and understand one language you know.

You charm each target for **30** days, or until you or an Ally deals damage to it.  After the Charm ends, it chooses its Disposition toward you.
