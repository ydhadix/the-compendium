### Modify Memory
5th-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Target | One creature |
| Duration | 1 minute (Concentration) |

##### Spell Effect
The target makes a Will Save.  If you are fighting the target, it gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | You charm the target, and it is Incapacitated and unaware of its surroundings, though it can still hear you.  This effect ends if the target takes damage or is targeted by another Spell. |
| Success | No effect. |

While the target is Charmed, you can reshape its memory of one event it experienced within the past **24** hours and that lasted no more than **10** minutes: you can erase the event, restore it with perfect clarity, alter its details, or replace it with a memory of another event.  You must describe the change aloud, and the target must understand your language.  The modified memory takes hold after this Spell ends; if the Spell ends before you finish describing it, the memory is unchanged.

##### At Higher Levels
When Upcast, you can alter the target's memory of an event up to **7** days ago _(6th-Level)_, **30** days ago _(7th-Level)_, **365** days ago _(8th-Level)_, or any time in its past _(9th-Level)_.
