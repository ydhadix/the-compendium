### Modify Memory
5th-Level Enchantment
{ .subtitle }

| | |
|---|---|
| Classes | Bard, Wizard |
| Components | V, S |
| Casting Time | Magic Action |
| Range | 30 ft. |
| Area | — |
| Target | **1** Creature |
| Duration | 1 minute (Concentration) |

---

Each target makes a Will Save.  If you are fighting a target, it gains Advantage on the Saving Throw.

| | |
|---|---|
| Fail | You charm and incapacitate the target, and it is unaware of its surroundings, except it can still hear you.<br>While the target is Charmed, you can verbally change its memory of one event it experienced within the past **24** hours and that lasted no more than **10** minutes.  If the target can understand you, you can erase the event, restore it with perfect clarity, alter its details, or replace it with a memory of another event. |
| Success | No effect. |

#### Ending Early
This Spell ends on a target if it takes damage or is targeted by another Spell.

#### Permanence
If this Spell lasts the full duration, the memory takes hold and the effect lasts until dispelled _(no Concentration required)_.

#### At Higher Levels
When Upcast, you can alter the target's memory of an event up to **7** days ago _(6th-Level)_, **30** days ago _(7th-Level)_, **365** days ago _(8th-Level)_, or any time in its past _(9th-Level)_.
