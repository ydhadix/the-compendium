# Parts of a Spell
Every Spell shares the same anatomy, laid out on its card and detailed below.
{ .subtitle }

| Parts of a Spell | Description |
|---|---|
| [Spell Level](spell-level.md) | The Spell's Level, from Cantrip to 6th-Level. |
| [Class List](spell-list.md) | The classes that can prepare the Spell. |
| [School of Magic](school.md) | The School the Spell belongs to. |
| [Casting Time](casting-time.md) | The Action or time it takes to cast the Spell. |
| [Components](component.md) | The Verbal, Somatic, and Material requirements to cast it. |
| [Range](target.md#range) | How far the Spell's Targets or Area can be from you. |
| [Targets](target.md) | The creatures or objects the Spell affects. |
| [Area of Effect](area.md) | The shape a Spell fills when it affects an area. |
| [Duration](duration.md) | How long the Spell's effect lasts. |
| [Concentration](concentration.md) | The focus some Spells need to stay active. |
